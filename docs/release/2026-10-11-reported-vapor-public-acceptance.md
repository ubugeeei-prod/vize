# Published Vapor acceptance on the reported Vue release

Tracking reports: #8624, #8625, #8626 and #8627. Their source runtime uses Vue
3.6.0-rc.9; that evidence does not establish behavior on the reported rc.10.

The independent `release-vapor-acceptance.yml` consumer authenticates the normal
official C/H/tag/source-PR/Release-run tuple using the existing public verifier.
H must contain every original fixture. Six original control rows and their raw
issue/source/control blobs are copied unchanged from H. JSON-encoded source is
decoded only for execution, with the original encoded blob retained and hashed.
Two additional authored SVG controls cover tier updates and array/object
class/style normalization and removal. The existing native DOM/SSR, Musea,
VRT, installed LSP and other release checks remain independently required.

The consumer lives outside the checkout, installs exact public Vize packages,
and fixes Vue, runtime-vapor and the independent compiler-sfc/dom to the
reporter's 3.6.0-rc.10. Vite 8.3.2 and real Chromium execute the installed Vize
plugin's whole original SFCs. The separate upstream compiler-sfc VDOM route
compares complete ordered DOM attributes/text, namespaces, events, updates and
unmount. SVG checks also require physical 64x64 root and 32x32 shape dimensions
and actual computed color; writable mock-DOM SVG className cannot grant credit.
Unmount must remove every physical host node, including comment anchors. Where
fixture state drives updates, replaying its patches after unmount must leave the
retained DOM and recorded events unchanged on both backends. This observes stopped
fixture-driven DOM effects; it does not claim that intentionally retained delegated
handler bindings or every original component-local ref are revoked.

Public package SRI/provider bytes, runtime package SRI, original fixture hashes,
consumer harness hashes, lockfile and successful or failed complete browser
observations are retained. Success seals only after all sixteen native/oracle
case observations. A source check, dry run or an earlier release containing
only some fixes does not qualify delivery or close any original report. This
campaign grants no SSR, complete Vapor parity or n8n umbrella acceptance.

Dispatch only after an official published cut includes the four fixes. Record
the actual successful consumer run and version before closing the reports.
Release dispatch/tag/promotion remains owned by the normal release operator.
