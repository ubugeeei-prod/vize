## Actual owner and callback boundary

The existing `NativeLintComponent` owns the exact original bare SourceBlock and
one lint-enabled default Vue 3 component parse. The ordinary and selected L1
constructors stay unchanged. This owner grants neither Descriptor selection,
File/DOM authority nor a whole successful lint result.

The actual registered `NativeTemplateRule` retains its required root callback.
Its default attribute profile is StaticOnly and its default element callback
is a Result-returning no-op. Only a concrete enabled instance that provides this
trait can opt into Bindings. Metadata names cannot confer that capability.
The driver freezes every enabled instance's profile exactly once, then takes
their intersection. An empty set, one narrow instance, or a narrow duplicate
instance keeps StaticOnly; disabled instances do not contribute. A root callback
cannot widen the frozen profile. Unknown/external/unprovided rule and requested
Vue/Vapor refusals retain their original priority.

The whole original component's lexer/recovery/source checks precede all root
and element callbacks. Root callbacks run in registry order. Each admitted
element then dispatches the same actual instances in registry order; a callback
reads its retained attributes in authored order, before child recursion.
No sorting, cross-rule attribute-first dispatch or second header/body walk is
introduced. Pending diagnostics finish only after the entire original traversal
succeeds. A late parser/body/header/context/callback refusal returns no partial
LintResult; this does not roll back arbitrary rule side effects.

## Sealed checked header

The unchanged binding validator first moves into a private ordinary module in
a move-only commit. Existing selected `binding`/`strict_binding` entrypoints
retain their old policies and refusal priorities. The new wider caller uses
the same original attribute iteration and one VueDirectives decomposition.

Private constructors produce a temporary checked element view. Public getters
expose only the actual original element/attribute and retained kind/head/range,
including fixed Bind/Prop/Full bind arguments and nonempty completed dynamic
arguments. The wider category is source syntax: values and dynamic expressions
remain opaque. HTML-head lexical completion confers no JS syntax/semantic
validity or runtime argument name. Object/missing/empty arguments and other
semantic directives remain typed refusals.

Independent source review found a genuine category hole: clean original lexing
of `:[name]tail` can overwrite the retained dynamic argument with a final static
tail. Prefix and repeated-bracket forms can similarly overwrite an argument.
Only the new wide policy now joins the retained name/argument/modifier spans to
constant opening/closing bytes. A fixed argument starts at the genuine argument
origin and ends at modifiers; a dynamic argument starts immediately after its
original `[` and its closing `]` immediately precedes modifiers or head end.
Closed suffix/prefix/multiple-argument forms return UnresolvedBinding at the
authentic head. There is no new scanner, decomposition, JS parse or selected
policy widening. Positive bracket/modifier/Unicode controls and original full
refused-input vectors accompany this correction.

The configured reporter accepts only the sealed checked attribute and verifies
its original component equals the context root component. Same source buffers
and equal spans cannot substitute for owner identity. It derives the range from
the checked proof and preserves current rule, filename, locale, HelpLevel,
severity override, complete ordered diagnostics/counts and absent labels/fixes.
Raw parts, arbitrary spans and escaped short-owner borrows are compile-fail
controls. A genuine same-component but different-element attribute also fails
the private checked-header join.

Temporary SmallVec storage may spill. It is dropped before child recursion,
so retained header storage is O(maximum header width), not ancestor-depth sum.
Callbacks reading retained observations cost O(R*A); the unchanged static
duplicate comparison remains O(A squared). No allocation-free/whole-header
linear claim, persistent index, serialization or extra stage is made.
