## Smallest ready consumer

Admit one root original For over a same-owner direct primitive Const setup
declaration, with one original value parameter and an attribute-free plain HTML
Element containing empty/static text or the already supported single current
value-alias interpolation. For example:

```vue
<script setup>const count=2</script>
<template><i v-for='item in count'>{{item}}</i></template>
```

The actual normally owned Descriptor, Program, completed File, attached
OriginalFor, whole Params and collection syntax, original declaration scopes and
immutable collection/body occurrences already exist. No new L1/L2 provider,
parser, resolver, header/body/AST/Op walk, manufactured ExprRef or ScriptUnit is
needed. SetupConst is not a numeric type or a positive-range proof.

The existing DOM Enter retains the same `DomFileForHead.collection_read`; the
selected policy still checks actual `NativeSelectedSetup.binding`. Preserve the
existing root block bit as the whole loop eligibility seal. Only the constant
carrier Element uses the existing non-block bit; Leave checks that same row's
constant-versus-mutable child contract before completing the root. Existing
empty/static/current-value singleton closure and every other body refusal stay
bounded. There is no new persistent table, row field, vector, frame or allocation.

## Exact target contract

[Vue 3.5.35 expression processing](https://github.com/vuejs/core/blob/v3.5.35/packages/compiler-core/src/transforms/transformExpression.ts)
marks an actual constant setup Identifier as patch-skippable.
[Its For transform](https://github.com/vuejs/core/blob/v3.5.35/packages/compiler-core/src/transforms/vFor.ts)
then chooses tracking-enabled `openBlock()`, `STABLE_FRAGMENT` 64 and a callback
Element vnode. The mutable branch keeps disabled tracking, child blocks and
`UNKEYED_FRAGMENT` 256. Native L4 derives this choice from the admitted original
row, writes the original `$setup` collection and Params spans, and calls the
actual `renderList` helper through the same existing Writer and module assembler.
The callback collision guard additionally covers actual `createElementVNode`.
Existing `_`/`$` ReservedAlias refusals remain earlier than target guards.

Native static children are emitted directly as vnodes. This does not claim the
primary compiler's hoist/cache optimization, or add such a stage. Full desired
native modules and maps must be independently authored and frozen; the complete
pinned primary modules/maps are retained by the hosted qualification recipe.

[The actual renderList implementation](https://github.com/vuejs/core/blob/v3.5.35/packages/runtime-core/src/helpers/renderList.ts)
owns number/string/empty semantics. Do not evaluate initializers or infer a
numeric range from PrimitiveLiteral. Distinct development invalid-number warning
and production RangeError behavior is a real runtime control, not a new compiler
guard. String iteration uses UTF-16 units. Source/refined primitive classes retain
their existing target policy; no SSR/hydration claim follows from DOM execution.

## Source gaps deliberately left open

- SSR For remains Operation-refused. It needs its own authentic original-For
  receipt, Enter/Leave part boundaries and server collection writer; DOM rows
  cannot grant SSR authority. Its shared source is reserved by #7752.
- Parent-alias nested collection has genuine template provenance, but no setup
  ScriptUnit or runtime spelling. Nested/control/body target contracts remain
  separate, without fake setup promotion.
- Key/index reads need their actual original role and runtime callback contract;
  keyed attributes, groups, components, slots and broad bodies remain refused.
- Native `v-if` requires an original conditional attribute operand and complete
  branch/source receiver; generic mechanical If nodes cannot supply that owner.
- Arrays, imports, calls/macros and wider setup syntax remain refused by the
  existing sole Program walk; a larger container/runtime provider is separate.
- #6838/#6839/#6840/#6880 remain open. Registered component-loop diagnostics and
  historical dynamic ref/array/component cases grant no output or default/history
  closure. This bounded constant consumer is not general Vue control completion.
