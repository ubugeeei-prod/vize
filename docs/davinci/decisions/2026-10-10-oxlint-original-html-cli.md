## Normal empty-host authority

HTML-only targets yield the genuine host's `NoFilesFound` outcome because Oxlint
does not select HTML. Normalize it only with completed native execution of at
least one HTML file, an eligible original root, the pinned exact normal status,
empty stderr, no signal/stream/spawn error and the whole closed format-specific
packet. Default requires its genuine zero-file rule/thread footer; JSON requires
all five unique host report fields and genuine non-null rule/thread/time metadata;
Unix and Stylish require precisely the sole original NoFilesFound line. An early
root exclusion or zero native execution retains the original bytes and status.
Arbitrary substring stripping and invented host metadata are forbidden.

For JSON, append actual native diagnostic fragments and add actual HTML file/time
measurements to the existing host fields. Preserve every other host field and the
original authored diagnostic array/layout. Human reports preserve existing host
bytes and append the complete attributed native report. Actual native errors and
original/root deny-warnings produce failure; warning-only eligible HTML can finish
successfully. Setup/inspection/write/severity contracts outside the finite profile
remain visible refusals after preserving the genuine original process.
