# Model-checking the unsafe islands

The fleet rule admits `unsafe` when every block states its `// SAFETY:` argument and a differential test exercises it. This record adds a machine-checked layer where the argument is about memory or UTF-8 that Kani can decide on the shipped code. It also lists every remaining site with the oracle that holds it. `tests/tooling/unsafe-inventory.test.ts` holds the list. It walks the module tree of every `crates/*/src` and `davinci/*/src` crate root and skips `#[cfg(test)]`, `#[cfg(kani)]` and `#[cfg(creusot)]` modules, including inline ones. Comments and literals are blanked, and the test counts the `unsafe` tokens in each product file. The per-file counts must equal the sums of the rows below. A new `unsafe` therefore fails CI until it has a row, a class and a verifier. Every `kani` reference must name a `#[kani::proof]` with `kani::cover!` checks, and a Davinci Kani job must run it with its kernel in the workflow paths. Every `creusot` reference must name a function in the row's own file, that file must be a module of a `tests/formal/creusot` package, and the Davinci Creusot workflow must watch it.

Sites fall into three classes. **(a)** Pure memory or UTF-8 reasoning over values the code builds itself. **(b)** FFI and operating-system contracts: libc, Win32, N-API and the mimalloc option store. Kani has no model of the foreign side, so these rows name the platform contract and the test that runs it. **(c)** Lifetime widening and arena or traversal pointer dereferences. Their argument is about who keeps a borrow alive or who holds the only mutable path. Kani has no aliasing model, so these rows name the Miri lane or the tests that walk the real trees.

## How the harnesses run

Each harness is a `kani.rs` module next to its kernel. The kernel declares it with `#[cfg(test)] mod kani;` and every item in it is `#[cfg(kani)]`, as in the position-index harnesses. A product build never compiles the module, so these declarations cannot change product code. The kernels use `CompactString`, the oxc-backed arena or other crate items, so a standalone `kani file.rs` root cannot include them. Instead `cargo kani --manifest-path <crate>/Cargo.toml --lib --tests --harness <name>` compiles the crate unchanged with the harness added. Davinci Kani runs one job per crate.

Kani is for small models here. Every harness is checked on the smallest piece that carries its SAFETY claim. It must pass locally under the fleet runner's limits: one CBMC at a time, 4 GB resident and 10 minutes. Kani checks bounds, pointer validity and liveness, frees and every assertion. The harnesses assert each SAFETY comment's premise as a property. The bytes `fill` reports must equal a prefix of whole `&str` pieces, which makes them valid UTF-8 and proves every one was written. Kani gives an unwritten `MaybeUninit` byte every value, so an unwritten byte fails the comparison. Parked references must read back their values after the vector relocates. The allocator wrapper must hand back writable, prefix-preserving blocks.

## Proved deductively

Some claims are about an index or a byte sequence of any length, which is past what CBMC can bound. Creusot proves these on the shipped source instead (see [the Creusot record](./2026-11-17-creusot.md)).

- **`ScopeChain`'s current row.** Kani's smallest model passed 4.8 GB because `Scope`'s tables and data variants dominate it. The index law does not depend on `Scope`, so the rows and the current index now live in a generic kernel, `scope/chain/rows.rs` (`Rows<T>`), whose fields only its own methods can touch. Its type invariant is `current < rows.len()`. Creusot assumes the invariant of every table a method receives and proves it of every table a method returns or leaves behind through `&mut`. In `Rows::current` and `Rows::current_mut` it discharges the `requires` that creusot-std 0.14 gives `<[T]>::get_unchecked` and `get_unchecked_mut` (`ix.in_bounds`). No `Rows` method has a precondition, so the proof holds for any caller in the crate: a panic is a failing goal in Creusot, so `select` reports a missing row and `ScopeChain::set_current` panics on it as before. `the_current_row_exists_after_every_transition_sequence` in `scope/chain/creusot.rs` restates the law for every table and every sequence of appends, selections and reservations. The package is `tests/formal/creusot/scope-chain`.

## Not model-checked, and why

**CBMC model too large.** These models exceeded the runner's 4 GB or 10-minute limit even at their smallest useful bounds, so they were dropped:

- `rebuild_source` end to end: `CompactString`'s heap representation passed 8 GB, an arbitrary `char` per part passed 12 GB, and one part of each kind around two fixed scalars passed 10 minutes. `fill` carries the claim instead (above). `CompactString`'s `spare_capacity_mut` and `set_len` rest on `compact_str`'s contract and the `text_rebuild` fuzz target.
- `apply_scoped_css` over two-scalar stylesheets (4.1 GB), and the v-bind transform over five-token stylesheets with `memchr` stubbed by its specification (10 minutes). Symbolic text through these scanners is past the budget.

**Whole drivers.** The SFC formatter, the template formatter and the script-setup compilers convert at the end of whole oxc-AST or SFC drivers. The byte building is the driver itself, not a separate function. Extracting a kernel would change the product IR, so these rows name their oracle. `read_to_string` reduces its claim to `decode_utf8`. Below 64 bytes that is `core::str::from_utf8`. Above 64 bytes it is simdutf8, whose runtime CPU dispatch Kani cannot compile. Its differential tests against the standard decoder are the oracle.

## Findings

- `reborrow_markup` (`crates/vize_patina/src/markup.rs`) and the `jsx_*_ref` accessors in `markup/jsx_names.rs` were safe functions that widen a borrow or dereference any raw pointer they are given. They are now `unsafe fn` with a `# Safety` section, and every caller states its `SAFETY:` argument. No undefined behavior was reachable: every caller kept the program and header alive.
- `ScopeChain::get_scope_unchecked` had no caller in the repository and is deleted.
- `apply_scoped_css` compared `c as u8` with the open quote inside strings, so a non-ASCII scalar whose low byte is `"` or `'` (for example U+0122 `Ģ`) closed a CSS string early. That was a scoping-behavior bug, not a memory one: the output still copied whole scalars. Fixed: both scoped CSS scanners now take the string-body step in `css/string_body.rs`, which Kani checks against CSS Syntax for every scalar.
- Product unsafe blocks without a `SAFETY:` comment (`preserved_text.rs`, `raw_mode/unix.rs` `emergency_restore_raw_mode`, `corsa_session/paths/store.rs` and the N-API helpers in `js_value/raw.rs`) now carry one each. The `unsafe fn` declarations in `errno.rs` and the `GlobalAlloc` methods rely on their module or impl comment.
