# L0 runtime ownership (2026-09-30)

Decision for [#6833](https://github.com/ubugeeei-prod/vize/issues/6833).

L0 owns the existing artifact keys, Dump trait and scalar codecs, page parser,
collector and remark observers, pass planner/runner, fact registry/manager,
diagnostics and witness verifier. The unused placeholder APIs are replaced by
the implementations already exercised by the compiler. Source moves and the
`vize_l0_derive` rename are in a separate move-only commit. The derive now emits
canonical `::vize_l0` paths. This removes all eleven L0 skeleton modules and
21 `todo!()` calls; it adds no stage, serialization step, fallback or budget.

`vize_davinci` temporarily re-exports the exact L0 types and macro so current
consumers use the moved implementation. It still owns consumer-specific
Croquis/repro/feed pages, summary and renderer; #6833 is not complete until
those owners move, all active imports migrate, and the compatibility package
is deleted. The feed's existing JSON string escaper becomes a shared L0 helper;
its escaping bytes and remark field order remain unchanged. Reviewed storage
counts move with their implementations; the obsolete placeholder rows drop.

The foundation remains std-bound as accepted in the directory decision. This
change does not claim embedded no-std portability or complete #6834. Recorded
key hashes, dump/witness/diagnostic bytes and instruction ceilings retain their
existing contracts. Captured historical build stdout/stderr and oracle fixtures
remain untouched.
