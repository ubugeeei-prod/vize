# Original static Vapor modules and runtime acceptance

Tracking: [#6840](https://github.com/ubugeeei-prod/vize/issues/6840),
[#6839](https://github.com/ubugeeei-prod/vize/issues/6839).

The bounded target consumes only `NativeTemplateVaporAnalysis`, retaining its
moved original completion and deriving every output view from that same owner.
The sole L3 walk owns all eligibility, root order and fallthrough; L4 performs
one append-only encoding pass over those facts. It does not parse source, walk
an AST for decisions, reconstruct File values or accept raw source/IR pairs.

Every accepted original root has one static `template` declaration and the
complete exported render function returns its actual ordered nodes. The exact
Vue 3.6.0-rc.9 vocabulary supplies imports. Static helper flags 2/3 preserve
actual root attribute fallthrough; markup literals encode decoded nested text
and generic attributes once. Plain root Text uses the helper's raw text branch
rather than HTML escaping. Root text beginning with `<` refuses in L3. An
actual pinned hydration probe found that direct `createTextNode` would record a
fresh detached Text and throw during unmount, so the target uses the official
static helper and verifies hydration as well as mount/clone/disposal.

A target-neutral template assembler accepts linked static declarations before
its exported function; the existing empty-prelude wrapper preserves every old
module byte and link offset. Unsupported facts fail before any writer or module
is returned. A compile-fail law rejects generic diagnostic File analysis at the
public target entry; original lower refusals cannot grant completion.

Twelve frozen cases derive official syntax from the pinned compiler and retain
complete independent module/map oracles. Actual Rust tests construct the original
Descriptor-selected component and privately exhaust its genuine lower walk;
no handcrafted File is an acceptance fixture. They compare complete code,
helper sets, Recorded/NoLinks equality, every original byte anchor and the entire
map against an independent Source Map codec. Cases cover empty/text/comment,
proper nested and sibling HTML, attributes, quotes/backslashes, Unicode and
LF/CRLF/CR/U+2028/U+2029 source coordinates. The latter require the actual shared
source-map provider; this target does not duplicate its resolver.

The mandatory merge-group action runs those real Rust tests, requires all twelve
captured modules/maps, executes both entire native and freshly checked official
modules under the actual pinned browser runtime, and uploads nonempty module and
runtime captures. Trees include comments, namespaces and every attribute; root
fallthrough on/off, repeated clone identity and empty unmount are checked. Pinned
single-root hydration is included. Local frozen runtime execution is reported
separately from genuine hosted Rust captures. Missing captures fail instead of
silently replacing the denominator with frozen modules.

Ordinary lower whitespace/entity legalization, full HTML/dialect coverage,
dynamic effects/control-flow, prepared SFC script integration, the product's
fix-history #6880 and default compiler migration remain unfinished. No legacy
runtime helper, instruction budget change or reverse dependency is introduced.
The provider and target use a native GitHub Stack and require exact-head Actions,
protected full/instruction queue acceptance and actual merges.
