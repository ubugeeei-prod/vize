# Original Vue setup and interpolation type projection

Issue: [#6849](https://github.com/ubugeeei-prod/vize/issues/6849), with the
[#6879](https://github.com/ubugeeei-prod/vize/issues/6879) default replacement gate.

The L4 type target consumes the private native SFC admission receipt produced
by the existing `lower_sfc_native` route. This authenticates the complete
original descriptor, selected original Module Programs, once-parsed native
Component and expression observations, normally completed sole File, exact
source blocks and intrinsic JS/TS profile. The projection keeps that receipt
borrowed; detached strings, arbitrary ASTs and caller-paired Files cannot mint it.
L4 adds a normal dependency on the native L1-to-L2 producer, with no legacy
dependency or additional pipeline stage.

The first family supports setup-only JS/TS and scriptless literal reads. It
copies the complete selected setup Program unchanged, preserving comments,
JSDoc and actual language kind, then emits each genuinely resolved original
interpolation inside unlinked expression punctuation. This contract requires
complete original File semantics, not runtime compiler `VueSetup` eligibility;
it neither broadens that compiler flag nor asserts primitive-only syntax.
Ordinary scripts and ordinary/setup mixtures are refused because their distinct
original scopes cannot be faithfully concatenated. Styles, attached bindings,
components, slots and structured controls are refused until their type
semantics are complete. Source families refused by the original native SFC
provider, including typed declarations and terminal line-comment interpolations,
remain refused with their original observations retained.

Validation is fused into the normal canonical L4 emission traversal. Each
interpolation must consume the next retained native embed with its actual
NodeId, same original AST, exact decoded source/span, real recorded setup scope
and same-File visible bindings. Every embed must be accounted for; unsupported
operations refuse the whole document. There is no markup/Program/expression
reparse, second AST walk, reconstructed declaration list, generated context
binding or legacy generator.

The original prepared decoder segments produce complete emission links. The
diagnostic mapper delegates to the same retained source's covering projector;
endpoints inside an entity highlight its whole authored spelling, including
equal-length expansions, and are not edit selectors. Global UTF-16 conversion
rejects mid-surrogate positions and overflow. Invalid byte ranges, generated
punctuation and ranges crossing source owners return typed failures. A
nonrecording variant emits identical bytes and explicitly refuses mapping.

Focused laws cover complete JS/TS owners and original scope/AST identities,
cross-script/template absolute spans, Unicode/CRLF, decoder atoms, generated
boundaries, scriptless literals and whole-document refusals. The real configured
Canon consumer and complete TS7 diagnostic vectors are dependent work. Exact
source-built Actions, full protected merge-group validation, unchanged all-100
ratchets and actual merge are required separately. No default product route is
replaced; #6849/#6879 remain open.
