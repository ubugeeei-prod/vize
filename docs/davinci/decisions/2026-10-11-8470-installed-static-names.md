# Installed public Musea static names

The narrow delivery gate for [#8470](https://github.com/ubugeeei-prod/vize/issues/8470)
and [#8478](https://github.com/ubugeeei-prod/vize/issues/8478) is
[Released Musea static name acceptance](../../../.github/workflows/release-musea-static-acceptance.yml).
It independently accepts an official immutable C/H/source-PR/Release-R/tag tuple
and one fresh public Linux x64 consumer. This avoids delaying existing static-name
fixes for unrelated LSP, VRT or hosted-companion changes absent from the release.

The workflow authenticates the annotated tag, immutable source PR, successful exact-H
Release attempt and complete release-job census using the existing public observer.
It derives versions from raw H objects and copies all original colon/collision,
ordinary and example source bytes from H. The two complete native browser laws are
adapted at provider/path/type imports and additive serialized HTML fields. Every replacement is recorded;
original assertions, timeouts, selectors, six Self variants and async setup remain.
Exact public archives authenticate every installed Vize native/plugin file, including
the loaded Linux provider and actual Vite/Musea entry points, before and after execution.

The denominator is eight reported/ordinary static previews and six native Self
variants across defaults, globals changes and deep-link reload. Actual iframe Document
identity and setup counts prove that globals change without remounting. The additive
two ordinary colon previews preserve SHA-256 static URL identities, labels and scoped
CSS. Three browser laws must pass with zero skips. The workflow retains original and
adapted drivers, source fixtures, npm metadata/archives, HTTP bytes, whole DOM,
screenshots, failure details and exact provider receipts. Bash propagates failures
through tee; child-process failure, timeout or an incomplete denominator fails the run.
The first workflow push exposed a job-environment context rejection before any job
started. Initialize the evidence path from `RUNNER_TEMP` in the first bash step via
`GITHUB_ENV`; the parsed-workflow law rejects unavailable `runner` job-env expressions.

The original eight previews and the complete six-Self/globals browser law passed in
a fresh public v0.443.0 macOS arm64 review. That observation is local evidence, not
Linux delivery completion. A successful official Linux workflow run with its exact
tuple and retained receipts remains required before recommending these issues closed.
This observer grants no aggregate release, literal-object-key, VRT, hosted HTTPS
companion, LSP, complete platform matrix or broader n8n acceptance credit. Those
issues retain their independent terminal oracles.
