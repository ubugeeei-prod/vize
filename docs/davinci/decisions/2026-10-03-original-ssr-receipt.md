# Original selected-template SSR authority

Tracking: [#6839](https://github.com/ubugeeei-prod/vize/issues/6839), [#6840](https://github.com/ubugeeei-prod/vize/issues/6840).

A generic completed `FileArtifact` can retain a caller-supplied Text payload
that differs from its source. `NativeSsrFileAnalysis` therefore proves neutral
File completion only; it remains a diagnostic boundary rather than original
Vue output authority.

`build_native_ssr_file_decisions` consumes the genuine, non-cloneable lower
`NativeTemplateView`. Its private `NativeTemplateSsrAnalysis` retains that view
and the sole internally derived SSR analysis. The original selected Component,
completed File and source stay together. Neither a neutral File nor diagnostic
SSR analysis can construct this receipt, and neither the completion capability
nor neutral analysis can be extracted. Original immutable getters do not mint
another capability. The existing canonical decision walk runs once; there is
no reconstruction, AST prewalk, additional stage or caller eligibility flag.

The selected L1 owner retains a boolean derived directly from the authentic
Descriptor's style count during existing template selection. It survives the
Descriptor borrow and owner movement; comment/script lookalikes cannot mint it.
This receipt refuses every styled SFC before the decision walk with a typed
`StyledSource` error spanning the original whole source. This conservative
boundary is deliberate until actual original style/scope receipts are consumed
by SSR. A boolean does not certify CSS admission or scoped output semantics.

Five compile-fail custody laws, genuine original owner/order/cardinality/span
laws, original root/nested component-role refusal and authentic style metadata
laws cover this provider. Local Rust reruns are paused after shared disk
exhaustion; exact-head hosted Actions and protected merge-group validation must
prove the final source before actual merge. No prior green result is inherited.

L4 `emit_template` consumption, original complete module/map/runtime captures,
script generation, full source maps, dynamic/special/dialect families, whole
product parity and compiler history #6880 remain separate unfinished work.
The existing diagnostic SSR APIs and all default product routes retain their
current behavior. Neither #6839 nor #6840 is closed by this bounded provider.
