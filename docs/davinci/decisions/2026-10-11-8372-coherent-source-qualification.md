## 判明した失敗と修正

#8572 の `54b687a7`、#8574 の `0e9f0e4e`、#8587 の `dfab59e2` の全 Docs 検証は
失敗しました。日本語の Vue ルール一覧で、単独ページ用の設定見出しの ID を
3 回埋め込んだことが原因です。成功した一部の画像や本文検証を、全体の成功とは扱いません。

共通の埋め込み処理から、この単独ページ用の ID だけを除きます。
単独ページの ID、コード例の全文、Bad / Good のリンクと差分注釈は保ちます。
コードブロック内に同じ文字列がある場合も、その原文を保ちます。
一覧の重複 ID を拒否する既存の判定は変更しません。
修正前の失敗と、修正後の実際の SSG を使った desktop / mobile の判定を保持します。

## 全ページ検証と残る条件

新しい下段は 113 ルート・226 ジョブです。日本語ルールの既存追加を引き継ぐ中段は
115 ルート・230 ジョブ、Musea と Blacksmith を含む上段は 119 ルート・238 ジョブです。
以前の上段の全 114 ルートを元の順序で保持し、main に加わった 5 ルートも含めます。
本文・HTTP・コード・リンク・テーマ・フォント・レイアウト・全ページ画像の判定は保ちます。

新しいソースで Actions と全 Docs 検証を実行します。古いソースで成功した検証や、
失敗した検証の一部の証拠を、新しい実行の結果として使いません。
実行していない下段の全 Docs 検証を成功と呼びません。上段の結果を引き継げる範囲は、
元の入力・生成結果・検証の全文の一致と、変更された範囲を確認して別に記録します。

保護されたキューでの実際のマージと、配信後の本文・リンクの確認が必要です。
これらが終わるまで、396 ページ全体の受け入れ条件や #8372 を完了扱いにしません。
