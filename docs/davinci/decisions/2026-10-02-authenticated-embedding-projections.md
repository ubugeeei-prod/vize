# Authenticated fixed embedding projections

Tracked with [#6836](https://github.com/ubugeeei-prod/vize/issues/6836).
This is a native language-provider extension, not native On/For or product
replacement. The complete Program observation remains stock-configuration-only.

The pinned parser owns `EmbeddingInput`: original arena, original content
pointer/length, explicit Module profile, fixed language goal and ordinary
temporary CompactString. The exact existing wrappers are `(` + newline +
content + newline + `)` for Expr, the nonasync `()=>{` body wrapper and the
nonasync parameter arrow. No caller AST, parser result, replacement wrapper,
configuration, options or boolean can establish authority. Script, inferred
Unambiguous and declaration-file embedding profiles remain refused.

Preparation constructs ordinary temporary bytes. L1 retains the same31-unit
and expression-safety guards over those complete bytes before calling observe;
refusal does not promote a wrapper into the arena. `observe(self)` has no arena
argument: it promotes the same temporary text into the privately retained
original arena and invokes the default stock parser once. Default parse options
and actual source profile remain attached. All supporting OXC package identities
remain official fc702c1; the already pinned compact_str0.10.0 and oxc_ast_visit
packages become explicit normal dependencies of this one parser crate.

`EmbeddingObservation` ordinarily owns the entire ParserReturn, including
comments, diagnostics, module record, irregular whitespace, token vector and
fatal/Flow status. Recovery and local shape/context holes expose no admitted
projection while retaining all original observations. Existing Expr shape/span
checks and generated arrow boundary checks move here. The existing contextual
visitor moves here once for body/parameters; Expr gains no additional walk.
There is no extra parse, semantic pass, AST clone, serialization or stage.

The same visitor observes module declarations and formal Await with nested
parameter/body context save/restore. A bounded strict runtime-formal correction
rejects semantic binding values eval/arguments and implements/interface/let/
package/private/protected/public/static/yield. It masks erased TS annotations
and Signature formals; property keys and reference uses remain distinct.
Nested actual runtime formals establish their own context. This is not a full
semantic early-error engine, and the generic Parameters capability does not
establish duplicate-name freedom. Native Dense uses its canonical existing
binding enumeration and zero-ID duplicate preflight; intrinsic whole-head/file
association remains unfinished.

The three consuming methods accept only self. They move the selected original
Expression, FunctionBody or FormalParameters header into that original arena,
retaining every descendant pointer. The remaining complete parser owner stays
ordinary storage beside it, so real diagnostics drop normally. Wrong goals
return the whole original owner boxed before mutation; a local hole exposes no
recovered root. Short privately minted AdmittedExpression/AdmittedHandlerBody/
AdmittedParameters borrows expose shared selected syntax, original content,
derived parser window, actual profile and default options. Raw nodes or numeric
windows cannot construct a capability. Shared syntax does not freeze OXC's
semantic ID Cells or establish file/dialect/semantic identity.

L1 retains the whole private embedding owner in NativeSyntax. Its existing
comments, diagnostics, corrected spans and authored views delegate to that
owner. Consuming Expr now takes no allocator; RetainedExpression retains the
authentic ExpressionObservation and exposes its short admitted capability.
Program metadata remains separate and intact. The
[parameter handoff](./2026-10-02-retained-parameter-observations.md) consumes the
original ParametersObservation without an allocator argument, retaining its
explicit profile and full ordinary observations. Handler consumers must adapt
their actual whole-owner handoffs to the corresponding authentic projection;
they must not replace it with raw roots, status flags or tuples.

Meaningful laws pin temporary/no-arena admission, exact wrapper/content ranges,
original root and child/comment pointers, full diagnostics across recovery and
normal owner Drop, intact wrong-goal returns, actual nonfatal /uv rejection,
wrapper escapes, module/Await/strict-formal distinctions and decoded entity
identity. Privacy laws reject replacing private source, constructing projection
proofs, mutating admitted syntax or substituting an arena on observe/consume.
Scoped matching-cache source validation is not fresh complete Cargo acceptance.

The ordinary-owner Drop executable is a `harness = false` test, so it implements
the limited libtest protocol that nextest actually uses. Terse listing advertises
one `original_embedding_diagnostics_drop_before_their_arena` case; ignored and
nonmatching filters advertise nothing and do not execute its body. Exact and
substring selection execute the same original three-goal law. Listing never
initializes measurement or parses input. Unsupported arguments fail explicitly.
The measurement body, inputs, owner checks and allocation assertions remain
byte-identical. Direct executable controls include a negative fixture that must
fail when selected yet remain unexecuted during listing. A successful plain
executable invocation is not named nextest-worker evidence: hosted discovery and
actual selection of this advertised case remain required.
