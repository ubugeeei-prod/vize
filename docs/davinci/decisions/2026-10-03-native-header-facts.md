# Original selected header Fact provider

Date: 2026-10-03. Issue: [#6848](https://github.com/ubugeeei-prod/vize/issues/6848).

## Decision

Retain genuine original selected authored headers in the existing L0 Fact SDK
before implementing the Exact/Error `a11y/aria-unsupported-elements` consumer.
A lint-kind receipt alone cannot witness an Error. This additive opt-in provider
emits no diagnostics, changes no default route and does not close #6881.

`NativeSyntaxLint::header_facts` accepts only the authentic selected owner and
its actual element projection. Its non-Clone `NativeHeaderFacts` retains the
original owner, profile, source and element borrow. No caller can supply a tag,
source, ordinal, span, fact value, evidence artifact or classification. Original
recovery is refused before construction. Equal foreign owners are refused by
identity; detached compatibility projections do not establish admission.

The same complete strict-header iteration used by the three existing advisory
rules now supplies each actual `NativeAttribute` beside its checked binding.
It preserves full original authored ranges, actual attribute ordinals, static
versus typed Bind semantics, opaque values, original lint tag kind and inherited
literal header mode. Existing rule fixture bytes and full comparisons remain
unchanged. The private nonmatching binding now retains its already validated
range; it adds no parse, body walk, pipeline stage or serialization.

## SDK allocation and proof

Central `davinci/vize_l0/src/fact/ids.rs` allocates only these production IDs.
Existing IDs 1–15 and the fixture range beginning at 32 remain unchanged.

| Group                   | ID  | Stratum | Key                               | Dependencies          |
| ----------------------- | --- | ------- | --------------------------------- | --------------------- |
| `NativeLintHeaders`     | 16  | 0       | Actual original element ordinal   | None                  |
| `NativeLintAttributes`  | 17  | 0       | Actual original attribute ordinal | None                  |
| `NativeUnsupportedAria` | 18  | 1       | Actual matching attribute ordinal | Both preceding groups |

Each artifact is scoped to exactly one genuine header, so its original sibling
ordinal is an authentic scoped key, not a global node identity. Checked u32
conversion refuses instead of fabricating a key. The temporary sealed owned
observations are consumed into SDK tables, without an exported alpha form,
cache or serialization. FactManager computes the declared dependency closure.
Every view uses an actual `FactConsumer` demand; repeated reads borrow the same
immutable table.

The counterexample producer reads both original input tables through its own
declared `FactView`. Its exact authored rule contract is lowercase
`meta|html|script|style`, actual component exemption, and static/typed Bind names
beginning with `aria-` or exactly `role`. This bounded lint contract does not
claim DOM membership, runtime resolution or universal accessibility semantics.
No legacy semantic helper is invoked. Exact pre keeps literal directive heads.
Unsupported/dynamic/object heads, malformed modifiers, duplicate static names,
modified/argument-only pre and inherited template ambiguity refuse the complete
artifact rather than omit a real parser diagnostic.

A stored counterexample can produce only a causal original-tag → original-full-
attribute → derived-counterexample chain. Three registered `WitnessCheck`s use
the actual SDK verifier to re-read each exact group, key, span and verdict.
Nonmatching keys produce no chain. No Error is emitted until the dependent
consumer verifies its genuine chain before constructing `Diagnostic::proven`.
No fabricated witness, legacy exemption or severity downgrade is allowed.
