# 設定リファレンスと Musea の日本語レビュー

対象: [#8372](https://github.com/ubugeeei-prod/vize/issues/8372)

## 修正する内容

ルール以外の未レビュー表示だった 12 ページを、英語版と合わせて全文確認しました。
そのうち、設定リファレンスと Musea の 30 箇所を修正します。
コード例、設定の項目名、リンク先、製品の対応範囲は保ちます。

- 設定リファレンスでは、設定項目・重大度・共有設定とプラグイン設定の関係を明確にします。
  Musea のオプションを「美術館のオプション」と呼んでいた見出しも修正します。
- Musea では、Props、Style Dictionary、Storybook などの固有名を保ち、
  途中で文が切れていた機能説明と操作手順をつなぎます。
- VRT の手順では、「意図的な変更を加えず」という逆の指示を修正します。
  英語版と同じく、意図した変更を確認してから `--update` または `approve` で承認します。
  `--ci` の失敗条件、`new` の扱い、初回の更新、削除時の `clean` は保ちます。
- Blacksmith のベンチマークは生成元の日本語テンプレートを修正します。
  TypeScript バックエンドの状態と、意図的に加えた診断を使う検証の説明を日本語にします。
  バックエンドが使えない場合の公開拒否も保ちます。

読みやすかった Getting Started、設定、移行、Musea globals・hosting・snapshots、
Vite+ の 7 ページは変更しません。ホームページは既存の担当者が扱います。
UI styles の公開パスと Musea capture の言語別リンクは、この変更の範囲に含めません。

## 統合と残る条件

この変更は #8512 → #8572 → #8574 の後続層として扱います。
共有レンダラー #8566 と日本語リファレンス #8440 の実際のマージ後に、
各担当者が順に現在の main へ組み直し、最後にこの変更を引き継ぎます。
検証中の親のソースや PR 本文は編集しません。

実際のマージ後の親は #8574 の `0e9f0e4e2d79119a46ce9bbaaef07f8b27c9fbc1` です。
元の 31 箇所とコード・リンク・測定結果の保持に使う原文は変わりません。
共有レンダラーが追加した 5 言語の testing 検証も保ちます。

新しい正確なコミットで Actions と全 Docs 検証が成功するまで、マージ可能とは扱いません。
保護されたキューの実際のマージと、配信後の本文・リンクの確認も必要です。
396 ページ全体、生成ルールの残る対応範囲、ナビゲーション、公開サイトの受け入れ条件を
この限定修正だけで完了扱いにはしません。#8372 は開いたままです。
