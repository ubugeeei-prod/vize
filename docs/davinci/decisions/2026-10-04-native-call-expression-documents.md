# Original ordinary Call documents

Issue: [#6847](https://github.com/ubugeeei-prod/vize/issues/6847).
Paired decision: [original Call consumption](https://github.com/ubugeeei-prod/vize/issues/6847#issuecomment-5973093942).

The existing native retained-expression Doc provider gains ordinary
nonoptional Calls in its same immutable original Expr walk. The already merged
selected Vue 3 interpolation consumer receives those documents without a new
API or parse. The isolated `wt` starts from actual main
`ead89a7592e653a8ed585f4f3fed88fac71b3551`, after original unary/member
and mapped physical-gap prerequisites actually merged. This is independent;
no open-parent Stack membership is inferred.

The original Call retains callee, ordered arguments, optional flag, type
arguments, `pure` metadata and spans. Its callee starts at the Call start;
nonempty argument spans occur in order inside the original parentheses;
the closing parenthesis occupies the last decoded byte of the Call. The
existing typed-comment/ASCII-whitespace scanner checks original opening,
closing and separating punctuation. The callee is consumed before locating
its following opening delimiter, so its internal comments cannot obstruct
the original sequential comment cursor.

The pinned argument parser discards `parse_delimited_list`'s trailing
separator. Consequently, trailing-comma custody comes from the same checked
source scan, not argument count or an invented AST field. A private optional
token result preserves a genuine authored comma; its absent case still
requires the complete suffix to contain only checked original comments and
ASCII whitespace. Literal comment punctuation never supplies a comma.
Required tokens retain their previous missing-token refusal. No new scan
stage, classifier, visitor or AST pass is introduced.

Plain proven gaps normalize to `callee ( )` or `callee ( a, b, )`, preserving
whether the authored trailing comma exists. Call punctuation adds no layout
breaks; supported child infix groups may break. Original callee parentheses
retain reference shape, including `eval` and member callees, without semantic
rewrites. Literal and complete entity spellings, typed comments and mapped
authored physical LF/CRLF gaps remain borrowed through the existing checked
source projection. Generated line endings are independent of authored ones.

Whole literal-output fixtures cover empty, ordered, nested and chained Calls,
member/computed callees, numeric/string/Unicode arguments, original callee
parentheses, commas, typed comment gaps and encoded punctuation. Genuine
selected Descriptor laws retain encoded-quote literal slashes and physical
LF/CRLF, with full interpolation outputs at widths 0/1/7/80/200. Re-selection
and actual JS/TS reparsing compare independent Call fingerprints, including
optional/pure/type-argument presence, callee shape, ordered children and
complete original literal/comment bytes. Fixed points preserve the complete
output. Original callee/argument/comment/map/content and owner addresses are
checked separately.

Whole refusals cover optional/Chain Calls, TS type arguments, Spread,
unsupported callee/argument descendants, foreign roots, syntax holes and
unproven non-ASCII gaps. The depth-16 Doc limit and L1's 31-unit guard remain
unchanged: twelve unary prefixes plus four nested ordinary Calls reach 16;
thirteen prefixes plus the same four Calls remain genuinely L1-admitted and
reach the Doc refusal at 17. Old native Call-only negative fixtures now use
real unsupported Spread descendants, alongside independent new positive
whole outputs. Legacy history and differential scripts remain untouched.

Fresh source-built exact-head Actions and the actual final protected
candidate's full/instruction gates, followed through signed actual merge,
are required. Frozen fixture sources and original raw receipts are retained;
uncompiled fixtures receive no runtime credit. No local build/install,
additional manual full campaign, legacy helper, oracle change, budget
expansion or shipped-route replacement is used.
