## Existing original event

The normal Program statement walk already owns a genuine function declaration,
its actual child scope and formal-parameter bindings. It previously refused
every original parameter annotation. At that same parameter event, accept only
the seven existing reference-free TypeScript keyword forms: bigint, boolean,
null, number, string, symbol and undefined. The original TS/TSX Module and
default ParseOptions must already pass `ProgramInput::checked`. Both the
original annotation span and inner type span pass the existing authored-source
projection before the actual Parameter binding is declared.

The private boolean predicate reuses the unchanged keyword match; it creates
no annotation row or erasure receipt. There is no new parse, AST visitor,
namespace walk, source scan, pipeline stage, serialization or source buffer.
The actual original Program, comments, complete source and source/profile
authority remain unchanged. A keyword without type or value references needs
no invented namespace resolution.

The existing event's `exported` flag means a directly exported declaration.
Only the new typed-annotation path refuses that flag. Untyped
`export function f(value) { return value; }` retains its genuine binding,
export and reference behavior. A later `export { f }` uses its unchanged
separate original export event; a preceding typed function can remain complete.
This is not a whole-program export classifier and adds no second scan.

Every existing function restriction remains: async/generator/declare, nested
function declarations, return annotations, generics, this/rest parameters,
optional/default/decorated/accessibility/readonly/override parameters, patterns,
reference-bearing or other type forms and unsupported body statements still
leave the actual File incomplete. Script/definition/nondefault-parser/copied
source profiles remain refused. Imported, ordinary and default-export behavior
is unchanged.

## Independent authored laws

Eleven new source-authored laws preserve the exact former
`function f(value: number) { return value; }` input as the deliberate new
positive boundary. Only that entry leaves the old negative list; every other
old negative source and expected assertion remains intact. The laws check all
seven original keyword kinds, actual Parameter/unit/function scope, value
namespace, authored identifier spans, recursive/forward references, sibling
shadowing, Unicode/CRLF/nonzero source origin and original Program/comment
pointers. A real TSX owner retains its authored fragment and complete original
File; no fabricated JSX receipt or raw Program substitutes for it.

Complete original negative issue vectors retain unsupported parameter and
unresolved body-read sites. Direct typed export refusal and later export
completion have distinct laws. Other parameter/function/body/closure and
unsupported sibling families retain original observations and typed issues.
The existing five real observer interruption points now also exercise a typed
original input; all old source bytes and assertions remain, with whole-unit
interruption preventing completion or retry after unwind.

The unchanged statement event rejects whole-unit setup and ordinary eligibility
before entering any function. Genuine Descriptor/Program/File laws require
`VueSetup::checked` to refuse the otherwise complete neutral typed function.
The original selected setup cursor refuses before consuming an interpolation;
its actual Program, source span and parameter facts survive. No typed parameter
grants `SetupAnnotation`, runtime erasure or template visibility.
