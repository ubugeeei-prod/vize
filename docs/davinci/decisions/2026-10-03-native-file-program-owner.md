# Source-owned File Program semantics

Paired decisions: [#6838](https://github.com/ubugeeei-prod/vize/issues/6838)
and [#6844](https://github.com/ubugeeei-prod/vize/issues/6844).

The neutral File owner and its genuine JS/TS language producer ship together.
The completed owner contains the exact canonical artifact and privately built
unit, declaration, namespace, scope, import, export and use records. Borrowed
binding/expression handles retain that owner; numeric indices identify rows
only within its namespace. No caller-provided declaration list or raw node
association establishes file facts.

ProgramInput requires the original stock parser's opaque AdmittedProgram and
the exact full-file SourceBlock. Source, requested profile and parse options
come from the actual observation. Equal text in foreign storage, nondefault
options, requested Unambiguous profiles and partial source frames are refused.
The real nonfatal `/x/uv` recovery cannot provide admission. Public custom
parser configurations retain ordinary parsing and cannot mint that authority.
The original Program/comments/ordinary-owned diagnostics remain in L1; the
short consumer borrow never reparses or transfers them into a sibling owner.
L1 is only a dev dependency in this slice; normal dependencies remain native
L0 and the same pinned OXC AST/parser/span universe.

The existing statement/declaration traversal consumes original retained AST
events. Each supported expression delegates once to the shared reference
resolver. Transactional sink checkpoints roll back both reference and observer
records after unsupported syntax or callbacks. The existing unit-close row
resolution handles forward names, exports, read/write roles, shorthand and
constructor uses. It adds no Program, expression, tree or seal walk, pipeline
stage or serialization.

Plain named synchronous function declarations introduce genuine parent
declarations and private child scopes. The original parameter enumeration and
body traversal retain dense identities, authored spans and lexical parents;
sibling restoration follows the short child borrow. Parameters and locals
cannot be treated as top-level template bindings. Async/generator functions,
typed/default/rest/destructured parameters, annotations, body directives,
nested functions, classes and unimplemented statements remain typed refusal
families. Unresolved names never receive invented context/global IDs.

Each actual unit starts with a private inline Pending walk state before its
first observer callback. Normal closure alone marks Complete; stack guard
destruction changes Pending to Interrupted by safe access to the owned row.
Drop allocates nothing, calls no observer and mutates no issue vector. Pending
and Interrupted units prevent completion. Typed interrupted-program queries
derive the genuine stored unit/span while the original syntax issue slice stays
unchanged. Caught unit/declaration/statement/parameter/call panics preserve
partial facts and the original artifact source.

Diagnostic-only public observers expose borrowed events and no mutable Facts,
binding IDs or admission setters. The lower template factory records actual
minted nodes with their complete retained tables and lexical scopes; it grants
no native Component/SFC, Vue role, runtime-access or control authority. Whole
template-driver interruption, native custody, intrinsic profile, authentic
exposure and indexed conditional/For facts remain dependent delivery layers.
File completeness means completeness of the admitted unit family; omission of
a source block is not detected by a neutral builder and cannot establish whole
SFC admission.

Current direct proof compiles the complete actual L2 library and tests against
the actual Shared parser/L1 artifact in one retained 068/700/816/ea545 metadata
universe. It executes 56 library laws and 30 File fixture laws with zero ignored,
including four real parser-admission laws and five observer unwind points.
Strict production, complete test-source and all six owning fixture checks pass.
The first-unit allocation target compares identical fresh process setup with a
preowned panic payload: baseline=1 and guarded=1. Terse list discovery prints
only its real case, ignored discovery prints nothing, and exact selection runs
the unchanged measurement. Historical allocating and plain-main failures stay
preserved; scoped cached evidence is not fresh Cargo or hosted acceptance.

Owned storage rows, source inventory and generated ledgers are updated without
changing allowances. Actual metadata, full Actions, all fixed instruction and
allocation ceilings, native Stack membership, protected queue and terminal
merge remain delivery requirements. Product routes, legacy output and all
performance budgets retain their existing contracts. Full Vue dialect, macro,
runtime exposure, JSX/TSX semantic admission and product acceptance are TODOs.
