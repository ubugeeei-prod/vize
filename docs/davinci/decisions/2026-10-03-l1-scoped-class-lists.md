# Original CSS class-list receipts

The next bounded scoped slice reads the actual original qualified-rule tokens
already retained by StyleSyntax. A private SimpleClassListStyle receipt proves
at least two simple classes separated by genuine comma tokens in that same
complete rule. Its insertion iterator borrows each actual classname token end;
no supplied offsets, copied selector, source scanner, new parse or normalized
AST grants authority. The original descriptor, complete style source, parser
errors, tokens and declarations remain unchanged.

The first list profile keeps literal original classname spelling and permits
separator whitespace only after a comma. Leading comment/whitespace trivia
and final whitespace before the rule brace remain original. Escaped list names,
pre-comma whitespace, comments between selectors or after a classname, empty
members, pseudos/combinators/attributes and mixed selectors refuse the whole
receipt. Existing single-class receipt behavior is unchanged. The complete
one-rule/flat-value parser refusal remains authoritative before list admission.
Its actual quoted-token binding/comment-marker refusal also applies before
any list receipt, retaining the original error and partial declaration data.

The pinned Vue audit supports insertion-only `.a,.b{...}` and
`.a,\r\n .b {...}` bytes. It removes whitespace before commas and places scope
attributes after trailing selector comments. Those unproven normalization
families stay typed refusals rather than source edits guessed from raw text.
No generic stylesheet iterator replaces the existing strict parse_one_rule:
StyleSheetParser skips an initial charset rule, and RuleBodyParser skips stray
closing braces. A broader stylesheet owner needs its own complete original
custody proof.

Provider laws bind every insertion to original parser tokens/full-file Unicode
and CRLF coordinates, complete retained rule/declaration data and move custody.
Malformed/normalized/mixed selector lists, actual parser failures and wrong
boundaries retain complete original source with no partial receipt. The new
provider lends borrowed iterators and adds no production owned allocation.
