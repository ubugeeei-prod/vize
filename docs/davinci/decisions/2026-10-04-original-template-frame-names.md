# Original outer-template frame names

This bounded L1 provider implements the original frame prerequisite for
[#6837](https://github.com/ubugeeei-prod/vize/issues/6837),
[#6871](https://github.com/ubugeeei-prod/vize/issues/6871) and
[#6883](https://github.com/ubugeeei-prod/vize/issues/6883). Publication, exact-head
Actions, unchanged protected instruction gates and actual merge remain required.
It supplies lexical descriptor names, without Component grammar, a native File,
Maestro admission, full-session history credit or a default product replacement.

## Original authority

The sole existing `scan::close_at` checks literal `</`, the original opening name
with ASCII-insensitive equality, optional post-name ASCII whitespace and `>`.
Only that successful event creates private `MatchedClose` with the actual name
span. `find_template_close` forwards only the original match that reduces the
template depth to zero. Original nested templates, quoted attributes, comments,
interpolations and raw-tag bodies retain their existing boundary behavior.

The same original `split_with` callback forwards this match beside the existing
uncertainty and self-close flags. `Policy::record` measures opening geometry
from the already-produced original `Block.name` pointer through the whole root's
`span_of`. Only the existing private template role stores the scalar pair;
script/style role storage and public `Container`, `Block` and attributes are
unchanged. Original whole closing spans and capture serialization stay exact.

A public capture, caller coordinates or a later scan cannot create the pair.
There is no new parser, AST/CST walk, table, heap allocation, pipeline stage or
serialization. Checked u32 geometry uses the splitter's existing source-size
guard. No instruction improvement or exemption is inferred; all 100 general and
four formatter ceilings, repeated three times, retain their immutable limits.

## Public receiver and source custody

`TemplateView::frame_names` borrows `NativeTemplateFrameNames` from the actual
admitted descriptor, actual template selection and its retained name pair.
The receipt exposes authored `opening` and `closing` spans, the whole-root
`source_block`, the original `container_index` and the original `template` view.
`accepts` requires descriptor and actual selected-row pointer identity. Equal
contents, identical indices or a second parse of the same source allocation
cannot grant membership. Public receipt/view fields and constructors stay private.

The two nonempty half-open UTF8 names exclude delimiters and whitespace. They
lie outside the selected template content, so validation uses the original whole
root and retained original opening/closing extents. Those extents validate the
recorded names; they never supply inferred name geometry. A missing pair or an
invalid source join produces `IncompleteBoundary` or `SourceMismatch`.

Descriptor admission still refuses missing, uncertain, self-closed, duplicate,
external, unsupported-profile and uppercase-opening input. An original
self-closing capture keeps its `Some(empty closing span)` compatibility value
and has no matched closing name. Closing case remains authored: an admitted
`</TeMPLATE >` supplies those exact bytes. A later linked-editing consumer must
require identical endpoint spelling rather than normalizing this provider.
Whitespace after slash and a longer closing-name suffix remain refused.

The receipt borrows normal descriptor/arena/source owners. No static lifetime,
unsafe self-reference, shared handle or copied owner is introduced. Normal owner
moves followed by reborrowing, repeated opposite-order reads and ordinary drops
retain original custody and allocate nothing during queries.
