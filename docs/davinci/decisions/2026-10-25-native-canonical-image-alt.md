# Shared native canonical image-alt query

Issue: [#10563](https://github.com/ubugeeei-prod/vize/issues/10563).

`NativeCanonicalLint::img_alt` is an explicit query over the genuine admitted
Vue `NativeSfc` File or same-Program JSX/TSX `JsxMarkupFile`. A detached File,
caller span or compatibility tree cannot construct that capability. The query
makes one canonical page traversal and interprets attribute presence, without
parsing expressions, decoding source or repeating frontend rule implementations.

The registered rule, original-header native entry and canonical query share one
image/alt presence policy and immutable localized message selection. Existing
registered and original-header range adapters remain authoritative for those
representations. Canonical findings use the genuine element's full authored
span, preserve Warning/Surface/help packets and have no labels, witness or fix.
Catalog selection happens at most twice per positive canonical query and zero
times for a clean query. Every returned diagnostic owns its text.

Static alt names count regardless of the attribute value, including empty and
bare attributes. The Vue producer also admits simple statically named bound
attributes with self-contained values; the query does not evaluate their
expressions. Unresolved external value references remain a File admission
refusal. The current producer refuses modifier/dot/same-name binds, dynamic arguments,
object spreads, unknown directives, v-pre and invalid expressions before a
canonical lint context exists. JSX dynamic values, spreads and entity
normalization retain their typed whole-view producer refusals. These are
boundaries, not passing native-rule observations.

The query defensively refuses every component op. A semantic component name cannot
prove the authored tag: `<img is="vue:Other"/>` has a non-image component name
after normalization. Conversely, `<div is="vue:img"/>` must not invent an image
diagnostic. Supporting those shapes requires an original-tag IR fact; this
slice does not change the producer layout. The current genuine Vue File already
refuses the tested component shapes at File admission; these tests establish
producer refusal, not execution of that defensive query branch. Non-HTML image
namespaces also refuse. A late markup comment discards all pending findings.
Original Program comments refuse JSX context construction, including comments
whose empty containers disappear from the canonical page. Configured
suppression handling remains a separate host responsibility.

Ordinary integration laws compare full registered-rule packets on actual Vue,
JSX and TSX owners, including all three locales, both quotes, LF/CRLF, Unicode,
nonzero source blocks, whole paired-element ranges, catalog lookup bounds and
repeat equality. The compatibility route is an oracle, not native ownership.
Outputs are checked after the original owner's arena is dropped. Refusal laws
retain the actual failed producer or admitted File without fabricating nodes.

The `native-image-alt-query.yml` source workflow builds the original-header
observer byte-for-byte on the immutable base and head, then compares its entire
diagnostic packets. Compiled Cargo targets are fresh and isolated by each
immutable source SHA, with actual compiler-artifact source paths, package IDs,
freshness and production source hashes retained. Only registry/git sources may
reuse a download cache. Both runs use genuine L1 `NativeTemplateComponent` owners
and include the same original child iteration. The new canonical observer
reports absolute query phases separately for actual Vue, JSX and TSX owners;
there is no trusted conversion between these private owner families. Each
observer reports nine 500-call samples after preparation and warmup, in the
same optimized profile, with result destruction outside the measured phase.
Source timings cannot establish a cross-representation or whole-product ratio.

The configured linter route is unchanged. This adds one bounded native consumer;
it does not admit all Vue syntax, add a Pug producer, establish whole-product
equivalence or complete #6848/#6871. Source qualification, protected delivery,
publication and fresh registry-consumer acceptance remain separate evidence.
