Ordinary opt-in SFC compilation remains unavailable. The existing original
parser already retains the default keyword, complete export statement and
declaration ranges in its real `ModuleRecord` export-default event. The AST
declaration alone does not retain the keyword range. A source scan, reparsing,
caller-provided coordinates or new span storage is unnecessary.

`AdmittedProgram::sole_default_export` borrows exactly one actual local
`ExportExportName::Default` entry, its original keyword span and the same
complete original observation. Named-as-default, type-only, indirect, star
and multiple entries refuse. Checking the existing slices is constant-time;
there is no new AST/source walk, parser stage, buffer, serialization or normal
parser storage/layout change. The private non-clone receipt keeps its original
Program/source/profile/options owner alive after ordinary observation moves.

This is original syntax custody only. Imports, other statements, functions,
classes, nondefault parse options and original legacy-literal facts can still
exist beside a genuine sole default-export entry. This projection does not
certify a direct empty object, strict-module semantics, complete File eligibility,
Vue roles, runtime output or product replacement. In particular, the stock
parser deliberately omits duplicate-export diagnostics in TypeScript; matching
exactly one local entry prevents those duplicate defaults from granting this
bounded receipt without changing the parser's diagnostics.

Five original-parser laws cover JS/TS UTF-8 and CRLF coordinates and direct AST
joins; exact original entry/keyword/Program/comment identity across an owner
move and a foreign parse; original profile/options and strictness boundaries;
named/indirect/star/type/multiple-entry refusals including admitted TS duplicate
defaults; and recovered/escaped-keyword/JS duplicate syntax refusal. Three
compile-fail docs cover private construction, cloning and dropping a live
original observation. Fresh configured source Actions must execute these laws
and doctests; protected full suites and all 100 unchanged instruction ceilings,
followed by actual merge, remain required. No local Rust build or installation
supplies validation credit.

The next genuine dependency is a distinct L2 ordinary empty-component proof.
It must join this same parser receipt to the direct empty `ObjectExpression`
in the existing sole export-default event, reject all other nonempty statements
with a sticky original-unit fact, and authenticate the same original Program,
source/profile, sole ordinary unit and uninterrupted complete File. Borrowing
the existing parser record avoids a new Facts pointer, Box or span mirror; its
separate eligibility bit must preserve the measured ScriptUnit layout and all
unchanged budgets. Actual runtime maps/output cannot consume a bare-object
source inference.

preflight currently blocks every staged `UnsupportedOptions`; a later narrow

until complete-File finalization. NativeTemplateOwner rejects every export;
its later exception must use the same opaque completed-script proof and keep
