## Original authority

NativeTemplateComponent::observe_text_value receives the actual NativeChild
at its original root or Element child event. Private Origin verifies the same
selected Component, actual SurfaceChild::Text, full original Token, direct
parent allocation or root, ordinal, template index, intrinsic JS/TS grammar,
complete SourceBlock/root/slice and checked authored span. It retains immutable
arena addresses, never a movable selected-wrapper address. No caller source,
span, raw token, allocator, EmbedSource or profile can mint the receipt.

NativeTextValue normally owns the entire original Token and complete EmbedSource,
including every decoded segment. A short admitted_for join authenticates that
same original child, source, parent and ordinal without decoding or iteration.
Equal reparses, copied roots, same-byte sibling events and foreign parents cannot
substitute. Parking/growth and moving the original selected wrapper preserve
backing identity. into_source consumes the receipt and drops its child authority;
the resulting ordinary source/map is only neutral coordinate evidence.

The declared profile is General/Text-context source preparation. It does not
claim the lexer's actual Data mode, whitespace policy, namespace/tree legality,
whole Component/File completion or target output. The existing private
prepare_text_value executes once at the actual child event on the entire
authored window. It uses the existing text-context entity decoder and complete
map builder, with no subsequent decode of reference-looking output.
The existing lexer may already recognize/decode callbacks while its recorder
retains raw text; this change does not claim one decoder invocation across the
whole parse. Preparation still performs the decoder's existing byte work; no
hidden constant-time claim, extra stage, scan, parse or legacy dependency is added.

Reported recovery/unsupported observations, missing/empty text tokens and actual
missing parent frames refuse before preparation. Conservative ASCII-insensitive
authored script/style names refuse as RawTextParent; title/textarea refuse as RcDataParent.
The lexer enters its special family through lowercase first and second name
bytes; later sequence bytes are case-insensitive. Uppercase-first/second original
controls remain conservative name refusals, not proof of an actual RAWTEXT/RCDATA
lexer mode. Lowercase-first-two mixed-case controls are retained separately.
The retained peer premise correction is paired on
[#6836](https://github.com/ubugeeei-prod/vize/issues/6836#issuecomment-5979151833)
and [#6838](https://github.com/ubugeeei-prod/vize/issues/6838#issuecomment-5979151992).
The original inherited opening-tag verbatim fact refuses v-pre descendants.
No ancestry traversal or new lexer context metadata is introduced.
Pre, namespace and table examples can retain source-only preparation without
claiming their whitespace, tree or target semantics. Literal whitespace/CRLF
and decoded whitespace remain exact: there is no trim, condensation or omission.

NativeTextValueFailure normally owns the precise typed refusal plus the actual
child's complete original block/token/ordinal/parent spelling. For a foreign
child it retains that child's source, not the rejected selected source.
The selected Component continues to own all original tree/parser observations.
No failure manufactures a prepared value or admitted join.
