## Original selection and one reused decomposition

`NativeTemplateComponent::observe_attribute_head` receives the actual current
`NativeAttribute` from `NativeElement.attributes()`. Its short sealed
`NativeAttributeHead` retains that attribute, the selected owner, an exact
original name SourceBlock, one Vue directive decomposition and its conditional
selection. Its fields are private; no raw-parts/source/flags factory, Clone,
caller profile or File insertion is available. Readonly copied typed parts
are metadata and cannot create an original header proof.

The factory preserves existing foreign, recovered and verbatim precedence,
checks the original token's name window and performs no value preparation or
JavaScript parse. Plain attributes and valueless directives remain valid head
metadata. Malformed name parts are retained; source/DirectiveNameError failures
stay precise. In actual selected parsing, a directive-capacity failure is already
retained as a complete `DirectiveAdmission`; original preflight still refuses
RecoveredComponent before any later head observation. Do not replace that
earliest owner with an invented direct directive error.

`head.observe_expression()` uses only its genuine complete `v-if`/`v-else-if`
selection. Unsupported arguments/modifiers/nonconditional heads refuse without
preparing a value. Both the new route and the unchanged public conditional
observer share one original preparation/stock parse tail. The old route keeps
its original check/source/decomposition/selection/value order. The new route
does not decompose the retained head a second time. Existing parser pre/lint
classification, Origin joins, value/event/for routes and grammar limits are
unchanged. Separate public observations remain possible; no global once receipt
or counter claim is made.

The normally owned `NativeAttributeExpression` retains original source/maps,
intrinsic JS/TS Module grammar, full syntax holes/comments/diagnostics and exact
header origin. Consumers park it in normal owning storage before admission or
projection failure and join it against the actual selected/current attribute;
this Drop-bearing observation cannot live in the no-Drop arena. The short head
must end before moving its borrowed owner and cannot make that owner a movable
self-reference. No new decode/parse/AST walk/visitor/stage or legacy production
dependency is introduced.

## Authored controls and exact acceptance

The added source laws use actual Descriptor selection and original headers,
independent complete source/decoded bytes and authored geometry. They cover
typed plain/static/dynamic heads, nonzero Unicode positions and ordinals,
old/new intrinsic grammar and original AST/map/comments, physical LF/CRLF,
entity-context spelling, empty/syntax/admission holes, foreign/sibling/copy
joins, short-view ending, moved/parked/dropped owners, missing values and
original recovery/verbatim/unsupported capacity precedence. The original
operand/event/for/value controls remain unchanged. Raw-field construction,
Clone and escaping the selected borrow have compile-fail controls.

The actual 31-unit wrapper admission precedes the expression guard: an over-cap
parenthesis input remains TokenBudget, and the separately authored small
unbalanced expression tests SafetyAdmission. Neither changes an admission cap
or substitutes a cached observation for executed proof. The storage inventory
records only actual new test storage; production head selection adds no heap
owner. The canonical consumption matrix remains source-checked.

Private source review and formatting give no runtime credit. Exact-head affected
Actions, all existing controls, protected full suites and 104 unchanged ceilings,
then actual signed merge are required. No local Cargo/npm/build/install, repeated
manual campaigns, input/output recapture or ceiling increase is authorized.

## Genuine formatter consumer remains unfinished

The actual scriptless SFC product merged as signed `aae579abe676` after full104,
238 native and 29 whole laws. This provider adds no new formatter success,
L2 File legality, target semantics, historical-profile product or native300/default
replacement. Vue2's separate original borrowed-expression Doc owns its private
Context/Origin/callback/export work; this source edits none of those paths.

A future explicit conditional-enabled Glyph receiver must retain authentic
NativeElement/NativeAttribute and reuse this head at its same existing visit.
Before decomposition, negative original recovery/verbatim routing preserves
the old lower native static/strict/opaque policy and earliest refusal order;
there is no opaque fallback after conditional failure. Check/subtract the actual
selected block start only for template-local name-layout error offsets; actual
head/value/Expr spans remain authored-file absolute. Keep normal owning
observations before every admission/projection/layout failure, exact prefix and
untouched suffix, and freeze complete whole output/options/error/AST/comment/
fixed-point/lifetime controls. Public strict/opaque policy widening, handlers,
for/bind/slot/scripts/styles, older whole profiles and native/default/printer
completion remain unfinished. A dependent consumer needs real provider APIs and
verified native Stack membership, current source/protected proof and literal
delivery.
