# Released typed prop defaults consumer

Tracked in [#8564](https://github.com/ubugeeei-prod/vize/issues/8564), whose
correction merged through [#8565](https://github.com/ubugeeei-prod/vize/pull/8565).
The source controls and differential fixture already exist. Closing the report
also requires observing the actual published CLI with those same expectations.

The development host is macOS. A dedicated read-only Actions consumer provides
the Linux runtime for the original GNU release archive. It uses a reviewed main
observer and immutable released H fixtures; the new observer is not required to
exist in the older product source H. It builds no product and changes no release
publisher or other public consumer campaign.

The dispatch fixes C, H, source PR, Release R and tag. The existing public GitHub
verifier checks the annotated pin fields, original source markers, terminal
successful R and complete job inventory. The consumer additionally verifies
H directly versions C and contains the actual #8565 merge. A pending Release,
changed cut, foreign source or mismatched public tag cannot execute the CLI.

The consumer downloads exactly one official x86_64 GNU archive and its sidecar,
checks both GitHub digests and the exact checksum line, and requires one regular
executable ELF member. Extraction happens in exclusive RUNNER_TEMP paths outside
the checkout. Every invocation uses the same verified public binary; runtime
override variables, repacked archives, symlink members and foreign binary paths
are refused. No Darwin or source-built substitute supplies acceptance.

The original H owns all fixture bytes and whole expected diagnostics. Their
original SHA identities include the unchanged 51-rule n8n projection. The
consumer retains every original 56 typed-default scenario and the previous
80 + 144 default/migration scenarios. Each of the 280 processes records complete
stdout/stderr bytes, status, signal, expected and actual JSON, source/config
immutability and loaded binary digest. Mismatches remain failed packets; counts
alone do not establish correctness. The source tests use inert custody and
archive controls; they never count as installed public product observations.

`1528ac699262a415e59531c2c2b1a22db7c4b3fc`. Querying a tree through a commit

`c8229d74dcb6a981535d31e69bc7840afa3a964dcfd6f1d892b59da7d55fa0da`;
