with the compiler decision record. The reporter's complete App and Child,
including their TypeScript annotations and three emitted events, are retained

## Existing production boundaries

The existing whole-expression function classifier parses its single expression
as TypeScript, recognizing an authored typed arrow or function instead of
wrapping it as an inline statement. Its complete-expression and nesting guards
remain in place. Callable-reference classification retains its existing
JavaScript parser mode. Retained JavaScript shape checks remain unchanged.

Static component `v-on` keys use the existing shared `create_on_name` helper,
which camelizes and capitalizes the authored event name. The key keeps its
original source location and handler metadata. Dynamic event keys, object
listeners, native DOM event spelling, modifiers, handler values, and lazy
component property getters keep their existing paths. No pipeline stage,
serialization, dependency direction, budget or backend default changes.

## Complete source and runtime laws

One existing-workspace Rust test target compiles the original pair and three
authored controls: VDOM, typed return/function handlers, and a component with an
object prop spread. Both complete SFC modules are passed unchanged to the normal
TypeScript loader. The actual Child is evaluated before the parent; no child,
handler, emit function or runtime helper is replaced with a mock.

Development and production each exercise both requested inline and separated
outputs. The unchanged production Vapor policy already forces script setup to
inline its template; these are request cells, not two distinct production Vapor
outputs. The independent official compiler reference uses complete inline SFCs
in every cell. The locked compiler and real client runtime are 3.6.0-rc.9;
the reporter's 3.6.0-rc.10 comparison remains separate.

All 16 request rows compare both mounted components against fixed full trees,
the ordered log text, stable button/paragraph identities, empty diagnostics,
and complete unmount. Both clicks execute the original child event sequence.
The 32 whole map-on/off result pairs may differ only in the map field; mapped
source names and full source content are required. Raw map fields and complete
official modules/bindings/maps remain in the packet. This does not assert
decoded mapping coordinates or template-map semantic accuracy.

Rust saves complete source/results and Git head/tree/parent before launching
Node, then retains original exit status, stdin-write failure and both raw
streams before runtime assertions. Node preserves progress, partial observations,
failed HTML/diagnostics and cleanup failures without turning a failure into a
pass. Evidence is retained beside each existing Actions JUnit artifact.
