## Decision

An otherwise complete neutral `FileArtifact` does not prove original Vue
template custody. The lower `NativeTemplateFile::view()` capability is minted
only after its internally created File producer and selected original root
cursor finish normally. It keeps the original selected Component and File in
one owner. A caller cannot replace that association with equal source bytes,
numeric ids, a role, a completeness flag or a detached File/Component pair.

`build_native_dom_file_decisions` consumes that non-cloneable
`NativeTemplateView` by value. It derives the File internally and invokes the
existing `build_dom_file_decisions` once. The result privately retains both
the moved completion view and the existing sole-file analysis. Its read-only
getters expose the original lower owner, File, artifact, policy, decision
tables, DOM facts and checked expression rows. It has no neutral analysis
extraction, public field constructor, conversion or clone.

The existing canonical `NodeEvent` traversal computes all decisions. The
entry adds no AST or tree walk, pipeline stage, serialization, binding list,
runtime vocabulary or purity/access classification. It adds no owned vector
or new side table; the completion view borrows the actual combined owner.
