character or a resolved Vue-file import and returned before querying the native
checker. This admits the reported readonly tuple and plain state object.
The repair retains the existing tag inventory and item serialization and uses
Vue's actual exported `Component` type to reject only known incompatible
candidate bindings.

The tag route reuses its one existing Croquis analysis. Recorded authored
binding spans must equal the identifier bytes, then the existing canonical
source mapping must identify the same generated identifier. Absolute checker
positions use UTF16. The actual value-import module symbol must be a module,
its unique `Component` export must resolve to a known type, and all source and
target handles belong to one acknowledged native snapshot and selected project.
Full snapshot source text and the complete project descriptor must match before
type relations are queried. Every temporary snapshot is released while its API
owner is alive; errors or missing/any/unknown evidence retain the old fallback.
No additional parser, backend process, SDK adapter or level stage is introduced.

The five original source/config/body pins are separate from the newly authored
whole completion vectors and control SFC. The new source-built law prepares
47 complete RPC responses in six sessions, including the original five queries
on LF/CRLF, disabled type checking, Vue imports/aliases/define/async/functional
components, known data and shadowed factories, any/unknown, astral offsets,
whole suffix replacement and unsaved replacement/restore. Every full item and
RPC envelope is compared. Existing registered/global/native tag laws remain
mandatory. The existing capture records decoded JSON messages, stderr, physical
executable identity and terminal status; it does not record framing bytes.

Actual scope remains limited to native configured API evidence and an authored
non-type-only Vue import. Missing evidence preserves the previous guesses.

`FunctionalComponent` with an `any` return type, so ordinary function intent is
not distinguished. That separate problem remains open instead of adding a
function blacklist or a naming heuristic.

completion laws on the actual head, with real pinned native/Vue supply and full
