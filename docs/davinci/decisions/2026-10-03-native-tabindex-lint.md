## Original attributes and exact values

`NativeSyntaxLint::tabindex_no_positive` consumes a genuine same-owner
NativeElement from the Descriptor-selected L1 NativeTemplateComponent. Original
owner/recovery admission, token/quote/value validation, typed directive heads,
verbatim flags and all unresolved-header refusals remain unchanged. A later
unresolved or unsupported attribute refuses the whole ordered result, including
an earlier positive tabindex. No child body is walked and no source is reparsed.

The existing registered `a11y/tabindex-no-positive` rule reads only static
attributes, matches `tabindex` with ASCII-insensitive names, and applies even
to component tags. Dynamic Bind/Prop values, events and model expressions stay
opaque and are not static integers. Verbatim directive-looking names remain
literal. Values use the same `parse::<i32>()` and positive comparison as the
actual rule, preserving plus signs, leading zeroes, negative/zero values,
whitespace rejection, malformed integers and overflow behavior.

Entity-free values use their original borrowed bytes directly. Character
references use only the genuine L1 Attribute `decode_one` and compact L0 String,
then the same i32 parser. Unknown references remain literal. No legacy helper,
compatibility parser or synthetic decoded owner is involved.

The shared checked original-attribute view gains its full authored range, from
the original name through the value's closing quote or unquoted content. The
rule returns owned ordered NativeLintFindings, each a finished L0 Surface
advisory Warning with the actual localized message and full Help over that
attribute range, no secondary labels and no fix. The caller supplies L0
MessageLookup. Findings remain owned after the selected owner/arena drops.

unchanged actual TabindexNoPositive-only registered legacy oracle. They cover
all three locales and quoted/unquoted ranges; positive i32 boundaries and
plus/leading-zero forms; zero/negative/whitespace/invalid/overflow values;
named/numeric reference decoding and encoded boundaries; opaque expressions;
case/component/verbatim controls; original attribute order and Unicode absolute
spans; later refusal; foreign/recovered owners; owned lifetime and empty
selection. Every existing image-alt and iframe input and equality remains.

Only the exact new dev-only catalog path/import is registered. Unchanged
host/storage boundary laws remain enforced; both canonical Patina inventory
witnesses are regenerated. Rustfmt, inventories and ten boundary/storage laws
pass locally. The new Rust laws are authored, not yet hosted acceptance.

queue and main merge confirmation are required. No duplicate manual full100,
