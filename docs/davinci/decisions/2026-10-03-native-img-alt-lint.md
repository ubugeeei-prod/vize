# Native L1 image alternative text lint

Issue: [#6848](https://github.com/ubugeeei-prod/vize/issues/6848).
The product fix-history gate [#6881](https://github.com/ubugeeei-prod/vize/issues/6881)
remains open. This change adds an explicit native entry for one existing rule;
the ordinary linter, presets and rule registration retain their current routes.

## Admission and ownership

`NativeSyntaxLint::new` borrows the genuine L1 `NativeTemplateComponent`.
That provider derives its selected template, checked source block and intrinsic
script grammar from the authentic admitted Vue Descriptor, and parses the
selected body once. A detached `ComponentParse`, arbitrary block, raw element or
caller-supplied recovery flag cannot construct the native lint context.

The context reads the original owner's recovery, authored projection and
unsupported observations. Recovery refuses with its absolute source offset;
other unsupported component observations remain refusals. Nothing clears or
replaces those observations. The context borrows the same selected owner, and
each rule call checks the original component identity of its `NativeElement`.
Equal bytes from a different owner do not satisfy that check.

The caller chooses and drives the genuine original children. The native rule
does not parse another source, traverse the component body or join an unrelated
carrier. Its only iteration is the supplied element's original opening header.
Private L1 child and attribute projections retain their parent and ordinal.

## First supported rule

The entry is `NativeSyntaxLint::img_alt`, with the unchanged `a11y/img-alt` code.
It uses the actual registered accessibility rule as its dev-only differential
oracle, rather than the separate `vue/a11y-img-alt` alias. The accessibility
rule compares tag and argument names without ASCII case and has warning
severity, localized message/full help, no secondary labels and no fix.

The native entry accepts static `alt` attributes and typed static arguments of
`:alt`, `.alt` and `v-bind:alt`, including their authored modifiers. Values stay
opaque; attribute presence does not require an expression parse or evaluation.
An original native `v-pre` flag instead keeps directive-like names literal.
All header tokens and attribute value/quote tokens are checked against the
original UTF-8 source block. Missing tokens, inconsistent value/quote pairs,
unresolved dynamic arguments and object `v-bind` refuse before any diagnostic,
including when an earlier static `alt` already exists. Unknown or malformed
directive heads also remain refusals.

An admitted missing `alt` produces a finished L0 `Diagnostic` with advisory
`Warning`, origin `Stage::Surface`, the complete authored element span and one
structured `Help` part. The caller supplies the existing L0 `MessageLookup`,
so the actual message catalog and locale fallback remain host-owned. No error
witness or legacy exemption is invented. Diagnostic text is owned and can
outlive the selected owner and its arena. Opening and real closing tokens
determine the complete absolute SFC byte span without walking child bodies.
