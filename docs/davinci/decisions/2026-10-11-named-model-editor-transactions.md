publish the independent TS2322 diagnostic and its repair, and publish clean
whole initial diagnostics. Fixed query zero supplies the actual complete edits;
all owned memory/disk files and version-2 diagnostics must equal independently
authored goldens. Independently installed version-3 files and diagnostics must
also match. Retain every complete reply and diagnostic publication under the
separate `named-model-transactions` namespace, with existing process custody.

The existing whole-transaction applicator is reused unchanged. Inert source
laws reject missing/null/cross-component oracle success and foreign/resource/
overlapping whole transactions. Existing basic-model, bound-emitter and stock
Content Mapper null controls, shared capture flags, passive APIs, configuration
snapshots and `rename_scope` remain unchanged. No provider/cache/parser stage,
deadline or implementation defect is invented to accompany these tests.
