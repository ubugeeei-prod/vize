# Original selected conditional operands

Issues: #6836, #6838 and #6844.

The Descriptor-selected L1 template owner now observes a conditional operand
from its actual NativeAttribute. Vue3 owns the typed directive decomposition;
only complete argument/modifier-free v-if and v-else-if heads select an operand.
The producer derives the full original value, arena, JS/TS Module profile and
checked source from that same selection. It calls the existing attribute decoder
once and the existing stock expression provider once. No caller AST, language,
allocator, source range, decode map, status flag or raw Attribute can assemble
this owner. Conditional grouping and target spelling are later obligations.

The normally owned movable NativeAttributeExpression retains the original
RetainedExpression, comments, complete diagnostics, decode map and typed syntax
hole. Private origin fields retain original immutable arena-backed Element and
Attribute identities, header ordinal, root/block storage, selected template
index, grammar and full name/value spans. Addresses are compared only and never
dereferenced; neither the selected wrapper nor Component wrapper address is
stored. Moving the selected owner and growing parked operand storage preserves
admission. An independent parse of identical source, a copied source and another
Attribute from the same header are refused by the short join.

admitted_for reborrows the actual selected owner and current complete Attribute,
then borrows the original stock admission from the retained syntax. The view is
short, not Clone and not a body/File completion certificate. Readonly syntax
observations remain available after a hole. Consuming into_syntax deliberately
discards header authority while retaining the same original AST and observations.
The upper producer must replace its existing header expression parse with this
owner and park it before callbacks or Vec growth; adding another parse is forbidden.

Parser errors and unsupported carriers refuse preparation without consuming the
selected owner. Actual node/token holes also matter: ElementClose::Missing can
occur with no Component diagnostic. The provider checks this actual Element's
opening and closing framing directly, with no additional tree walk. Missing
Attribute framing/value, v-pre, foreign Component and unsupported head variants
are typed refusals. Valid implicit/void/self-closing extents retain their dialect
meaning. Unexpected parser shape retains the complete boxed original artifact.

Fresh actual-source validation passes all 337 whole-L1 unit laws (327 existing
plus ten operand laws), production and whole-unit strict Clippy with the committed
configuration, and two positive/six negative API privacy/lifetime compilations.
The laws cover complete UTF-8/entity windows and exact authored maps, original
stock root pointers, setup TS profile, syntax/comment/diagnostic custody, owner
movement and pending growth, foreign/sibling events, retained missing-close holes,
and raw syntax transfer after the selected owner leaves scope. The earlier
partial missing-close failure and sparse-configuration attempt remain preserved;
no lint waiver or assertion weakening was used.

This provider is source work on the genuine selected-owner dependency. Whole
Cargo, exact-head hosted gates, all 100 probes, protected Stack queue and actual
merge remain required. Live File header/body cursor integration, indexed If
facts, complete native conditional output, other directives/dialects, default
product migration and fix-history gates remain unfinished. The parser timeout
and memo/semantic-state investigation is independent and unchanged by this slice.
