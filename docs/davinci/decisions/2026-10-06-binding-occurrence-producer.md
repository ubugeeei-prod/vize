## Provider decision

Keep editor facts separate from the public `Croquis`, its fields, serialized
snapshots and VIR dumps. A hidden additive query facade returns the ordinary
analysis and an independently owned optional occurrence packet. Existing public
analysis/parser option structures do not acquire required fields. Script parser
Debug retains every original field in its original order and excludes the private
demand-only capture, so the existing whole snapshots remain the authority.

Each binding identity carries its originating lexical `ScopeId`, original
block kind and exact authored declaration byte span. The spelling witnesses the
source; it never establishes equality between declarations. References retain
the same binding identity and their individual AST identifier byte spans.

The existing script declaration/expression walk emits scoped reads when demanded.
Parameter and local-declarator witnesses replace the existing name-only pattern
walk in that demand. After all declarations are known, the existing scope parent
relation resolves references. Locals without an authored witness cannot escape
into a same-spelled setup binding. Top-level const/let/function eligibility for
lenses comes from actual declarations, not line text.

The existing template identifier walk retains its offsets in the existing
expression cache. Every occurrence reuses those facts with its current lexical
owner and authored location. Repeated physical visits are deduplicated by full
binding/span/block identity. Original alias declaration offsets separate inner
v-for/v-slot uses from globals. Implicit handler parameters and transformed
aliases without exact authored witnesses cannot become setup reads.

The ordinary legacy comment transform and names are preserved. An opt-in byte
map from that same transform projects only contiguous original identifier bytes;
synthetic replacement spaces or mismatched source witnesses refuse the packet.
This adds no request-time reparse or new analysis stage.

The existing demanded style-read expression analysis retains original free-read
identifier offsets rather than discarding them. It runs once in the opted-in
producer and does not enable unused-binding or unrelated diagnostic demand.
The existing scanner supplies exact original v-bind expression/quote boundaries;
separate style-block identities retain all occurrences and exclude CSS strings
and comments. The ordinary names-only style consumer remains unchanged.

Split scripts use the existing joined script view and its existing physical
mapper. Original scope IDs remain qualified by their originating block and exact
declaration spans; setup offsets shift by precisely the existing script seam.
Unknown setup references are retained with exact AST/source spans until the
actual plain/setup declaration packets and existing summary are joined. Only a
known merged declaration's exact span and identity can own such a read; implicit
globals remain unowned. Ambient names such as `Math` stay pending until this
actual join, so a genuine normal-script declaration has lexical precedence. The split-source law covers the setup read of `plain` as
well as its template use.
No source clamping, global counter, native IPC or per-node type query is added.
