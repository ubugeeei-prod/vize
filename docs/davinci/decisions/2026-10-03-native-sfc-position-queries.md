## Decision

`NativeSfc::reference_at_offset` and `binding_at_offset` query original script
and template uses at checked file-absolute UTF-8 boundaries. Names are half-open;
EOF, comments, remote import names and opaque source gaps have no fabricated
local use. More than one use observation refuses even when binding IDs agree.
Declarations and script use rules delegate to the original File query provider.

`NativeReferenceRef` borrows the actual File, original script/occurrence row,
real binding, recorded lexical scope and exact authored spelling. Its private
constructor prevents a product from substituting numeric IDs or handwritten
rows. Template reads check the same retained embed AST, decoded source pointer,
authored root pointer and span against the same File resolution entry. Decoder
and wrapper projection must select exact complete authored spans; partial entity
boundaries refuse. Original scope IDs describe recorded factories, not an
invented template-wide visibility interval.

`for_each_reference_to` refuses a binding borrowed from another actual File,
including equal-text copies with equal numeric IDs. It scans existing script
and original template observations without a parser, AST walk, semantic index,
per-node allocation, sorting or new pipeline stage. Traversal order is not a
source-order guarantee; a consumer may collect and sort owned locations.
Fallible traversal requires discarding partial visitor work before publication. No
indexing or performance improvement is claimed without measurement.

## Maestro integration and lifetime

The retained Vue worker keeps the admitted `NativeSfc` view as an ordinary
borrow inside its existing local query object. It calls the shared binding/use
API instead of walking original template embeds and resolution side tables
itself. Only owned UTF-16 locations enter replies. Original descriptor/scripts/
Component/embeds/File, allocator and immutable snapshot keep their existing
stack lifetime; borrowed queries end before their owners drop.

The existing physical-source/configuration publication guard, sticky original
producer refusals, immediate change/close retirement, cancellation, bounded
mailbox/live-worker admission and unwind release retain their original laws.
No shared native summary, unsafe lifetime cast, extra worker/cache or parser is
introduced. Standard/default LSP routes retain their separate fix-history gate.
