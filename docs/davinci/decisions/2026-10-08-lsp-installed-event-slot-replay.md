## Raw source identity and additive transport

An inert replay reproduced a real acceptance gap: replacement refs, graft files
and GIT_GRAFT_FILE could make both inherited merge-base checks claim unrelated
signed source inclusion. A clean unrelated graph failed; each injected graph
reached the next authority assertion. No actual repository identity was changed
and no provider executed. Resolve source inclusion through SHA-authenticated raw
commit objects and their literal parent headers. Resolve the stock lock,
Playground manifest and helper through authenticated tree/regular-blob objects.
Ignore inherited Git redirections and disable replacement/lazy-fetch reads;
missing, malformed, substituted or redirected objects fail. Raw ancestry remains
separate from the mandatory reviewed actual GitHub signed delivery receipt.
Thirteen inert laws include replace, graft, shallow and environment controls.
The full original32 source/oracle/dependency identities remain unchanged.

The transport retains strict request behavior by default. Only the first eight
uncontracted bound definitions use explicit requestObserved, preserving their
whole RPC error and outcome. Malformed replies still fail. Ordered prompt/native
publications share one deadline and retain duplicate packets; the original
single-publication call remains the count-one wrapper. Add optional original
versioned didOpen, lint configuration, stdin-open exit and a separate exit
deadline. Defaults keep every original32 behavior. Seven pure dispatch laws
reject foreign IDs/versions, malformed responses and incomplete sequences.
