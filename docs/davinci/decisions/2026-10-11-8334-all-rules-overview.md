# Keep All Rules as a complete overview

Issue: [#8334](https://github.com/ubugeeei-prod/vize/issues/8334).

## Decision

All five All Rules pages are indexes rather than collections of every complete
example. Retain the 317 rule headings, their existing purposes, the metadata
tables and their links. Each summary links to the owning group and the complete
individual reference. French, Portuguese and Chinese use the existing English
individual references; no translated reference routes are invented.

Native headings continue to own every rule fragment. Keep all 634 existing
Bad/Good fragments as explicit aliases beside links to the owning group's
examples. Preserve the existing section headings and older locale fragments.
The group pages continue to contain explanations, configuration, support limits,
complete Bad/Good source, shared project files and reactive graphs.

Generate the overview through the existing reference pass and catalogue
materialization. Do not rewrite group or reference generation, copied source,
code annotations, package-manager controls, preset metadata or producer limits.
Project membership comes from the actual project reference inventory, including
project-specific `ecosystem/*` IDs; a diagnostic namespace alone does not define
the owning page.

reference inventory, requires nonempty purposes and unique compatibility
aliases, refuses fenced example packets, and resolves each destination against
the actual complete group document. English and Japanese summary text matches
the original reference purpose exactly.

purposes, unique IDs, no collected example code and actual same-origin links to
both examples on the owning group. Existing native link checks resolve the
destination fragments. All five locales remain in the original full Docs desktop/mobile, theme,
accessibility, navigation and complete pixel campaign. The CLI previously
composed the three translated indexes and group routes beyond the base route
list. Export that complete original manifest so both the CLI and coverage check
consume its actual values, without adding duplicate routes. Retain every
original route and packet assertion.

Regenerate the existing measured `v-on` corpus with its original Rust command.
Remove only the 75 inventory rows for examples previously copied into All Rules;
retain every owning-source row and all other 24 corpus shards byte for byte.
The unchanged freshness and two-entry storage-budget tests must pass.

Replace only the former assertion that All Rules itself must contain every
complete packet. Retain the original English/Japanese 317-reference HTTP,
Bad/Good-anchor and whole-code checks, original indentation packets, complete
category checks and all 104 Vue packets per locale. The remaining category source
assertions retain their complete original bodies and expected values.
