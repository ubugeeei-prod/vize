# Original For resolution (#6836, #6838)

## Decision

`resolve_for_head` consumes the genuine `NativeForInput`, preserving the whole
original selected Attribute and both stock observations on success or refusal.
The sealed source adapter supplies only the original retained collection and
Params roots. No replacement parser, neutral tuple or authored AST can mint the
resolution table.

One existing retained-tree resolver walks the original collection first using
the caller's enclosing `BindingLookup`, then enumerates the actual one/two plain
alias binding roots from the original Params observation. Thus
`(items, key) in items` resolves its collection to the enclosing `items` before
the local `items` exists. Original alias declarations carry their exact value/key
role, name and separate decoded/authored spans. The whole head shares the
unchanged depth64/node4096 budget; namespace-specific alias projection preserves
the original internal wrapper without decoding or walking either AST again.

Local `ForAliasId` and enclosing `BindingId` use distinct enum cases. Their equal
numeric indices cannot collide. A readonly initial body lookup shadows the
enclosing environment with only these actual original aliases; it provides no
File admission, canonical child scope or body reference enumeration.

Duplicate semantic names refuse at the second original alias. The initial
semantic family conservatively refuses aliases beginning `_` or `$`, reserving
generated helper/context prefixes. Wider authored names require the eventual
owning emitter's complete namespace policy. No runtime helper or native output
support is inferred here. Missing enclosing collection bindings are resolved
and refused before alias policy; an alias cannot resolve its own collection.

Both collection-sink failure and a later alias refusal roll back all newly
recorded facts. No partial table escapes, while the complete original input,
profile, comments, diagnostics, maps and selected header association remain
owned. Movement and consuming recovery retain the actual original roots.
