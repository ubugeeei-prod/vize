# The production DOM emitter lives in L4

Tracked in [#6840](https://github.com/ubugeeei-prod/vize/issues/6840) ("DOM:
move"), closing the emission half of
[#6838](https://github.com/ubugeeei-prod/vize/issues/6838) ("`vize_l1_to_l2`
shrinks to lowering"). It follows the
[canonical artifact record](./2026-11-09-6838-l2-canonical-artifact-tables.md).

## What moved

The emitter that `vize_atelier_dom` selects for production DOM output moves
unchanged from `vize_l1_to_l2::emit` to `vize_l4::targets::dom::artifact`, next
to the native L3-driven DOM target. Its Vue orchestration files move from
`vize_l1_to_l2/src/dialect/vue/emit` to `vize_l4/src/framework/vue/dom`, still
included by their target modules, so dialect policy stays in a dialect module.
The JS-module dialect gate it shares with `vize_atelier_core` moves to
`vize_l2::expr::js::js_module_compatible`, so the legacy core depends on L2
instead of the lowering crate.

The emitter's core reads only L2 types: the canonical `ArtifactParts`, the L2
pass facts and the L2 fragment, text, static and slot schemas. Its source-level
entry points (`emit_dom_source*`) parse with `vize_l1` and lower and transform
through `vize_l1_to_l2`'s public API; no `vize_l1_to_l2` internal module is
reachable from L4. Consumers import the canonical path; there is no
compatibility re-export, because `vize_l1_to_l2` cannot depend on L4.

## What did not change

Emitted bytes, source maps, diagnostics and refusals are unchanged. The
emitter still re-parses retained expressions it cannot reuse and erases
TypeScript through oxc; the L4 crate documentation names it as the exception
to "L4 never reparses" until the native DOM target replaces it. The `typescript`
and `legacy-differential` features move with it.

Its behavioral tests stay in `vize_l1_to_l2/tests` for now and reach the emitter
through a `vize_l4` dev-dependency; they exercise parse, lowering and emission
together. Moving them beside the emitter is a separate, test-only change.

The storage inventory now scans `vize_l4` (scope `l4`), so the moved emitter
keeps its reviewed per-file `alloc::vec::Vec` rows and the existing L4 files
join the ledger.
