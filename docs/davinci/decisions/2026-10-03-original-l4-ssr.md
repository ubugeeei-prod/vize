# Original selected-template SSR emission

Tracking: [#6840](https://github.com/ubugeeei-prod/vize/issues/6840), [#6839](https://github.com/ubugeeei-prod/vize/issues/6839).

`emit_template` accepts only the genuine `NativeTemplateSsrAnalysis` completion
receipt. It derives original source and SSR facts from that same retained lower
owner and delegates to the existing private append encoder. Neutral artifact
and completed File emitters remain explicitly diagnostic. A compile-fail law
prevents diagnostic File analysis from entering the original-template API.
No independently paired File, source, table, AST reconstruction or new walk is
introduced.

Eight scriptless original SFC fixtures exercise empty/text/Unicode/JavaScript
escaping/comment/static HTML/nesting/fragment/ordinary-prop boundaries. The
Rust law observes the authentic Descriptor, selected Component, private lower
whole-root completion and moved L3 receipt. It compares the complete emitted
module against independent pinned Vue 3.5.35 function bytes, retaining only the
existing server-first import-grouping adjustment. Root props use the pinned inline layout for one
property and multiline layout for multiple properties; the real two-attribute
fixture covers that encoder correction. Both sinks match, every original/
generated link stays in its original whole-SFC frame, and prepared component
assembly preserves complete bytes and SSR attachment.

The separate immutable primary references retain full compiler options/code/
maps/digests. Dev tests recompile every reference twice, use real SSR helpers
for three attribute contexts and execute whole components with Vue's actual
`createSSRApp`/`renderToString`. Reference execution passed locally; native
module/map/runtime captures remain mandatory fresh hosted evidence, never
constructed from the expected reference. Independent VLQ decoding checks every
UTF-16 anchor and exact prepared-module shift against complete original SFC
source. Upstream maps use template frames, so full upstream map parity is not
claimed.

The existing mandatory first-shard merge action also runs this original-source
Rust law and runtime consumer. Two additional JSON artifacts retain eight
complete original modules/maps plus four original refusals, and 24 native,
24 upstream, 24 prepared-function, 24 prepared-component and 24 upstream-
component calls. Missing source captures fail. Original root/nested `search`
refusals retain exact node/span evidence; global/scoped style sources refuse
before any output capability or writer is returned. Prior diagnostic captures
remain distinct and unchanged. Source Actions, the exact queue candidate's
mandatory captures/all protected gates and actual merge remain required.

This additive API is a bounded template entry, not a complete native compiler
product. Script emission, text entity/whitespace admission, full style/scope,
directive/control/expression/component/slot/dialect families, complete maps,
compiler-history #6880 and default product replacement remain unfinished.
