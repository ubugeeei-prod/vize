## Pinned runtime contract

[Vue 3.5.35 renderList](https://github.com/vuejs/core/blob/v3.5.35/packages/runtime-core/src/helpers/renderList.ts)
owns actual collection semantics. Numeric values yield one-based values and
zero-based indices; strings use JavaScript UTF-16 code units. Zero/null/boolean
controls yield empty lists. Invalid numeric values have distinct development
warning and production exception behavior, which must remain the helper's own
behavior rather than an invented compiler guard.

[The pinned For transform](https://github.com/vuejs/core/blob/v3.5.35/packages/compiler-core/src/transforms/vFor.ts)
supplies the concrete unkeyed Fragment/block contract. For this mutable setup
Identifier, its actual output calls `openBlock(true)`, `createElementBlock` on
`Fragment`, `renderList($setup.count, original parameter callback)` and the
callback's Element block, with `256 /* UNKEYED_FRAGMENT */`. The current pinned
compiler reports `count: setup-let` and imports renderList/Fragment/openBlock/
createElementBlock in that order. Preserve actual canonical helper demands and
full-file collection/parameter/element/text links through module assembly.
