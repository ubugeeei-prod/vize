# L4 emission skeleton

Tracked in [#6840](https://github.com/ubugeeei-prod/vize/issues/6840), following
its [design](https://github.com/ubugeeei-prod/vize/issues/6840#issuecomment-5847908963)
and the 2026-09-28 skeleton-first decision on #6826.

- **Crate:** `vize_l4`, `no_std + alloc`, depending on `vize_l0`, `vize_l2`,
  `vize_l3` and `serde_json` only. It remains unpublished; no product selects
  its document, writer or targets.
- **Codename:** Stesura (the laying-down of paint). Docs only, like the other
  codenames.
- **Layout** follows the design comment: `write` (writer; `EmitDocument` and
  `SpanLink` move here), `expr`, `runtime` (the issue body's `helper`),
  `module`, `targets/{dom,ssr,vapor,ts}` (plural because the repository
  ignores every `target/` directory).
- **Links cost nothing when off:** the writer is generic over a `LinkSink`.
  `NoLinks` is a zero-sized sink whose calls compile away; the recording sink
  stores `SpanLink`s. No runtime `recording` branch.
- **Preamble last:** `Writer::finish_with_preamble` joins preamble and body
  with one exact-capacity allocation; nothing is inserted mid-text.
- **Helpers:** a `Helper` indexes one runtime's vocabulary table (at most 128),
  so the used set is one `u128` mask plus first-use order.

- **Document ownership:** `vize_l4::write` now owns its native
  `EmitDocument`, `SpanLink`, `SourceMapBuilder` and rewritten-identifier
  span recovery. The move-only commit is followed by a restoration of the
  original `vize_atelier_core::codegen` modules: the live compiler and SSR
  still use those modules. A consumer switch waits for the compiler
  fix-history fixture gate [#6880](https://github.com/ubugeeei-prod/vize/issues/6880).

Implemented: the writer (text, indentation, helpers, fragments, preamble join),
the recording sink (`Writer<Recorded>` finishes into the same `EmitDocument`
as direct `EmitDocument` calls) and `HelperSet`. Still `todo!()` under
module-level `#![expect(clippy::todo)]`: helper tables, `expr` rewriting
(needs the L2 resolution table, #6838), `module` assembly and all targets.

The skeleton-todo baseline (`tools/config/skeleton-todos.toml`) drops `vize_l4`
to 7 with the recording sink filled.

The first #7037 merge-queue measurement exceeded 31 instruction ceilings in
DOM, SSR and Vapor generation after the live document crossed a crate
boundary. That consumer switch was withdrawn because #6880 is still open.
The native L4 document keeps inline hints for future emitters; the live
compiler route and instruction budgets remain unchanged. Exact-head Actions
measurement must verify this narrower PR.
