one supported `0.433.0` minor release after the selected actual merges below,
then carry that exact candidate through all required validation and public
publication checks. The maintainer has already authorized frequent releases of
the existing products. This record selects a finite delivery batch; it changes
neither the [support policy](../../release/support-policy.md) nor the
[supported release procedure](../../release/pr-workflow.md).

## Version and public scope

A minor feature/API release is appropriate for the new public caller-owned
`WalkTiming` helper reexported by Carton and the opt-in Patina native SFC
setup ownership/context/refusal APIs. Existing Timer APIs and old ScriptRule
implementors retain their interfaces. Experimental L1 binding and L2/L3
attribute custody additions are included; Glyph's unpublished native option
and refusal shapes are not represented as protected published removals. The
existing native-selected DOM function gains bounded const For behavior without
changing its public signature. No protected public removal was observed in this
review; the existing deprecation window still applies to any such removal.
The actual candidate must pass all 12 published-crate SemVer checks using its
own bumped version, without weakening a gate or editing its classification
marker.

Public scope stays bounded: module-link and physical-target observations are
opt-in providers; Glyph's original quoted conditionals and Vue 1 callback Docs
do not complete whole grammar/history/default or browser/output-map gates;
caller-owned timing does not replace all global clock/TLS/platform services;
original attribute and binding custody does not complete native compilation;
Patina's sealed primitive-only setup capability does not cover ref-call positive
semantics, DOM/ref association or whole-rule/history/default replacement. #7798
selects the configured no-autofocus/no-access-key callbacks over their sealed
original header; full rules/dialects/JSX and linter history closure remain unfinished.
#7781 covers original const STABLE_FRAGMENT output while mutable let/var retains
UNKEYED_FRAGMENT; SSR and broader compiler controls remain unfinished.

#7790 adds native CLI graph/profile evidence machinery. Source runs captured
graphs, while manual run `37195795568` failed before production build/capture.
Actual CPU/allocation profiles remain unmeasured; production speedup is not
established and the generated 500-SFC type-checker 10x target remains unmet. #7779 reconciles official source-bound worker/artifact identities and
rejects failed, incomplete or stale evidence; a genuine hosted failed-only
recovery is still a future observation, not a measured acceptance claim.
