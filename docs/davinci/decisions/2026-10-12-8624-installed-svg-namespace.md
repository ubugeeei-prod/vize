## Physical browser requirements

The unchanged authored case contains SVG `a`, `filter`, `feGaussianBlur`,
`view` and `switch`; an HTML `a` inside `foreignObject`; and an ordinary HTML
`a`. All seven class bindings are observed through their actual DOM properties.
Five must own `SVGAnimatedString`, while the two HTML anchors own string class
properties. Whole ordered DOM trees, every element namespace, attributes and
class values must match the immutable expectations and independent complete
Vue VDOM compilation.

Mount and update require each element's expected inline and computed color.
Clear requires the style attribute to be absent and the inline color to be
empty; inherited browser color after clearing is deliberately not fixed.
The SVG must render at 64×64 and its rectangle's physical bounding box at 32×32.
Unmount must remove every host child node, including comment anchors. Subsequent
fixture state invalidations must leave the retained DOM and fixture events
unchanged. This does not claim revocation of intentionally retained handlers.
