# Original Vue 1 selected descriptor provider

Issues: [#6837](https://github.com/ubugeeei-prod/vize/issues/6837),
[#6842](https://github.com/ubugeeei-prod/vize/issues/6842) and
[#6882](https://github.com/ubugeeei-prod/vize/issues/6882).

This private provider implements the source custody prerequisite in the
[whole SFC plan](./2026-10-04-vue1-selected-sfc-source-plan.md). It grants
original historical source access, rather than whole formatter or browser
semantics. Publication and current-source Actions are still required.

## Original authority

`Vue.observe_vue1_descriptor` explicitly requires V1, the Vue dialect and
default surface options. One existing `split_with` event stream retains the
whole original `Container`, splitter errors, original slot and opening/closing
name geometry. The descriptor's private checked root and selection cannot be
constructed from a public capture, source tuple or modern descriptor.

The actual emitted block's `attrs.is_empty()` supplies the O(1) outer header
gate. An attributed template produces one `UnsupportedAttribute` at its real
opening span; the provider does not revisit attributes, classify language or
resolve external sources. Scripts, styles, custom blocks, duplicate templates,
unsupported spelling, missing or uncertain framing and wrong profiles retain
actual whole-source evidence and prevent the historical parser entry.

Only after the whole envelope passes does the provider call the existing
Vue 1 `parse_component_block` once with the original selected `SourceBlock`.
The normal `ComponentParse` owns its actual callbacks, prepared native syntax,
comments, diagnostics and recovery facts. `selected()` only reborrows that
same owner. It neither reparses nor decodes; its private view checks original
root, block, slot and frame identity.

Historical body admission stays separate. Every pipe, raw or one-time callback,
CR/CRLF/U+2028/U+2029 callback separator, encoded delimiter, expression hole,
verbatim body and recovered child keeps the actual existing Vue 1 refusal.
An empty or static body can be observed by this provider without receiving the
later consumer's one-Element-root policy. There is no Vue 2 filter conversion,
Vue 2 `parseComponent` authority, public mutable owner or modern admission.

## Authored laws and execution boundary

Twelve source-authored Rust laws cover the complete nonzero Unicode frame,
original callback and AST pointer joins, prepared entity maps and comments,
equal-byte/same-buffer/foreign-arena rejection, repeated parent/ordinal custody,
normal moves and empty/static body observation. Profile and later-slot laws
preserve the real public captures and the existing V2/V3 entries. Historical
body laws retain actual native diagnostics rather than fabricate errors for
semantic boundaries; globally encoded delimiters remain distinct from a
normally observed later callback.

Test-only hooks count the actual splitter and parser entries on an armed thread.
Readback does not increment them. Injected entry and after-park faults unwind
normal owners without retry; normal drop and concurrent isolation are checked.
These hooks add no production state or pipeline stage. Ten compile-fail examples
exercise real privacy, owner/source/arena lifetimes and absence of Clone or
modern conversion. The public positive example uses the real selected callback.

These laws have not been compiled or executed locally. Formatting and existing
pure source inventories are the only local checks. Automatic exact-head Actions
must establish the actual laws and unchanged inherited controls; protected full
validation and unchanged instruction ceilings precede actual merge. No runtime,
full SFC or default-path acceptance is inferred from authored tests.

## Genuine consumer dependency

The immediate private Glyph consumer must use the real checked Vue 1 TextDoc
provider from #7777 and this actual selected descriptor. It will retain one
Element root with only outside whitespace/comments in the same original child
visit; root text/interpolation and all unsupported headers refuse. Its whole
prefix/body/suffix Doc must precede one LF printer. CrLf refuses before printing.

Independent 24-row whole outputs and historical Vueify/parse5/browser controls
must be frozen before native qualification. Original and prepared callback maps
remain actual source geometry; generated VLQ maps are not a Glyph product API.
Equal undefined/noop getter outcomes are explicit no-credit controls, not
positive semantics. Default routing and the closed #6882 history stay unchanged.
