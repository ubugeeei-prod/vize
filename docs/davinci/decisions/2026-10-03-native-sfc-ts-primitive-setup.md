# Native TypeScript primitive setup without erasure

Tracked in [#6838](https://github.com/ubugeeei-prod/vize/issues/6838) and
[#6840](https://github.com/ubugeeei-prod/vize/issues/6840). This depends on the
original strict literal receipt provider and primitive Const setup consumer.

The existing sole Program walk admits direct Const/Let/Var declarations with
primitive literal initializers and empty statements from an authentic TS
module, alongside JS. The default original parser options, exact source and
Program owner, actual File unit/root scope, normal uninterrupted completion,
and strict literal/binding eligibility remain mandatory. Definition profiles,
JSX, ordinary scripts and unambiguous profiles cannot supply this capability.

Type annotations, definite assignment, declare, assertions, satisfies,
non-null expressions, aliases, interfaces, enums, namespaces, imports,
exports, macros and nonprimitive bodies remain refused by existing original
node checks. There is no TS erasure, source substitution, second parse/walk,
legacy compiler call, serialization or new pipeline stage. The retained
original TS script body is copied once into the complete native JS module.
Authentic Const facts keep getter-only exposure and literal identifier reads;
Let/Var retain their genuine mutable classes, setters and TEXT updates.

Three complete original SFC inputs cover every primitive class, mixed mutable
bindings, escaped identifiers, Unicode and comments. Their whole native code
and maps were generated by the actual source-built compiler. Independent
pinned Vue 3.5.35 compileScript/compileTemplate output and two real Vue renders
per input supply the reference; the TS wrapper uses real Vue defineComponent
without rewriting generated reference syntax. Runtime tests load the captured
native modules and reject missing mandatory capture files.

The const reference test is renamed in a pure move commit, then shares its
existing map/runtime laws across both families. The guaranteed merge-group
first tooling shard now captures and executes all original eight JS, five
Const and three TS modules beside strict-safe/refused module laws, uploading
all eight source/runtime capture files. The current source-built Node run has
41 passing tests and no skips; twenty L2 setup laws and eleven native product
laws pass. The first broader hosted product shard exposed an obsolete blanket
TS refusal input; that law now uses a genuine type-annotated declaration while
retaining its original syntax/profile/source-owner refusal checks. Exact-head Actions, full protected merge-group suites, unchanged
all-100 instruction ceilings and actual native Stack merge are still required.

Broader TS syntax, other Vue dialects, ordinary scripts and compiler default
migration remain unfinished. Compiler history #6880 must close before any
default replacement; this bounded opt-in slice grants no such completion.
