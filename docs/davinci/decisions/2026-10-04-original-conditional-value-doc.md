## Same original header event

The existing selected-template child traversal retains each original
`NativeElement`. In an ordinary complete header, its actual `attributes()`
iterator visits each slot once. The receiver calls `observe_attribute_head`
once at that event; the resulting sealed head supplies both the checked name
Doc and the existing conditional expression observation. It does not decompose
that name again or call the generic attribute-value observer as a second decode.

The shared opening layout and value-token helper preserve the old opaque and
strict paths. Original missing-extent/token or v-pre facts only select the old
negative route and its existing visit/refusal order; they never mint positive
admission. Clean headers still obtain a real head from L1. Descriptor issues,
unsupported outer block roles, selected-component construction and original
body/token checks retain their existing order.

Only `NativeSfcOptions.directives = FormatConditionals` opts the whole owner
into this route. Its default remains `Refuse`. The lower observed-template API
also has an explicit `NativeTemplateValuePolicy::FormatConditionals`; the
existing `PreserveOpaque` and `RefuseValuedDirectives` contracts remain intact.
These dedicated native policies do not imply legacy `FormatOptions` parity.

## Retained source and failure custody

Each original conditional `NativeAttributeExpression` is parked in a normal
owning vector before quote-frame checks, actual-event admission or Expr-to-Doc
projection. Any actual observation error remains separately normally owned.
Interpolation and attribute observations retain their own source order, while
both are constructed in the same original child/header traversal. A later
failure preserves both prefixes and the current minted observation; no partial
Doc is exposed and later children are not observed.

A complete quoted value uses the existing genuine retained-expression Doc,
checked against the selected block, inside its original quote tokens. Entity
spellings, comments, physical authored LF/CRLF, operators, literals and original
AST structure retain the existing expression provider's checks. Unquoted values
refuse after parking the original observation: inserting expression whitespace
could alter HTML attribute tokenization. There is no quote conversion.

Name-layout errors alone translate checked authored-file offsets to selected
block offsets. Value spans and wrapped expression/source/decoded coordinates
remain the original provider's coordinates. No raw span, boolean, flags,
caller-made head or AST tuple grants observation authority.

The genuine whole SFC owner receives all observations before outer framing,
then constructs one prefix/template/suffix Doc with complete layout lookahead.
It retains descriptor, selection, original source, native options and both
owning vectors across formatting or refusal. Public additive `into_full_parts`
methods transfer every observation/failure from lower observed-template
results. Existing interpolation-only `into_parts` tuples remain compatible and
explicitly document that they release the newly added attribute observations.
