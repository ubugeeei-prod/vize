## External Markdown links in the pinned renderer

The first early browser run at `fe593f54a310dd7a19842be727153cf84564b41f` failed on the
Chromium testing source link. The pinned Ox Content 2.81 renderer converts external `.md` links
into local `../https://.../index.html` paths, including raw HTML anchors. Its actual native renderer
reproduces the failure. The Chromium source and GitHub decision record links now encode their
filename dot as `%2E`; both official hosts resolve that URI-equivalent spelling to the same document,
and the current renderer keeps the external destination and security attributes. No dependency or
upstream source changes are needed. The added real-browser local-link assertion is the regression
check: it rejected the converted destination before this correction.

Restore the unencoded spelling when a future pinned renderer preserves external Markdown URLs.
That restoration must pass the same complete guide browser check; the current source correction
alone earns no fresh rendered or deployed acceptance.
