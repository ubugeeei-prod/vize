# P2-17 — IR contract review milestone

**The phase-2 internal S2 contract checklist is signed off. Landed
2026-09-12 through [#6057](https://github.com/ubugeeei-prod/vize/pull/6057);
this is not the phase-6 external-format stability promise.**

## Review boundary

P2-17 reviews the S2 format at the last cheap-fix window before P2-20 evaluates
the phase exit. The sign-off applies to in-tree Davinci consumers: lowering,
DOM emission, Folio/Spolvero dumps, profile exports and diagnostics/provenance
readers. Vize-internal formats may still break until contracts GA, but they may
not silently violate the rules below while phase 2 exits.

## Checklist

| rule                        | sign-off                                                                                                                                                                                                                                                                        |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No redundant encodings      | S2 op fields carry semantic state. Derived or cached state lives in fact tables, observer products or dump-time summaries; `[disegno] ops=` is computed, parsed and validated at the Folio boundary, not stored as second IR state.                                             |
| No constructor-time folding | Lowering constructors preserve the authored S1 shape and expression slots. Folding happens in named passes or, for P2-12b's source-map-free DOM product path, in the explicit DOM product adapter before codegen. Vue 2 legacy sugar remains a pass-manager mutation.           |
| Escape variant semantics    | `ExprRef::Opaque` stays pessimal: consumers cannot infer more than the recorded reason permits. Retained-`None` narrowing remains future work, but the current escape contract is monotone-safe rather than optimistic.                                                         |
| Spans survive lowering      | `ir_contract_spans.rs` checks committed SFC batteries after lowering and after the current transform path, and can widen to a corpus through `VIZE_DAVINCI_DIFFERENTIAL_CORPUS`; expression sources are checked against authored SFC block offsets.                             |
| `schema_version` everywhere | The current serialized agent-visible artifacts are the Spolvero feed and profile export, both carrying `schema_version: 1` and strict schema validation. Future remark or fact-table serializations must use the same versioned/refusal pattern when they become real payloads. |
| Provenance survives failure | `lower::Lowered` keeps diagnostics, provenance and partial S2 fragments on failures. The span support checks cover folio, op, binding, expression, provenance and fact spans; P2-8 remains the totality battery for malformed lowering.                                         |

The optional corpus command is deliberately listed as the widening witness; the
committed local gate is the authored battery so ordinary CI can run it without a
hydrated ecosystem checkout.
