## Result

`lintWithPlugins` shares a manifest-checked `plugin.result` artifact key between
its opt-in process cache and optional `cacheDir` store. The S0 content key
covers the complete SFC because diagnostic positions are file-absolute. The
P5-1b row declares the host build, compiled features, filename and plugin
identity, version, code, visited node kinds, demanded facts, and plugin-owned
configuration or ambient values. The key implementation and its documentation
are checked together by `key_manifests`.

Cache opt-in requires `cacheInputs`, including an explicit empty list for a
pure rule. Duplicate or empty names are refused. Changing a captured value
invalidates independently of the function source. The host build identity
combines the Git revision and a hash of the plugin source closure and lockfile,
so a same-version host rebuild also invalidates. Unknown node kinds or demands
are refused before cache lookup.

A disk hit returns the exact mapped diagnostics. Writes use a temporary file
and atomic rename; absent, torn, or stale entries miss and are replaced. The
same result survives a new cache instance and a separate Node process.
