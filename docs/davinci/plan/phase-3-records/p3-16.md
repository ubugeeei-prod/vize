# P3-16 - Phase exit evidence ledger first slice

This slice makes the Phase 3 exit ledger executable without claiming that the
phase is complete. `tests/tooling/davinci-phase3-contract-status.test.ts`
cross-checks `phase-3.md` against the `phase-3-records/p3-*.md` files so that:

- completed TODO entries must have record files and terminal status text;
- record files cannot drift away from the TODO index;
- open tasks with landed slices must keep naming their remaining work.

The 2026-09-15 second slice also rejects sibling records that keep describing a
completed Phase 3 task as unfinished. That caught the stale P3-5 follow-up which
still said P3-3 needed TS-17/TS-20 evidence after P3-3 had closed.

P3-16 remains open until the backend parity, source-map coverage, Vapor bench,
remarks, and TS-27/28/29/30/20 gates listed in `phase-3.md` are terminal.

## Receipt policy

A `pass` row must name a 40-character source SHA, the canonical
`https://github.com/ubugeeei-prod/vize/actions/runs/<id>` URL, and an artifact
identity in the form `<name>@sha256:<64 lowercase hex characters>`. The tooling
guard rejects a checked phase gate without that complete receipt and refuses
the top-level P3-16 checkbox until every row passes and P3-6 is closed.

The Vapor performance row remains open while any relevant wall budget is the
report-only `0` seed or the committed benchmark baseline is empty. The legacy
retirement row remains open while the named Vapor/SSR legacy selectors or
their differential feature flags remain. This ledger records those blockers;
it does not select a threshold, change a production route, or delete a lane.
