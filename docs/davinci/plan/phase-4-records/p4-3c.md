## Producer and consumer

`UnusedBindings` is the seventh primary Croquis group. Its name key maps
to an exclusive declaration byte span in the `Bindings` script frame;
stratum 1 declares a dependency on `Bindings`. The producer only projects
authoritative `Croquis.unused_bindings` storage.

`SfcCroquisOptions::with_unused_bindings()` requests population from the
already parsed script AST, using OXC symbol/reference resolution. Reads
in closures, `defineExpose`, JSX and type queries count; unrelated shadows
and writes alone do not. The existing template walk removes actual reads,
component import aliases, namespace tags and custom directives. The shared
CSS scanner supplies style `v-bind()` reads. Invalid syntax, direct eval,
external blocks and unsupported dialect views cannot prove non-use.
An inline template without its supplied AST also cannot prove non-use;
the descriptor API witness checks missing-view, supplied-view and script-only cases.

Pug lint passes explicit derived-template provenance while preserving the
authored descriptor language and source map. Ordinary compiler options
leave population disabled. No new script parse or unconditional template
walk is added to the compiler route; no performance improvement is claimed.

`vue/no-unused-setup-bindings` lives in `rules/facts/`, is opt-in, Warning,
and tier Sound. Its declared demand is `UnusedBindings`; underscore names
are conventionally exempt. LintContext shares one fact manager per artifact
with `vue/no-undefined-refs`. Script-only SFCs use one descriptor draw.
