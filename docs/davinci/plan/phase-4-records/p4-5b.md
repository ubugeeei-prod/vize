# P4-5b: S2 expressions through the S4 document

Status: partial. This is an expression-span projection, not the production
virtual TypeScript generator. P4-5b and P4-5c remain open.

`vize_canon::projection::project_template_expressions` emits S2 expression
text into the shared `EmitDocument` and derives `ProjectionMapping` rows
from its span links. It has no second mapping representation.

`project_template_expression_document` accepts an already lowered S2 region
and returns that document directly. A future full-document consumer can reuse
its existing S2 tree without reparsing or lowering the template. The source
string entry still delegates to this emitter, so its mapping rows remain
unchanged. This entry emits expressions only; it does not replace the current
virtual TypeScript generator or close P4-5b/P4-5c.

The first slices covered interpolation and `v-bind` values. The next slice
adds `v-if` / `v-else-if` conditions, `v-for` sources, dynamic binding and
event names, handlers and object spreads, model reads, dynamic slot names,
and Vue value directives. Binding patterns are deliberately excluded:
loop aliases and slot parameters require scope emission rather than
standalone reference expressions. Model reads are emitted once; no setter
or type-flow claim is synthesized.

Nine regression tests pin the exact generated and authored byte ranges,
including nested control flow, object destructuring, event statements,
Unicode, CRLF, and the absence of rows for static / `v-pre` content.
The new cases failed on the interpolation-and-bind-only implementation.

Validation: `cargo test -p vize_canon --lib projection` (43 tests).
Remaining work includes scope/type emission, a complete virtual document,
the production consumer switch, three-generator removal, and corpus and
performance acceptance. None of those exits is claimed by these rows.

## TS-40 template anchors

The same projection and the current virtual-TS generator both run on every
template in `tests/_fixtures/davinci-ts40-projection/matrix.json` (12
fixtures). Each S4 anchor resolves to its own authored range. That range is
either an authored range of the current generator, or one opaque compound
interpolation (`{{` more than once) whose span contains the generator's
finer identifier ranges. Generated text is not compared. The comparison
count is pinned at 22. A zero run fails.

```
cargo test -p vize_canon --features davinci-differential --test davinci_projection_differential
```

## vize check diagnostics

`type_check_sfc` (the template-binding half of `vize check`) runs on every
`.vue` under `tests/_fixtures`. A diagnostic whose span sits in an
expression the current generator maps must sit in an S4 projection span
too. Script diagnostics are not projected. The comparison count is pinned
at 64. A zero run fails. tsgo is not required for this binding check.

```
cargo test -p vize_canon --features davinci-differential --test davinci_projection_differential
```
