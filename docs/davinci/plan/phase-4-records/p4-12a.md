# P4-12a — Style specification

**Landed 2026-09-22.** The mechanical acceptance holds. Charter #41's review point does not: the maintainer has not signed off the style direction, and no earlier phase pre-committed one. The fixtures are the proposal.

## What landed

[style-spec.md](../style-spec.md) is twenty-four rules, `S01`–`S24`. Each rule has `crates/vize_glyph/tests/style_spec/<id>/{input,output}.vue`. `output.vue` is the whole file under default options.

`node --test tests/tooling/davinci-style-spec.test.ts` is the bijection. It fails when a heading has no pair, a pair has no heading, a side of a pair is missing, or an id is duplicated. The orphan proof injects an `S99` directory into the checker; it does not mutate the tree. The same test locks the departures below against the fixture bytes, and checks that the single-attribute line and the suppressed line are past print width 100.

## Direction, for the review

Side-effect-stable canonical print:

- Top-level blocks stay in authored order. `vue/sfc-element-order` accepts both script-first and template-first, so `sort_blocks` default becomes false.
- Static literal attributes move only inside a barrier-free segment, by `vue/attribute-order`'s categories, authored order within a category. No alphabetical sort. Directives and bindings do not cross each other; a leftover attribute-order warning is accepted, a new one is not.
- `v-slot` follows `vue/v-slot-style`: default slot on a component stays `v-slot`, named slots use `#`.
- Void elements and empty components self-close (`<br />`, `<UserCard />`). Empty normal HTML elements stay paired (`<div></div>`). A broken self-closing tag puts `/>` on its own line.
- Script, plain CSS, and directive expressions are delegated to those printers. A non-HTML template language is reindented only. Pug layout is P4-12c.
