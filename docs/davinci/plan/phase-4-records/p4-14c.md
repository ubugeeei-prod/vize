## Complete producer pages (2026-09-26)

`vize explain --list` and `vize explain <code>` cover 397 distinct codes:
56 template compiler codes, 249 lint rules, 22 Canon type codes, 10 S3 verifier
codes and 60 cross-file codes. The new families expose their stable producer
metadata through `TypeErrorCode::ALL`, `ViolationCode::ALL` and
`CrossFileDiagnostic::CODES`. Canon uses its existing `ts/<n>` and
`ts/vue/<n>` catalog keys; S3 uses the published `S3V00x` code; cross-file
codes retain the `vize:croquis/cf/` prefix.

Every page uses the existing locale message and help. Type, verifier and
cross-file pages identify the producer without claiming a severity or domain
that can depend on an individual diagnostic. Existing compiler and lint pages
remain byte-identical. Full en/ja/zh snapshots add exactly 92 pages each.

TS-53 derives the expected page headers directly from the producer definitions,
not from the new metadata lists: Canon's enum/help mapping, S3's code mapping,
cross-file `code()` literals, compiler metadata and lint rule declarations.
Missing or stale metadata therefore fails the page coverage check. The Rust
suite verifies every new page against its message/help catalog in all three
locales, uniqueness and code lookup. Removing a known page is still a tested
failure of the mechanical check.

## Witness acceptance
