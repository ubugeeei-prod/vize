# P6-5 — ExprRef validation from the MoonBit implementation

Recorded 2026-09-26. MoonBit exercises the foreign branch of `ExprRef`, its
capability adapter, source spans, checker boundary and projection pages.
P6-4b retains its automatic producer, full matrix and maintainer review gates.
This report classifies the measured findings from the implemented slices.

## Fix status

`Fixed, merged` identifies a landed implementation. `Fixed, pending` identifies
an implementation and exact tests in [PR #6795](https://github.com/ubugeeei-prod/vize/pull/6795),
which still requires its merge. Deferred entries state the remaining work and
why a substitute would not satisfy the contract.

  pinned compiler from `.moonbit-version`; includes 13 lowered foreign payloads,
  the UTF-8 boundary fallback, twelve typed expressions and seven mapped type

  dependency closure keeps Wasmtime confined to the optional host.

  canonical surface bytes and every version transition.
