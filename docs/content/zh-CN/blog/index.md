## 如何发布

- 在 `docs/content/blog/releases/` 中实时发布帖子。
- `docs/content/blog/notes/` 中存在不规则帖子。
- 使用 `YYYY-MM-DD-slug.md` 作为文件名，以便帖子保持可排序。
- 从 `docs/templates/blog-release.md` 或 `docs/templates/blog-note.md` 开始。
- 新帖子显示在文档树中的匹配部分下。
