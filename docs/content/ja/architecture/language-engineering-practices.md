# 言語工学の実践

Vize は Vue ツールチェーンですが、コンパイラーと同じ障害モードがあり、構文の小さな変更により、
移動診断、コード生成、エディターの動作、パッケージ出力、パフォーマンスを同時に実行
時間。このページには、Vize が成熟したコンパイラーと型から採用した言語処理の実践が記録されています。
チェッカー リポジトリを作成し、それらを Vize 独自のフィクスチャ、スナップショット、パリティ テスト、ベンチマークにマッピングします。
そしてゲートを解放します。

## ベースラインポリシー

- 最も小さな失敗例または実例となるケースから始めて、次に、より広範なフィクスチャを受け入れられるのは、
  横断的な行動を証明します。
- スナップショット ファイルとベースライン ファイルはユーザーに表示されるコントラクトです。 diff によって診断が変更された場合、生成される
  コード、パブリック CLI 出力、またはエディターの動作について、PR は新しい出力が正しい理由を説明する必要があります。
- 揮発性データがベースラインに達する前に正規化します。パス、タイミング、ハッシュ、環境
  詳細によりスナップショットのチャーンが繰り返し発生しないようにする必要があります。
- パリティアーティファクトを明示的に保ちます。 `tests/snapshots/check`、`tests/snapshots/lint`、現実世界
  フィクスチャのスナップショットと Vue パリティ マトリックスが互換性レコードです。
- PR がそれらの出力に関するものでない限り、大規模なスナップショット ベースラインを更新しないでください。多数のファイルを移動する場合
  共通の原因についての短い説明を一緒に含めます。

## エスカレーションのトリガー

変化が次のいずれかの形である場合は、より広範な証拠を入手します。

- 構文、変換、または仮想 TypeScript の動作は、通常の Vue アプリケーションに影響を与える可能性があります。
  現実世界のフィクスチャを追加または更新し、公式の Vue ツールとの同等性を説明します。
- 生成されたコード形状、キャッシュ、プロジェクト グラフのトラバーサル、または型認識分析が移動する可能性があります。
  スループット: サーフェスと一致するローカル ベンチマークを実行し、PR ベンチマーク バジェットに依存します。
- URL処理、HTML/SSR出力、構成ロード、パッケージ公開、ネイティブロード、CI、または
  認証情報に隣接するコードの変更: セキュリティ監査ステータスを記録し、焦点を絞った回帰を追加します。
  境界がまだ守られていることを証明します。
- パーサーの回復、任意のバイト入力、CSS/テンプレート/式の解析、またはクラッシュの修正: 実行または
  一致するファズターゲットをスケジュールし、再現器を保持し、最小化された決定論的結果を取得します。
  修正リクエストを閉じる前に回帰を確認してください。
- LSP、エディター、クイックフィックス、完了、ホバー、または増分動作の変更: シナリオレベルの追加
  最終的な診断だけでなく、ユーザーに表示されるシーケンスを実行するカバレッジ。
- スナップショットは、パス、ハッシュ、順序、タイミング、環境、またはホスト プラットフォームによって変更されます。
  最初に正規化してから、残りの差分が意味のある場合にのみベースラインを受け入れます。

## 運用上のガードレール

Vize は、メモリに依存する代わりに、これらのプラクティスを実行可能に保ちます。

- `CONTRIBUTING.md` は、貢献者向けのクラス変更規律に名前を付けます。
- `.github/PULL_REQUEST_TEMPLATE.md` は、行動の参照、リスク、検証証拠を求めます。
- `bench/test-inventory.mjs` は、PR CI の現在のテスト資産インベントリをレポートします。
- `.github/workflows/benchmark.yml` は、ベース CLI とヘッド CLI のパフォーマンスを比較し、PR 予算を適用します。
- `.github/workflows/check.yml` は、実稼働 npm および Rust の `security-audit` ジョブを実行します
  依存関係に関する勧告。
- `.github/workflows/fuzz.yml` は `tests/fuzz` カーゴファズ ワークスペースを実行し、アップロードがクラッシュします
  パーサー/コンパイラーのトリアージのための再現者。
- `docs/release/production-readiness.md` および `docs/release/vue-parity-matrix.md` は、いつ
  動作は実稼働対応または互換性があると言えます。
- `tests/tooling/language-engineering-practices.test.ts` はこのページ、貢献ガイドを保管しています。
  PR テンプレートを結び付けます。
