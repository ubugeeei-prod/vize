Vize は新たな段階に入っています。

これまでの開発は、機能の実装、インフラストラクチャの構築、
専用のテストスイートと合成サンプルを通じて動作を検証します。

次のステップは異なります。

私たちは現在、Vize をテストする**現実世界のプロジェクト**を積極的に探しています。

## 目標

このフェーズの目標は、互換性のギャップ、仕様のギャップ、
パフォーマンスのボトルネック、および運用コードベースでのみ現れるエッジケース。

Vue アプリケーション、ライブラリ、フレームワーク、またはツールをメンテナンスしている場合は、ぜひご連絡ください。
Vize で実行した経験について。

すべての修正レポート、再現、ベンチマーク結果、および互換性の調査結果が移行に役立ちます
プロジェクトは最初の安定版リリースに近づいています。

## まだ実験中 — 正確さが第一

Vize はまだ実験的であると考えるべきです。重大な変更が発生する可能性があります。修正は
依然として期待されており、特定のシナリオでは動作が Vue と異なる場合があります。

このフェーズの焦点は機能開発ではありません。焦点は正しさです。
現在、現実世界のアプリケーションがテスト スイートになっています。修正が必要な問題が発生した場合は、
報告してください — すべての報告は、コンパイラ、言語仕様、および
エコシステム全体。

## 助ける方法

たくさんの修正リクエストやPRをお待ちしております。リーズナブルな採用活動も積極的に行っております
テストベッドとして使用する大規模な Vue プロジェクト — コードベースが大きくなり、より現実的になるほど、
貴重な信号です。実質的な Vue アプリケーション、ライブラリを保守している (または知っている) 場合、
フレームワークまたはツールについては、修正リクエストをオープンするか、それに対して Vize を実行できるように連絡してください。修正
レポート、複製、ベンチマーク結果は大歓迎です。

出力を検査する方法については、[テストとフィードバック](../../guide/testing.md) ガイドを参照してください。
プレイグラウンド、既存のテスト ケースを読み、`vize check --profile` でプロファイルを作成し、プロジェクトを提供します
E2E / VRT テストベッドとして。

## v1.0.0 へのロードマップ

現在のフェーズは**現実世界のテスト**です。

Vize がこのフェーズを正常に完了すると、プロジェクトは次のように進みます。

- v1.0.0-アルファ
- v1.0.0-ベータ版
- v1.0.0-rc
- v1.0.0

アルファ、ベータ、リリース候補の段階では、安定化とエコシステムに焦点を当てます。
互換性、パフォーマンスの向上、長期保守保証。

目標は、急いで 1.0 に到達することではありません。目標はそれを獲得することです。

Vize の未来の形成を支援することに興味がある場合は、今が最適なタイミングです。
関与している。
