# 範囲別のコンパイラ設定

プロジェクトの一部だけ別のコンパイラ設定にしたい場合は、`entries[].compiler` を使います。たとえば、空白を書いたとおりに残す必要があるディレクトリがある場合です。
エントリは、[設定](./configuration.md)で説明している共有設定に書きます。エントリで上書きできる設定は、[Vite プラグインのコンパイラオプション](./vite-plugin.md#compiler-options)にまとめています。

```json
{
  "compiler": { "whitespace": "preserve" },
  "entries": [
    {
      "basePath": "src/condensed",
      "files": ["**/*.vue"],
      "ignores": ["generated/**"],
      "compiler": { "whitespace": "condense" }
    }
  ]
}
```

エントリの `basePath` は、プロジェクトのルートからの相対パスとして解決されます。一致したエントリは、宣言した順にトップレベルのコンパイラ設定へ重ねられ、後のエントリほど優先されます。`vize({ ... })` にプラグインのオプションとして明示した値は、共有設定より優先されます。ファイルのパターンと除外パターンでは、順序付きの `!` による否定、ディレクトリ単位の指定、波かっこ、隠しファイルを使えます。

範囲別の設定は、事前コンパイル、クライアントと SSR の読み込み、HMR のすべてに適用されます。事前コンパイルでは、実際に適用される設定が同じファイルをまとめて処理します。ディスクキャッシュの識別子にも設定した範囲が含まれるため、エントリのコンパイラ設定を変更すると、以前の設定でコンパイルした出力は再利用されません。
