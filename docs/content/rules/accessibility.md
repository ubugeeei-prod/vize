# Accessibility Rules

Accessibility rules are Patina single-file template rules. All rule detail pages below are peer
references: preset membership changes where a rule is enabled by default, but it does not create a
lower-priority "additional" tier. Current accessibility rules take no `linter.ruleOptions`;
configure severity with `linter.rules`.

## Rule Detail Pages

- [Core Markup](./accessibility-core.md): text alternatives, anchors, ARIA basics, keyboard click
  parity, and form labels.
- [Structure](./accessibility-structure.md): headings, iframe/image text, focus support, labels,
  landmarks, and media captions.
- [Interactions](./accessibility-interactions.md): hover/focus parity, shortcut safety, hidden
  focus targets, autofocus, distracting elements, icon markup, redundant roles, and ID references.
- [Integrity](./accessibility-integrity.md): presentation roles, static interaction handlers,
  placeholder labels, required ARIA props, tab order, list semantics, and unique element IDs.
