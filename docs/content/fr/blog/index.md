## Comment publier

- Les publications de lancement sont en direct dans `docs/content/blog/releases/`.
- Les publications irrégulières sont présentes en `docs/content/blog/notes/`.
- Utilisez `YYYY-MM-DD-slug.md` pour les noms de fichiers afin que les publications restent triables.
- Commencez par `docs/templates/blog-release.md` ou `docs/templates/blog-note.md`.
- De nouveaux posts apparaissent dans la section correspondance dans l’arbre de documentation.
