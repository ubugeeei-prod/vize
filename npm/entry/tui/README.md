# @vizejs/tui

Build terminal UIs with Vue. `@vizejs/tui` is the discoverable name of
[`@vizejs/fresco`](https://github.com/ubugeeei-prod/vize/tree/main/npm/fresco): every entry point
(`@vizejs/tui`, `@vizejs/tui/components`, `@vizejs/tui/ascii-font`, `@vizejs/tui/composables`, `@vizejs/tui/testing`, `@vizejs/tui/qr-code`) re-exports the matching Fresco module.

```bash
vp install @vizejs/tui vue
```

```ts
import { createApp } from "@vizejs/tui";
```
