for [#7935](https://github.com/ubugeeei-prod/vize/issues/7935), including its
referenced [#7932](https://github.com/ubugeeei-prod/vize/issues/7932) project.

and original command are retained unchanged. The report supplies the Nuxt
config inline; its minimal single-line carrier preserves that exact code.
The two page bodies were not supplied and are explicitly authored carriers.

The reported Nuxt project is an empty-report law under the original off
config. The separate authored application has an imported default SFC root
and unconditional `createApp(App).use(router)` bootstrap. Its unknown name,
missing param, extra param and array-valued non-repeatable param remain real
diagnostics when app ownership stops accepting the report's throwaway test

HTML carrier imports a child whose div root closes its parent's paragraph.

time; they do not add Vue compiler inputs to the unrelated remarks corpus.
