      Problem: provide('owner', value) passes a plain value to consumers.
      Why this matters:
      - Consumers that call inject() receive a snapshot-like value.
      - Later provider updates will not be visible unless consumers receive a ref or computed value.
      Safer patterns:

      Name collision example:

        provide('owner', myData)

        provide('owner', otherData)  // Collision!
      Type-safe pattern with InjectionKey:
      
        // injection-keys.ts
        import type { InjectionKey, Ref } from 'vue'
        
        export interface UserState {
        name: string
        id: number
        }
        
        export const UserKey: InjectionKey<Ref<UserState>> = Symbol('user')
        
        // Provider.vue
        import { UserKey } from './injection-keys'
        provide(UserKey, userData)  // Type-checked
        
        // Consumer.vue
        import { UserKey } from './injection-keys'
        const user = inject(UserKey)  // Type: Ref<UserState> | undefined
      Suggestion: Define an InjectionKey, for example const ownerKey: InjectionKey<...> = Symbol('owner'), then use it in provide() and inject()
