      WARNING vize:croquis/cf/non-reactive-provide
      provide('owner') value is not reactive - consumers won't see updates
      Problem: provide('owner', value) passes a plain value to consumers.
      Why this matters:
      - Consumers that call inject() receive a snapshot-like value.
      - Later provider updates will not be visible unless consumers receive a ref or computed value.
      Safer patterns:
      
        provide('owner', ref(value))
        provide('owner', computed(() => value))
      Suggestion: provide('key', ref(value)) or provide('key', computed(() => value))
