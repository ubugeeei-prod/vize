# Open-buffer alias definition regression

`case.json` binds the authored sources, complete response expectations and
unchanged original before evidence by SHA-256. The dedicated real-CLI consumer
is `crates/vize/tests/lsp_open_buffer_alias_definition_cli.rs`.

The dependency sources are opened without copying them to disk until the
explicit saved-file phases. Relative and configured-alias component tags must
return the same complete scalar Location at the file origin. Closing an absent
dependency returns exactly `null`. Target-array controls preserve a saved
fallback and restore it after an open first candidate closes. Both LF and CRLF
sessions use encoded UTF-8, space and `#` paths; brackets retain the URL library's
ordinary file-path representation.

`historical-5ed/` preserves the original independent before observation. It is
observed failure evidence, not an expected-response generator. The archived
native binary is not a current-main whole build, external Corsa proof or public
release. The new goldens are independently authored, with only the temporary
absolute target URI substituted at execution.

This corpus is deliberately consumed directly: the generic differential LSP
manifest cannot represent definition lifecycle transitions. No existing corpus
input, expected response, omission policy or performance ceiling is changed.
