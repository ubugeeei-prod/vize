# Slot modifier option controls

These twelve authored scriptless SFCs extend, rather than rewrite, the original
47-case slot validity corpus and 16-case retained-binding corpus.
`controls.json` declares complete source packets for false/true options and
exact directive spans. `additions.json` names three new default-policy findings
on unchanged original inputs. `consumers.json` declares whole source CLI and
JSON-RPC diagnostics, including scalar CLI columns and UTF-16 LSP positions.

`independent.json` retains 48 complete pinned ESLint/Vue observations: twelve
inputs, two option settings and two repetitions. It includes the official Vue
base processor and mandatory rules. Only each exact physical recording path is
replaced by its authored filename; all other packet fields remain intact.
Fresh independent responses are persisted before comparisons.

The real source-built consumer runs in the existing n8n Actions workflow. Root
true, scoped false and disabled-rule routes retain whole process responses,
repeat packets, outside-cwd CLI results and full raw JSON-RPC session bytes.
Installed public qualification and the original adoption umbrella stay separate.
