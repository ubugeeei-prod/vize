# Complete slot parameter controls

These 24 independently authored scriptless SFCs add a bounded parameter-rule
campaign. The original 47 slot-validity cases, 16 retained-binding cases,
12 modifier controls, provider pins, history packets and 125 consumer vectors
remain unchanged. `controls.json` records SHA-256 custody for 13 existing files.
The new oracle test rechecks those original bytes before qualification.

The cases cover shorthand and positional defaults, nested patterns, object,
array and top-level rest, TypeScript annotations, multiple and optional
parameters, computed-key and default-RHS reads, lambda shadowing and capture,
escaped and Unicode identifiers, entity decoding, CRLF and closed block
comments, malformed method/accessor/rest/unbalanced headers, a default own
binding with `.modifier`, and outer-scope and clean static controls.

`controls.json` declares complete English Patina packets for both option values.
`consumers.json` declares complete CLI and JSON-RPC diagnostic packets.
Byte ranges, scalar CLI columns and UTF-16 LSP positions come from the unique
authored directive span in the input source, never from Vize output.
Parameter AST coordinates remain relative to decoded `parameterRaw`.
An entity before a declaration therefore creates a gap between that decoded
offset and the physical authored offset; this campaign claims no entity map.

`independent.json` retains 96 complete official observations: 24 sources,
two `allowModifiers` settings and two executions. All four original provider
version and entry SHA-256 pins are preserved, together with the official
`vue/base/setup-for-vue` processor and mandatory rules. Only the exact physical
recording `filePath` becomes its authored filename. Fresh complete raw responses
are persisted before comparison; no message, diagnostic field or source byte
is removed.

claim semantic equivalence for the two cases or completion of n8n adoption.
