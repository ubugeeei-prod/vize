# Rare dialect inputs

`grammar.json` is the source for `generated/*.html` and `inventory.json`.
Each case has a stable `dialect/...` ID, source witness, dialect selector,
parser mode and source SHA. Run:

```sh
vp node tools/support/compat/fixtures/generate-dialect-inputs.mjs --check
```

Use `--write` only when changing the grammar, then review the generated bytes
and hashes. These rows are inputs only. They are not legacy observations,
native executions or product differential cases; product manifests must
reference each input explicitly before it counts toward acceptance.
