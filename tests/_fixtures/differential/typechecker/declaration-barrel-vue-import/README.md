# Declaration barrel to Vue type imports

The whole authored minimal project compares a direct TypeScript import with
the generated declaration barrel `#imports -> imports.d.ts -> useWidget.ts ->
Widget.vue`. It uses the installed Vue package and the normal public batch
checker, followed by the same materialized project through actual Corsa.

The mandatory native law retains every raw and mapped diagnostic, the full
authored sources and projections, provider manifest, selected config, normalized
options, program roots, and the diagnosing process's `getSourceFileNames` request
and response. The absent neighbor must remain TS2307. Replacing the valid number
with a string must add exactly TS2322, and repairing it may remove only TS2322.
No authored TypeScript module may enter native through the original tree when
that module already has a registered projection.
