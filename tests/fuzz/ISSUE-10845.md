# Expression timeout #10845 and overlapping probes #10682

Original campaign: https://github.com/ubugeeei-prod/vize/actions/runs/40305930405

Original source: `bac765899e0ca6949543c19db821c048dceb99d9`; job `121514902323`;
artifact `12642352904` (`fuzz-reproducers-js_ts_expression`). The primary
`timeout-223ca3e643b6ed7fd0e6528bbc75025544554eaa` input is retained byte for byte as
`regressions/js_ts_expression/issue-10845.input` (23,857 bytes, SHA-256
`60c49daaab7e06a062b0ffa7dced0eb4ddab9dbee1b52f1657fc4f1c08aa14a5`).
The original artifact's two preceding slow units are retained as `.slow-1.input`
and `.slow-2.input`; the audit case manifest verifies all three identities.
The original log reports 27 seconds on the last unit under a 25-second libFuzzer
limit. That historical emitted binary was not archived; rebuilt baseline runs
must be identified separately from the historical campaign observation.

The `.min.input` fixture is a separate 2,133-byte reduction from the primary
input, found by deleting contiguous ranges while preserving admission and the
slow, rejected parse. It does not replace the original. Its SHA-256 is
`73e51fe565438b9e18d8696f4bc57d368310898539e1f406387b7592a9e1a926`.

The existing last-raw-`>` necessary-condition shortcut cannot reject overlapping
probes before a later `>>>>>>>`. Distinct speculative openers repeatedly descend
through the same remaining tuple/computed-property/array expression subproblems.
The original type and assignment production bodies remain unchanged. A new
wrapper reuses only proven fatal subproblems inside expression type-argument
transactions; the committed parse still produces its own AST and diagnostics.

Keys retain the production and its parameters, parser/lexer tokens, lexer
position, previous token end, all grammar flags, trivia state and persistent
side-effect revisions. A subproblem which changes cover tables, module records,
comments, deferred diagnostics or await tracking is not stored. Monotonic
revisions detect writes even when collection lengths stay equal. Reuse restores
the failed end token and trivia state before unwinding and the owning probe
rewinds normally. Successful generics do not construct memoization keys until a
failed type-argument probe has enabled sharing. Tables are per parser, never
shared across source files or cold invocations.

`speculation::tests` compares full Program, expression, token, comment,
diagnostic, module-record and source-fact packets against the unchanged
production bodies with sharing disabled. The original input also has a causal
subproblem-visit regression, rather than a wall-clock-only assertion.

`.github/workflows/expression-overlap-audit.yml` builds immutable baseline
`9157b9fa83dbdc98100be084be288f21d0d1bc18` and candidate with the same frozen driver,
pinned toolchain and initially absent compiled targets. It retains complete
before/after packets, five fresh-process timing samples per case, Callgrind
instruction counts and source attribution, sanitizer build commands, exact input
and binary hashes, and maximum-RSS receipts. Every timing iteration creates a
fresh allocator and parser; OS caches are not flushed. These are parser-phase
measurements, not a claim about cold project-wide checking.

The audit includes the unchanged #10401 original, its same-length `// x`/`// >`
append pair from #10682, and its separate 4K/8K/16K raw prefix controls. Those
prefixes and the small `a < [a < [` family do not pass admission and remain
explicitly raw parser controls. All admitted original/reduced/suffix inputs must
still reach the parser. The guard, `-max_len=65536`, `-timeout=25`,
`-rss_limit_mb=4096` and `-malloc_limit_mb=2048` are unchanged. The candidate must
replay all three original artifacts and the reduced/suffix cases under the same
address-sanitizer/libFuzzer regime. Baseline sanitizer exit receipts are retained
whether the rebuilt source crosses the historical timeout or completes.

The 25 original #10682 inputs and complete Program/control packets are also
retained losslessly in `tools/support/compat/parser/historical-10682.tar.gz`
(SHA-256 `780df7dfa9517de9155d5dffa8ec167a1f9c98391f1dd107f735be80d361185a`).
The archive includes the original manifest, summary, source provenance and
per-packet identities from run `40207210136`, artifacts `12604715691`,
`12604018848` and `12604895472`. Original baseline and candidate packets were
byte-identical before deduplication into the archive. The historical observer
source is copied byte for byte from audit commit
`df2bfdef0313791c05026efd0371bed6f3c06823`; its source SHA-256
`9d095b94ec587d9f22cfa696a1bb5c6bd23813eced6a633d2989c6a270f05238`
matches the original provenance. Both new source builds must reproduce these
historical full packets, in addition to their broader paired observation modes.

Raw source-fact booleans on recovered/fatal programs are private parser state.
The audit copies the same frozen `#[cfg(test)]` observer module into both source
checkouts and retains the overlay diff and driver hash. This test-only bridge
writes both booleans for every case/profile without changing production APIs or
parser behavior. External drivers use the existing admitted-observation API;
they cannot forge access to recovered syntax authority. The final corpus is 41
cases, giving 1,640 paired public Program/expression packets, 820 raw private-fact
observations per source, and the 25 complete historical Program/control packets.
