## Why not `ui.bind`

`ui.bind` is the **template** one-way binding. CSS `v-bind(color)` has
no JSX twin (P2-16's fairness litmus) and points into a style block, so
it is a `vue.*` dialect op. The op carries two spans: the call
(`VueCssBindOp::span`) and the argument (`ExprRef`'s span). Both are
**block-relative** via `Span::to_block_relative` against the style
block's content start. A shifted `block_start` prints identically.

## Why not atelier_sfc

The five named sites (`css/transform.rs`, `transform_css_v_bind`,
`extract_css_vars`, `descriptor.css_vars`, `setup_emit.rs`) remain the
**compile** path. They produce expr-text lists and rewrite CSS to
`var(--…)`. P2-10's non-goal freezes those names
(`scoped_v_bind_name` / `prod_scoped_v_bind_name`). Putting S2 ops
inside the published crate would either (a) depend on unpublished
Davinci crates (the release gate forbids it) or (b) change emission.
The conversion therefore lives in `vize_ricalco`, `publish = false`,
with a scanner that mirrors the shipped finder (strings/comments are
not calls; `my-v-bind(` / `-webkit-v-bind(` need a left boundary) so
the expr-text census matches without sharing a graph edge.

`descriptor.css_vars` is still the emit feed. S2 ops are the span-bearing
facts lint / lattice / type projection were missing (charter #13). Those
consumers are phase 4; this task only makes the ops exist.

## ExprRef (P2-5b applied here first)

CSS `v-bind()` contents go through `ExprRef::parse_js_in`. Identifiers
and real JS (`parentBg ?? 'var(--bg)'`) are `js(...)`. Text the
retained contract refuses — the shipped extractor's comment-bearing
`color /* keep ) inside comments */` — is `opaque(parse-rejected)`,
pessimal from the first byte. No new `OpaqueReason`.

## The carrier

Style blocks never enter the template `SurfaceTree`. Lowering emits a
carrier `ui.element style` whose bindings are the calls and whose
children are empty (the CSS is not duplicated as `ui.text`).
`Lowered::push_style_block` appends that carrier after the template
tree and keeps `op_count` equal to the folio header.

**P2-11 must skip this carrier.** It is not a DOM `<style>` vnode; SFC
styles compile through atelier_sfc. Recorded so realization cannot
"just walk every `ui.element`".
