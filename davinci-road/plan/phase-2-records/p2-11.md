# P2-11 — DOM backend on S2 (series record)

**An explicitly marked small series** (the plan README's permitted
exception): one reviewable PR per emit increment, all under this ID.
This record grows one installment file per landed PR; the task's box
in `phase-2.md` stays **unticked** until the series completes the
acceptance gate. Do not invent installments that have not merged to
`origin/main`.

The S1-to-S2 emit test-consumer import path is `vize_s1_to_s2::emit`;
the physical package still uses the codename `vize_ricalco` until a
dedicated naming slice. `vize_atelier_dom` is published and cannot name
unpublished Davinci crates in its release graph. The current decision is a
firewall: S2 DOM witnesses live in atelier_dom **test space** through
dev-dependencies that are stripped on publish, and the tooling gate rejects any
unstripped edge from a publishable crate into an unpublished stage crate. The
old DOM lane is still the shipped compile path. The exit gate is unchanged.

The `emit.rs` module docs keep a running capability list. **This
record's landed numbers are the forty `origin/main` PRs**, not that comment.

## Current named remainder (after #5214)

Installment 20 closes the dynamic-argument `v-bind` key/modifier item that the
installment-19 snapshot correctly left open. The current `emit.rs` capability
list names both static and dynamic keys as realized into the shipped DOM
prop-key shape. Installment 21 removes the Vue 2 pipe-filter refusal surface:
`legacy-sugar` rewrites filter expressions into `_filter_*` calls, the emitter
resolves `_resolveFilter`, and the byte-differential witness covers
interpolations, bindings, component slots, slot outlets, and Vue 3 pipe
non-filter behavior. The historical installment-19 remainder is preserved in
[`installment-19.md`](./p2-11/installment-19.md), not presented as current.
Installment 22 closes the follow-up helper-order and patch-flag surface for
Vue 2 filters. Installment 23 closes the slot-outlet same-name surface:
value-less and blank `:name` / `v-bind:name` now lower to the runtime `name`
expression like the shipped DOM lane. Installment 24 expands the patch-flag
witness across component props/listeners, native and component `v-model`,
object-spread merge flags, component object bind, and nested dynamic slots.
Installment 25 extends that matrix across dynamic component `:is` exclusion,
dynamic component object bind, named component `v-model`, and component
`v-model` modifiers. Installment 26 pins component `v-model` with an explicit
`@update:modelValue` listener in both source orders, including the shipped
dynamic-prop array order. Installment 27 realizes component `v-model:[arg]`
directly from S2: `ui.model` carries the argument as `DynamicName`, Folio
round-trips it with `name=`, the DOM emitter computes model/update/modifier
keys, and dynamic arguments select `FULL_PROPS` while static arguments keep
`PROPS` plus the shipped dynamic-prop array shape. The P2-9 surface/hoist
comparator no longer has a dynamic-model-argument skip class.
Installment 28 closes the P2-10 style-carrier remainder: SFC style-block
`vue.css-bind` carriers remain S2 facts for consumers, but root-fragment
selection and DOM emission skip them while preserving page-order id
accounting; authored template `<style>` elements remain real DOM nodes.
Installment 29 admits bare `<template>` children as implicit default slot
content and hoists them byte-for-byte like the shipped DOM lane. It also
threads the already-discovered `ui.slot-content` proof into `createSlots`
entry emission, retiring the stale `CreateSlotsMissingSlotTemplate` local
guard instead of keeping a second impossible lookup.
Installment 30 keeps authored slot-template carriers inert for `v-once` and
`v-memo` while preserving a source-covered `SlotDefaultShape` refusal for
truly unsupported extra directives. Installment 31 closes the named malformed
slot fact gap: nested and stray slot-template carriers now emit through the
shipped inline-template fallback in slot bodies, native children, `createSlots`
entries and slot fallback arrays.
Installment 32 realizes well-formed `v-show` directly from S2: the lowering
admits `vue.show`, Folio round-trips `vue.show value=`, and the DOM emitter
wraps native elements and components in runtime `vShow` directive entries while
preserving shipped helper order, patch flags, `v-for` empty-props shape, custom
directive order, and native `v-model` listener keys.
Installment 33 realizes `v-html` directly from S2: the lowering admits
`vue.html` on elements and slot outlets, Folio round-trips value-bearing and
value-less forms, and the DOM emitter writes shipped-compatible `innerHTML`
props with exact patch-key order across native, component, slot, structural,
object-spread, custom directive, and native `v-model` cases. Argument and
modifier spellings remain deferred.
Installment 34 realizes `v-text` directly from S2: the lowering admits
`vue.text` on elements and slot outlets, Folio round-trips value-bearing and
value-less forms, and the DOM emitter writes shipped-compatible `textContent`
props through `_toDisplayString`, including `undefined` for value-less
spellings, exact dynamic-prop arrays, object-spread merge flags, slot props,
and native `v-model` listener ordering. Argument and modifier spellings remain
deferred.
Installment 35 realizes `v-cloak` directly from S2: the lowering admits every
compiler-compatible `Head::Cloak` spelling as the presence-only `vue.cloak`
marker, Folio round-trips it, and the DOM emitter removes it from props while
preserving shipped patch flags, slot elision, component no-op shape, and the
`v-for` empty-props marker the shipped lane keeps for inert directives.
Installment 36 realizes slot outlet `v-on` props directly from S2: named and
dynamic listener props emit through the same handler helpers as the shipped DOM
lane, slot outlet spread props keep the shipped `v-bind` object / object
`v-on` / entry-prop order, duplicate listener props keep duplicate object keys,
and byte witnesses cover fallback, `v-if`, `v-for`, forwarded scoped-slot
locals and Vue 2 `.native` behavior.
Installment 37 realizes object `v-bind` modifiers directly from S2: object
spreads carrying `.prop`, `.attr` or `.camel` now preserve the spread
expression and emit through the same `normalizeProps` / `mergeProps` shape as
the shipped DOM lane, while the source-level `object_bind_has_modifiers`
refusal bucket retires into the closed catalogue.
Installment 38 realizes object `v-on` modifiers directly from S2: object
spreads carrying option modifiers now preserve the handler expression and emit
through the same `_toHandlers(expr, true)` shape as the shipped DOM lane, while
the source-level `object_on_has_modifiers` refusal bucket retires into the
closed catalogue.
Installment 39 widens the exact patch-site witness across the late directive
and object-spread surfaces: `v-show`, `v-html`, `v-text`, `v-cloak`, object
`v-bind` modifiers and object `v-on` modifiers now share a dedicated
S2-vs-shipped per-node patch-flag test. This is a witness expansion, not a
production-lane switch.
Installment 40 pins the current publish graph decision. The stage crates remain
unpublished in this phase, but publishable crates may exercise them only through
dev-dependencies that Cargo strips on publish. A normal or build dependency from
a publishable crate into `vize_davinci`, `vize_s1`, `vize_s2` or
`vize_ricalco` is now a tooling failure, so the old DOM lane cannot be replaced
by an accidental unresolvable release graph edge.

The series is not done. Waiver budget remains zero. The old DOM lane remains
the shipped path; the hydrated full-corpus comparison count, patch-flag
equivalence and DOM allocation budget are still task-level blockers. The flag's
deletion is still an exit-gate line, not this record's to tick.
