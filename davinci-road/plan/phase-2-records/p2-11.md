## Current named remainder (after #5200)

Installment 20 closes the dynamic-argument `v-bind` key/modifier item that the
installment-19 snapshot correctly left open. The current `emit.rs` capability
list names both static and dynamic keys as realized into the shipped DOM
prop-key shape. Installment 21 removes the Vue 2 pipe-filter refusal surface:
`legacy-sugar` rewrites filter expressions into `_filter_*` calls, the emitter
resolves `_resolveFilter`, and the byte-differential witness covers
interpolations, bindings, component slots, slot outlets, and Vue 3 pipe
non-filter behavior. The historical installment-19 remainder is preserved in
[`installment-19.md`](./p2-11/installment-19.md), not presented as current.
Installment 22 closes the follow-up helper-order and patch-flag surface for
Vue 2 filters. Installment 23 closes the slot-outlet same-name surface:
value-less and blank `:name` / `v-bind:name` now lower to the runtime `name`
expression like the shipped DOM lane. Installment 24 expands the patch-flag
witness across component props/listeners, native and component `v-model`,
object-spread merge flags, component object bind, and nested dynamic slots.
Installment 25 extends that matrix across dynamic component `:is` exclusion,
dynamic component object bind, named component `v-model`, and component
`v-model` modifiers. Installment 26 pins component `v-model` with an explicit
`@update:modelValue` listener in both source orders, including the shipped
dynamic-prop array order. Installment 27 realizes component `v-model:[arg]`
directly from S2: `ui.model` carries the argument as `DynamicName`, Folio
round-trips it with `name=`, the DOM emitter computes model/update/modifier
keys, and dynamic arguments select `FULL_PROPS` while static arguments keep
`PROPS` plus the shipped dynamic-prop array shape. The P2-9 surface/hoist
comparator no longer has a dynamic-model-argument skip class.
Installment 28 closes the P2-10 style-carrier remainder: SFC style-block
`vue.css-bind` carriers remain S2 facts for consumers, but root-fragment
selection and DOM emission skip them while preserving page-order id
accounting; authored template `<style>` elements remain real DOM nodes.
Installment 29 admits bare `<template>` children as implicit default slot
content and hoists them byte-for-byte like the shipped DOM lane. It also
threads the already-discovered `ui.slot-content` proof into `createSlots`
entry emission, retiring the stale `CreateSlotsMissingSlotTemplate` local
guard instead of keeping a second impossible lookup.
Installment 30 keeps authored slot-template carriers inert for `v-once` and
`v-memo` while preserving a source-covered `SlotDefaultShape` refusal for
truly unsupported extra directives. Installment 31 closes the named malformed
slot fact gap: nested and stray slot-template carriers now emit through the
shipped inline-template fallback in slot bodies, native children, `createSlots`
entries and slot fallback arrays.
Installment 32 realizes well-formed `v-show` directly from S2: the lowering
admits `vue.show`, Folio round-trips `vue.show value=`, and the DOM emitter
wraps native elements and components in runtime `vShow` directive entries while
preserving shipped helper order, patch flags, `v-for` empty-props shape, custom
directive order, and native `v-model` listener keys.
Installment 33 realizes `v-html` directly from S2: the lowering admits
`vue.html` on elements and slot outlets, Folio round-trips value-bearing and
value-less forms, and the DOM emitter writes shipped-compatible `innerHTML`
props with exact patch-key order across native, component, slot, structural,
object-spread, custom directive, and native `v-model` cases. Argument and
modifier spellings remain deferred.

The series is not done. Waiver budget remains zero. The old DOM lane remains
the shipped path; the publish-graph decision, hydrated full-corpus comparison
count, patch-flag equivalence and DOM allocation budget are still task-level
blockers. The flag's deletion is still an exit-gate line, not this record's to
tick.
