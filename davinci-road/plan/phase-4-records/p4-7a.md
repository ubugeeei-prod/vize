# P4-7a — S2-backed markup facade

**Patina's markup facade gains a zero-copy S2 backend, and a TS-25 lane proves
the facade observes the same document through Relief and through S2. Landed
2026-09-22.**

## What landed

- `crates/vize_patina/src/markup.rs` (1,636 lines) split into one module per
  facade type under `markup/`, and every type gained S2 variants.
  `MarkupDocument::from_s2` views an [`S2Markup`] — a borrowed S2 artifact:
  SFC templates through `S2Template::lower` (S1 parse + the new
  comment-preserving `vize_s1_to_s2::lower_preserving_comments`), JSX render
  roots through `S2Markup::from_jsx_root` over the P2-16 projection. `ui.if`
  answers `MarkupConditional`, `ui.for` answers `MarkupList`, and every
  attached op (`ui.bind` / `ui.on` / `ui.model` / `ui.slot-content` /
  `vue.directive` / the `vue.*` presence ops) answers `MarkupBinding` and
  `MarkupDirective`.
- `markup/differential.rs` (compiled under `cfg(test)` and the new
  `davinci-differential` feature): a `TraceRecorder` rule writes down every
  hook with its spans, names, values and modifiers plus every element query
  (children, attributes, opening items, ancestry, key, text, the whole
  `walk_tree`), and the traces of the two projections are compared line for
  line with exact string equality.
- `tests/davinci_markup_differential.rs`, the corpus-runnable entry, and
  `markup/tests/differential_tests.rs`, the plain-suite witness; both pin the
  same battery census.
- The `patina_s2_markup_one_root` stage in `benches/davinci_markup.rs`.

## The facade contract, made one

A raw template parse keeps `v-if` / `v-for` as directive attributes; S2 keeps
them as regions (`architecture.md`: "structured control flow (`if`/`for` as
regions, not directive attributes)"). The facade now presents S2's shape on
every backend, and the Relief backend synthesizes it (`markup/relief_scopes.rs`)
with the lowering's own rules, so the lane compares like with like:

| subject                   | contract                                                                                                                                                                                                                                                                                                                                |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Control flow              | a `v-if` chain is one `enter_conditional`, a `v-for` one `enter_list`; the structural directives are consumed, never reported as bindings or directives                                                                                                                                                                                 |
| Child view                | `walk_children` is the authored child list: in a template the `v-if` / `v-for` carrier element is the child (S2 reads a `ui.if` back as its branch carriers, with the gap comments from S1 and the re-emitted gap whitespace in their authored places); a JSX conditional / list expression is one `MarkupNode::If` / `MarkupNode::For` |
| Chain gaps                | whitespace and comments between branches are consumed; whitespace condensing kept re-enters _after_ the scope (the lowering's `drop.branch-gap` / preserved-gap rule)                                                                                                                                                                   |
| Blank `v-for`             | builds no list, as the lowering builds no `ui.for`                                                                                                                                                                                                                                                                                      |
| `<template>` carriers     | stay visible elements inside their scope; S2 unwraps them, the facade reads the carrier back off S1 (`S2Carrier`)                                                                                                                                                                                                                       |
| Element ranges            | a template element reports its opening tag (what the Relief parse records and the lint lane reports at); an implicit table owner is zero-width at the tag name of the row or cell that opened it; a synthesized slot carrier covers its slot spelling (S2V002 nesting)                                                                  |
| Element kind              | the lint-mode parse's rule (a component is a core built-in or a capitalized tag), not S2's DOM resolution                                                                                                                                                                                                                               |
| Text and attribute values | entity-decoded with the S2 decoders (`vize_s1_to_s2::emit::decode_html_entities` / `decode_html_attribute_entities`); a merged text/interpolation run is split back into its recorded `TextParts`                                                                                                                                       |
| Expressions               | `MarkupBinding::expression` is the trimmed, non-blank value text on every backend                                                                                                                                                                                                                                                       |
| `v-for` source / alias    | split with the lowering's own grammar (`vize_s1_to_s2::lower::split_v_for_value`), one splitter                                                                                                                                                                                                                                         |

## S2 backend design

`S2Markup` holds the op tree, the lowering's `TextParts` side table, the S1
surface tree, and the compile arena. S1 answers exactly the surface questions
S2 normalizes away, located by span (an S2 op span starts at its S1 element's
`<tag` token; S1 is a contiguous partition, so the lookup is a binary search
per level) rather than by a private re-scan:

- authored attributes S2 consumed or dropped — a `<slot>` outlet's `name`, a
  `v-if` carrier's static `key` (lifted into `IfFacts`), ill-formed or
  deferred directives — restored as surface items, in authored order;
- arguments, modifiers and values on the `vue.*` presence ops (`v-cloak.foo`,
  `v-cloak="x"`), which keep only what realization reads;
- opening-tag ranges, opening items (`walk_opening_item_ranges`), and the
  unwrapped `<template>` carriers.

Nothing is copied: elements, bindings, text and scopes borrow the op tree, the
side tables and S1. The only allocation is on-demand entity decoding into the
artifact's own arena, and only for text that carries an `&`.

`vize_s1_to_s2` gained four public entry points for this, each an existing
internal rule exposed rather than a second implementation:
`lower_preserving_comments`, `lower::split_v_for_value`,
`emit::decode_html_entities` and `emit::decode_html_attribute_entities`.

## Decisions

- **The reference parse uses the compiler's `<pre>` rule.** The lint lane's
  own parse (`ParserOptions::default()`) condenses inside `<pre>`; S2's text
  lowering is defined against the compiler's configuration (P2-9 installment
  4). The lane compares against Relief parsed with `is_pre_tag`, and the
  record states the lint parse's quirk rather than teaching S2 to reproduce
  it. Markup rules read text only for significance, which condensing never
  changes.
- **JSX is compared against the lowered Relief root.** The P2-16 projection is
  a projection _of_ that root; the OXC-direct projection has no scopes and is
  retired by P4-7b.
- One battery JSX module is refused by the P2-16 projection: a custom JSX
  directive (`v-custom={c}`, `S2Refusal::Directive`). The refused set is
  pinned by name in the plain suite.

## Left open (P4-7b)

- Switch `lint_sfc` / `lint_jsx` to the S2 facade and delete the Relief and
  OXC variants; the rules' `enter_list` / scope handling is already exercised
  by the Relief backend's structured view.
- Close the custom-JSX-directive refusal before the JSX lane can run on S2
  alone.
- The S2 pass measures about 1.6× the OXC pass's wall time on the gallery
  probe (6.4 µs vs 4.0 µs, report-only): the S1 lookup runs per element
  wrap. Carrying the S1 element down the walk instead of re-finding it is the
  obvious follow-up if the lint lane's wall ratchet needs it.
- Canonical-corpus closure evidence (the real-project matrix) is not wired;
  the committed lane runs the checkout's own shard.
