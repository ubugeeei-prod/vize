# P4-5b — S2 projection as an S4 target

## Slice 1: the target, the document APIs and the TS-25 lane (2026-09-22)

The TypeScript projection is emitted from S2 template ops plus the retained
script text into the P3-9 `EmitDocument`, and its `ProjectionMapping` is read
off the document's links (`vize_canon::projection::project_sfc`). There is no
projection-private emitter or mapping model (charter #26).

### Document APIs (additive, owned by this slice)

| API                                                       | Why the projection needs it                                                                                                                    |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `EmitDocument::link_since(start, authored)` (+ `_named`)  | One authored construct is written as several pushes, some linked; the whole run then links to the construct (the generator's 52 retro-ranges). |
| `edges: Vec<(Span, Span, u8)>`, `push_edge`, `edges()`    | Generated↔generated semantic links move with their fragment: rebased by `push_spanned`/`push_escaped`, never segments, round-tripped by parts. |
| `ProjectionMapping::from_emit_links` nests by containment | An enclosing link recorded after its children still owns them; sub-spans answer narrowest first.                                               |

### Target (slice 1 coverage)

Every S2 op and binding op is walked exhaustively (a new op fails to
compile): interpolations, `ui.bind`/`ui.on`/`ui.model`, dynamic names, Vue
dialect ops, `ui.if` conditions, `ui.for` sources and aliases, slot outlets
and slot parameters. Each construct is one `void (<expr>);` statement linked
to the construct with its expression linked to the expression. Only
`ExprRef::Js` projects; foreign, filter and opaque payloads emit nothing (the
pessimal law) and are counted per class (`ExprClassCounts`). Scoping (context
bindings, alias and slot parameter types, component props, macros) is not in
slice 1.

### TS-25 lane

`crates/vize_canon/tests/davinci_projection_differential.rs` compares
authored-anchor resolution over the TS-40 matrix: 57 anchor occurrences
(pinned by the plain-suite witness), 5 divergent, recorded exactly in
[`ts25-projection-divergence.txt`](../ts25-projection-divergence.txt) and
asserted behind `davinci-differential` in CI:

- `define-model` (`title`, `modelValue`) and `parent-local-import`
  (`ChildLocal`): the current generator maps macro and component references
  the S2 target does not project yet;
- `parse-recovery` (`broken` ×2): the S2 target projects a malformed SFC the
  current generator refuses.
