# P4-6c — Patina on the unified channel

**Every one of Patina's 248 rules declares a `RuleContract` — tier, declared
domain, default severity — in one table; the rule-parity matrix renders the
tier and refuses a rule without one; Patina diagnostics convert to
`vize_davinci::Diagnostic` under the witness law; the 98 error rules report
under counted exemptions; and FP-1 is fixed at its root.**

## Decisions

| subject       | decision                                                                                                                                                                                                                                                                                                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Table         | `RULE_CONTRACTS: &[RuleEntry]` sorted by name, one `row!(name, Tier, DOMAIN, Severity)` line per rule; `contract_for(name)` binary-searches it. Fourteen shared `Domain` statements (directive syntax, bindings, macros, CSS text, types, …) — a domain states what the tier's claim ranges over.                                                                            |
| Keys          | `tests.rs` enumerates every registry the linter draws on (`RuleRegistry::with_all` + opt-in, script, CSS, Musea) and asserts the table's names equal them exactly (248) and each severity equals the rule's `default_severity`.                                                                                                                                              |
| Tiers         | Initial declaration: `exact` 199 (a structural check the file's own syntax decides), `complete` 32 (fires only on a fact it resolves — bindings, macros, types — and cannot see what it does not resolve), `heuristic` 17 (a pattern that guesses intent), `sound` 0. P4-8 waves revisit each family with evidence; P4-15a derives defect classes from the exact/sound rows. |
| Demotion      | `script/no-potential-component-option-typo` guesses (edit distance) but its `RuleMeta` defaults to error: the const constructor refuses a heuristic error, so its contract says warning and `DEMOTED` pins the discrepancy until its P4-8 wave demotes the default or proves the check.                                                                                      |
| Conversion    | `output::unified::to_unified(&LintDiagnostic, SourceRoot) -> Result<Diagnostic, UnifiedError>`: severity clamped by the contract (configuration cannot promote a heuristic finding), errors under the rule's exemption, labels → secondary parts, help → help part, fix edits → suggestion parts, every range checked against the file.                                      |
| Exemptions    | 98 rule rows (one per error row, derived from the table by the inventory checker), plus `parser/template`, `parser/sfc` and `configured-error` (a warning-default rule raised to error by configuration) — Patina onboards 101 rows; the ratchet then only lets them fall.                                                                                                   |
| Unknown rules | A rule name outside the table and the two parsers (e.g. cross-file lanes assembled by the CLI) is refused with `UnifiedError::UnknownRule`, never silently exempted.                                                                                                                                                                                                         |
