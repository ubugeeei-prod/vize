# P4-4a — Orphan verdicts for non-effect products

**Checked (2026-09-23).** Every product in the consumption summary's
"no external consumers" section names a demand gate. `--check` fails
when an orphan has no gate or a gate names a product that gained a
consumer.

## Verdicts

| product | gate | why it stays off the hot path |
| --- | --- | --- |
| `Croquis.hoists`, `HoistTracker` | `analyze_hoisting` | The bit is the gate. No pass fills the tracker, so registering it allocates nothing. |
| `Croquis.symbols`, `Symbol*` | `symbol-table` | The table stays empty. Nothing in the draw writes it. |
| `Croquis.used_directives` | `track_usage` | Inserted only while usage tracking is on. |
| reactivity-overlay types | `reactivity-overlay` | Built only by `ReactivityTracker::overlay`. |
| `SetupContextTracker` | `setup-context` | Payload of `Croquis.setup_context`, which canon and croquis_cf already read. |
| `ProvideInjectTracker`, `RaceConditionTracker` | `provide-inject`, `race-conditions` | Payloads of fields the cross-file rules already consume. |
| `Croquis.component_usages`, `Croquis.used_components` | `ComponentUsages` | Producer storage. External readers use the fact group. |
| `Croquis.undefined_refs` | `UndefinedRefs` | Producer storage for the bindings fact group. |
| `EffectGraph` | `effect-graph` | Built only by `build_effect_graph_*`. |
| snapshot and summary types | `semantic-snapshot`, `summary-on-demand` | Built only when those methods run. |
| script, template, and scope payloads | `script-parse`, `template-facts`, `analyze_template_scopes`, `script-types` | Storage for passes those flags already gate. |

Provide/inject and race rules stay productized: their `Croquis` fields have
external consumers. The corpus-shard suppression scan on this tree is
`fp-candidates=0` (one unmapped `no-console`). No new FP candidate.

Lint callers take `SfcCroquisOptions::lint_demand`. Compile callers take
`DrawerOptions::compile_demand`. The flag sets are the old presets.
