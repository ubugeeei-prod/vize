# P4-2 — Fact-group alpha/beta split

**Every fact group may now declare an α form beside its β table:
`AlphaExport` (owned, `'static`, independently versioned, explicit
`export`/`import`), printed only inside a versioned `[fact-alpha]` document,
with `fact-alpha-schemas.md` as the documented contract and an executable
check that fails on an undocumented group. Landed 2026-09-22.**

## Boundary

No production group is registered yet (P4-3 migrates the trackers), so
`ALPHA_GROUPS` is empty and "every group registered at merge time" is the
fixture set in `tests/fact_alpha`. The schema doc fixes the α key/value shape
of the two P4-3a groups (`bindings`, `undefined-refs`), which the P4-3a
contract defers to this doc. Persistence and fingerprints are P5-1/P5-2.

## Decisions

| subject                   | decision                                                                                                                                                                                                                                  |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Trait                     | `trait AlphaExport: FactGroup { const ALPHA_SCHEMA: u16; type Alpha: Folio + PartialEq + Send + Sync + 'static; fn export(&FactTable<Self>) -> Alpha; fn import(Alpha) -> FactTable<Self>; const ALPHA_DESC }`                            |
| β stays the table         | β is the P4-1a `FactTable` the manager rebuilds on demand; α is a separate owned page, so the in-memory index can change without touching the serialized contract, and vice versa.                                                        |
| Owned                     | `Alpha: 'static` is the P1-11 arena/cache contract as a trait bound: an α page can never borrow an arena or a source.                                                                                                                     |
| Versioned by construction | `AlphaDocument<G>` prints `[fact-alpha]`, `group=`, `schema_version=` before the page (the P2-17 rule) and refuses a page under another group or version with an exact, line-numbered `FolioError`; body errors keep their document line. |
| Doc contract              | `fact-alpha-schemas.md` has one table row per α group (`group`, `id`, `alpha_schema`, key, value, status); `check_alpha_schema_doc` returns `Undocumented` / `Mismatch` for the first registered group it misses or contradicts.          |

## Mechanical witnesses

- `cargo test -p vize_davinci --test fact_alpha` — `import(export(t)) == t`
  for three fixture groups (a keyed number table, a keyed text table, a
  scalar) over three artifacts including the empty one; TS-16 `Full`-mode
  byte round trip of every α document plus two pinned canonical texts; exact
  refusals of a wrong version, a wrong group and a truncated header; the
  schema-doc check passing on the registered and planned groups and proven
  to fail on an injected undocumented group, a wrong version and a wrong id
- TS-24 (`--target wasm32-wasip2`, with and without default features), TS-1
  (`cargo test -p vize_davinci`), TS-13 assertion lint, the storage ledger
  (`alpha.rs` registered)

## Follow-up

P4-3 waves implement `AlphaExport` for their groups, flip their schema-doc
rows from `planned` to `registered`, and add them to `ALPHA_GROUPS`; P5-2's
per-SFC summary serializes `AlphaDocument`s.
