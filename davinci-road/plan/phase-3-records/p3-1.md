# P3-1 — Impeto crate and phase validator

**The first S3 slice lands the `vize_impeto` package, imported by new code as
`vize_s3`, plus the TS-27 phase validator. Landed 2026-09-12.**

## Boundary

This slice creates the S3 artifact vocabulary, not the S2-to-S3 lowering or any
backend retargeting. S3 starts as a flat, id-addressed document model with
explicit region, state-edge, and effect-scope records so later lowering and
backend work can add semantics without inventing a second dump contract.

## Decisions

| subject             | decision                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------ |
| Package spelling    | Cargo package id is `vize_impeto`; preferred workspace dependency alias is `vize_s3`.      |
| Residency           | Live programs use `vize_s0::Vec` and remain `Drop`-free; folio mirrors are owned.          |
| Phase spellings     | `built`, `partitioned`, and `scheduled` are the only accepted phase names.                 |
| Op family           | The 16-op set generalizes the current Vapor operation family without backend ownership.    |
| Validation boundary | TS-27 checks graph, region, effect-scope, and scheduled-order invariants with exact codes. |
