# P3-2 — Reactivity lattice fact group v1

**This slice establishes the first S3 reactivity-lattice fact group and its
folio page.**

## Boundary

P3-2 does not wire retained oxc ASTs into lowering yet. It commits the typed
summary boundary that P3-3 will feed: one binding id, origin, effect mask,
escape-analysis result, verdict, and authored span become one published
classification fact.

## Decisions

| subject        | decision                                                                                                                        |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Value axis     | `static -> props-stable -> reactive -> unstable`; joins move only toward less stable classes.                                   |
| Verdict axis   | `proven`, `refuted`, and `unknown` stay orthogonal to the value; consumers fire only on proven.                                 |
| Effects        | P3-2 names the React-Compiler-style vocabulary as a compact mask: freeze, capture, reads, mutations, unknown calls, allocation. |
| Escape         | Returned, stored, and global escapes demote the class through `props-stable`, `reactive`, and `unstable`.                       |
| Provide/inject | Provide/inject-derived bindings can be no more stable than `reactive`; stronger effects still win.                              |
| Folio          | `S3ReactivityFolio` prints the fact group as `[s3-reactivity-folio]`.                                                           |
