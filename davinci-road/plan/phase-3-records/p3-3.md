# P3-3 — S2 to S3 lowering first slice

**This task creates the `vize_s2_to_s3` conversion crate, lowers S2 regions
into built-phase S3 programs, exports the first static/dynamic partition fact
group, and closes P3-3 with S3 Folio snapshots plus S2 to S3 fuzz coverage.**

## Boundary

The lowering is intentionally a conversion crate. `vize_s2` does not depend on
Impeto internals, and `vize_impeto` does not learn S2's tree payloads. P3-3
focuses on total graph construction, shared partition facts, and artifact-level
coverage. Backend retargeting stays in P3-6, and richer reactivity-lattice
inputs stay with the scheduling/optimization work that consumes them.

## Decisions

| subject         | decision                                                                                          |
| --------------- | ------------------------------------------------------------------------------------------------- |
| Package home    | `vize_s2_to_s3` is publishable and depends on `vize_s2` plus the `vize_s3` alias for Impeto.      |
| Program phase   | The initial lowering emits `Phase::Built`; partitioning/scheduling remain later explicit passes.  |
| Id order        | S3 op ids follow S2 page order: owner op, attached bindings, then owned child regions.            |
| Region spans    | Non-empty regions use direct child-op span union; empty owned regions inherit the owner span.     |
| Effects         | Dynamic partition ops receive effect scopes; effect-order edges are explicit and unscoped.        |
| Partition facts | Facts are returned beside the S3 program so SSR can consume the partition without reading S3 ops. |
