# P6-1c — Output-target WIT world

**Landed 2026-09-23.** `contracts/wit/output-target.wit` defines the output
world — canonical S2 and S3 pages in, one span-carrying S4 document out —
and TS-48 exchanges a fixed document with a stub guest in both hosting
modes, byte for byte.

## What landed

- **World** (`vize:contracts@0.1.2`, additive over 0.1.1): interface
  `emission` with one coarse-grained call, `emit(emit-request) -> emitted`.
  The request carries `s2-page@1` and `s3-page@1`. The answer carries
  `emit-document-page@1` (generated text plus generated↔authored links, the
  P3-9 `EmitDocument` shape) and diagnostics. The world exports `handshake`
  and `emission` and imports only the types-only `types` interface.
- **Host** (`vize_extension_host::output`): `OutputSession` negotiates the
  world's required features and accepts the answer as untrusted input.
  Request pages must be schema 1. The document must parse and reprint
  canonically, every generated range must lie inside the text on a character
  boundary, and every diagnostic span must lie inside an authored link.
  Both hosting modes serve it: `WasmOutputGuest` in process and
  `vize-extension-host serve --world output-target` out of process.
- **Released surface**: `contracts/versions/vize-contracts@0.1.2.json`.
  The Rust SDK and `@vizejs/extension-sdk` carry the WIT, the TypeScript
  mirror of `EmitRequest`, `Emitted` and `Emission`, and the new page
  schemas and required features.

## Acceptance evidence

- TS-48, output world
  (`cargo test -p vize_extension_host --offline --features extension-host --test wit_golden_output`):
  the stub guest (`tests/guests/output-echo`, on the SDK runtime) negotiates
  protocol 1 with no ignored features in both modes, returns the committed
  `probe.emit.folio` byte-equal, and traps an unknown request with the exact
  message. The component imports only `vize:contracts/types@0.1.2`.
- `cargo test -p vize_extension_host --offline --test output_contract`: the
  golden is canonical, and a wrong schema, a non-canonical page, a generated
  range past the text, and a diagnostic outside the authored links are
  refused.
- `cargo test -p vize_extension_host --offline --test contract_surface`: the
  released history 0.1.0 → 0.1.2 passes the P6-8 policy and 0.1.2 is the WIT
  today.
- The input and expression TS-48 tests still pass against `@0.1.2`.
- `node --test tests/tooling/davinci-extension-sdk.test.ts`: the TypeScript
  declarations mirror the released surface, including `emission`.

## Remaining

- The request pages are schema-checked folio text. Parsing them as a real
  `S2Folio` and an S3 document is P6-6, the first consumer of this world.
- No compiled-in output target answers the world yet (P6-6 / Volt).
