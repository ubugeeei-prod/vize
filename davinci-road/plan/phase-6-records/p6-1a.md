# P6-1a — Input-dialect WIT world and capability handshake

**Landed 2026-09-22.** The `vize:contracts@0.1.0` WIT package exists, the
input-dialect world is derived from the in-tree S1/S2 boundary, and TS-48 runs
it through a real component guest in both hosting modes.

## What landed

- `contracts/wit/`: `types` (span, page, the diagnostic channel), `handshake`
  (`capability`: integer protocol version + feature strings,
  `get-capability`) and `input-lowering` (`source-block` in, `lowered-block`
  out: S1 page, S2 page, diagnostics), assembled as the `input-dialect` world.
  One call per block; the call is total like the in-tree lowering.
- `crates/vize_extension_host/` (publish = false, experimental): the host
  mirror of the WIT types, negotiation (`handshake.rs`), acceptance of a
  guest's answer as untrusted input (`accept.rs`), the session that routes
  blocks by declared `lang:` features, the in-tree Vue dialect behind the
  same `InputDialectGuest` trait (charter #15's first-party tier), the
  out-of-process transport (`outproc.rs` + `wire.rs`: a child
  `vize-extension-host serve <component>` answering JSON lines), and the
  wasmtime component host behind the `extension-host` feature (`wasm.rs`).
- The S1 page (`s1-page@1`, [folio-format-s1.md](../folio-format-s1.md)): S1
  had no folio form, so the contract gained one. It records structure and
  block-relative offsets only; the reader checks that the tokens tile the
  block and rebuilds the tree, so a guest can neither drop nor invent a byte.
- `.github/workflows/davinci-contracts.yml`: the one CI lane that compiles
  wasmtime (clippy with the feature, then TS-48).

## Decisions

- **Payloads are the folio `Full` pages, schema-versioned per P2-17**: the S2
  page is the existing disegno page; `page.schema-version` is checked before
  the text is parsed, and the refusal names both versions.
- **Negotiation**: the protocol version must equal the host's (1); features
  must be sorted and unique so an offer has one spelling; the world requires
  `s1-page@1` and `s2-page@1`; `lang:<value>` features route blocks (a block
  with an undeclared `lang` never reaches the guest); unknown features are
  set aside, never refused — offering more is additive.
- **Guests import no host function.** The world's only import is the
  types-only `vize:contracts/types` instance, the linker is empty, and the
  echo guest is `no_std` with its own allocator, `cabi_realloc`, `memcmp` and
  panic handler. A guest asking for WASI fails to instantiate: guests are
  pure functions of their block. Packaging that scaffolding is P6-2's.
- **Trap messages carry no wasm backtrace** (`wasm_backtrace_max_frames(None)`):
  they cross the contract verbatim and a backtrace's code offsets change with
  every guest build.
- **Both hosting modes already run TS-48.** The child process of the
  out-of-process mode is the in-process host, so the in-process mode came for
  free; P6-3 still owns fuel and memory limits, the dependency-graph proof and
  the audit gate.

## Acceptance evidence

TS-48 for the input world — capability negotiation including the exact
version-mismatch refusal, and byte-equal payloads in the golden exchange:

- `cargo test -p vize_extension_host --features extension-host --test wit_golden`
  (7 tests): the echo guest (`tests/guests/echo`, built with `--locked` for
  `wasm32-wasip2`) negotiates in both modes; a build offering protocol 2 is
  refused in both modes with
  `handshake refused: protocol version mismatch: the host speaks 1, the guest offered 2`;
  four golden blocks come back
  byte-equal to the committed pages and equal to the in-tree Vue answer; a
  probe block carries every diagnostic shape (all severities, stages, part
  kinds, the witness) across the canonical ABI; an unknown block traps with
  ``wasm trap: wasm `unreachable` instruction executed``; a non-component
  file is refused at load with the same message in both modes; the guest's
  only import is the types-only instance.
- `cargo test -p vize_extension_host`: the S1 page laws over the TS-19
  battery and all 2,148 prefix/suffix truncations; the in-tree Vue dialect
  across the contract over the battery at three bases (126 exchanges: the S1
  page rebuilds the tree, the S2 page is the lowered op tree's folio, the
  diagnostics convert back unchanged, the wire JSON round-trips); the
  committed goldens pinned to the in-tree output; every handshake and
  acceptance refusal with its exact message.
- `cargo audit --deny warnings` over the lockfile with the 62 crates wasmtime
  48.0.2 adds (itself included): no advisory (RustSec database of
  2026-09-22).
