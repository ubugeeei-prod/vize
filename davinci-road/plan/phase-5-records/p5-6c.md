# P5-6c: remaining request paths on resident descriptors

Status: partial. The request-path `parse_sfc` count is 14, not zero, and
`IdeContext::with_content` remains. The phase exit is not claimed.

Earlier slices moved semantic tokens, inlay hints and document links to
`ServerState::sfc_descriptor`. The annotations/structure slice adds code
lenses, document colours, document symbols and folding ranges. Their
handlers now share the descriptor used by hover and diagnostics instead of
parsing the same buffer for every provider request.

The existing response construction is preserved. New tests cover full
responses, cache hits across providers, edit invalidation, cached parse
rejection and recovery, close/reopen, regular scripts, and Unicode/CRLF.
Four consecutive provider requests perform one descriptor parse per
revision. Existing exact range and colour tests remain unchanged.

The tooling ceiling falls from 44 to 40 total call sites (25 request-path
and 15 test-only). The four migrated providers have zero direct calls.

Validation: Maestro library tests (1,014 passed, two already ignored), plus
the ten parse-count and migration guard tests. The library suite uses the
pinned TypeScript 7.0.2 runtime, including real Corsa session isolation.

The context-consumer slice reuses `IdeContext::descriptor` for type queries,
type-aware completions, ecosystem completions, lint actions, fix-all actions,
and the auto-import/reactive-ref helpers. It removes eight additional direct
parses: the ceiling is now 32 total sites (17 request-path, 15 test-only).
Cached parse rejection, Unicode/CRLF edit ranges, typed completion details,
incremental-equals-clean responses and retained in-flight revisions are covered
by the context tests. The remaining type-service/ecosystem diagnostic paths and
other providers still prevent claiming the P5-6c exit.

Context-consumer validation: 1,017 Maestro library tests passed (two existing
ignores) with the pinned TypeScript 7 runtime, and the 21 parse-count/matrix
checks passed. The authored type-query tests also exposed a pre-existing
binding extractor error: the inference helper received the identifier rather
than the text after it. Passing the suffix restores literal/annotated types
without changing the Corsa type-checking service.

The template-ref/diagnostic slice shares the request descriptor between static
`ref` hover and definition. Ecosystem diagnostics receive the descriptor already
held by the collector and read its source, so their offsets cannot drift to a
newer document-store revision. The deprecated type-service diagnostic entry
point also uses the resident cache. This removes three direct parses: 29 total
sites remain (14 request-path, 15 test-only). The strict Canon diagnostic
pipeline still parses internally and is not claimed as migrated by this slice.

Regression coverage checks authored hover/definition responses and route
warning ranges with Unicode/CRLF, explicit request content differing from the
store, retained in-flight revisions, warm-cache reuse, edit invalidation,
parser rejection/recovery, and close/reopen.
