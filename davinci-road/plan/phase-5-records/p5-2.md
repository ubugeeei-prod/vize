# P5-2 — Per-SFC summary

Contract: [phase-5-tasks.md](../phase-5-tasks.md#p5-2--per-sfc-summary).
Landed 2026-09-22.

## What landed

`vize_davinci::summary::SfcSummary` is the per-SFC interface, built from the
α pages of that interface (the GHC `.hi` model, not a file hash):

- **Facets** — `component-signature`, `prop-types`, `emit-types`,
  `slot-types`, `reactivity-classes`, `component-references`. Each is one α
  group at schema 1. `Facet::from_alpha_group` refuses every other group
  (`expression-facts`, an S3 code shape) and a schema this summary does not
  read.
- **One fingerprint per declaration.** XXH3-128 over the group's name, its
  schema, the declaration's identity, and its contract. The file and every
  sibling declaration are not inputs. `AlphaPages` has no body and no
  code-shape field, so a hot-path optimization cannot be written into a
  summary.
- **Record what you used.** `Usage::record` stores the fingerprints a
  consumer actually read. `SfcSummary::invalidated` returns exactly the
  consumers for whom one of those fingerprints is missing or different.
- **Folio.** `[sfc-summary]` is hand-written: a schema line that is not the
  version this summary reads is refused, the signature is one declaration
  (`name` / `params`), and empty facets are omitted. `Display` and `Full`
  print the same bytes.

## Evidence

`cargo test -p vize_davinci --test sfc_summary` — 7 tests:

- canonical `[sfc-summary]` text round-trips byte for byte, `Display` matches
  `Full`, and a reordered header plus unsorted props normalizes back to that
  text (TS-16);
- the no-ripple fixture: caching `count.value * 2` in a `computed` changes
  the body and no fingerprint, and every recorded consumer stays fresh;
- changing the signature's type parameters invalidates exactly `shell` and
  `header` (the consumers that recorded it); changing `label`'s type
  invalidates exactly `card`;
- adding `size` and a second `count` leaves every existing fingerprint
  unchanged, and the same contract on two facets does not collide.

## Not in this task

The global summary is P5-3. Salsa firewall queries over these fingerprints

waves; this summary is the page those α exports fill.
