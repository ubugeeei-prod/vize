The literal-style projection consumes original OXC object expressions across JSX, retained template transforms and native L3. It does not parse a replacement expression or rewrite emitted code. A single, unmodified lowercase style binding can become an existing static template attribute. Any case-equivalent authored style source, spread, computed prop name or ambiguous merge retains its original runtime path and spelling.

Only literal string values with a proved declaration boundary enter this projection. References, calls, getters, methods, spreads, computed/numeric/prototype keys, CSSOM members, uppercase/vendor aliases, empty values, grouping, quotes, escapes, declaration separators, comments and control characters retain runtime behavior. This is a bounded constant evaluator; it does not establish general CSS validity. Duplicate JavaScript keys preserve their first insertion position and last value before CSS key normalization. Custom-property spelling remains case-sensitive. Bang-bearing values require a noncustom key, an ASCII value, one exact terminal lowercase `!important` token and a nonempty stem; every other priority spelling, Unicode boundary or custom-property priority retains runtime behavior without normalization.

The fixed inputs and original observed packets live in `tests/_fixtures/differential/compiler/vapor-literal-object-styles-10749/`. `authority.json` identifies the original 888 source campaign and preserves its complete before/head packets and measurements. Those historical packets predate the CSSOM and attribute-case review fixes. `admission-source-pairs.json` separately identifies the refined producer bytes; the older authority is never relabeled as qualification of those refinements.

The dedicated workflow builds the actual pinned baseline and literal PR head with separate Cargo targets, copies the identical observer and fixed inputs, and compares complete outputs. Its families contain:

- 180 original input packets, including 30 changed folds and 150 preserved runtime/default/SSR controls. Their complete head outputs must also remain identical to the original frozen 888 head packets.
- 48 CSSOM review packets: six refused vectors preserve their old runtime operations; two ordinary/important controls prove static component output.
- 48 attribute-case/order packets, all preserving their complete old outputs.
- A separate 48-packet priority family preserves seven refused vectors and the ASCII-space positive, without changing any earlier input family.
- Four complete SFC DTOs: Vapor CSR uses the static template; the other target combinations remain unchanged.
- Ten complete independent UTF-16 map arrays, preserving the original eight inputs and adding two HTML-entity/static-reference controls, including same-line astral characters and CRLF edits, with wrong aggregate origins, foreign source content and stale generated columns rejected.

Generated CSS maps to its actual authored style name and whole expression span. A direct template RootNode owns the complete input beginning at zero; a JSX root retains its actual module offset. The template map witness does not qualify authored JSX module maps. That additional boundary belongs to the composed authored-module and actual Babel host campaigns.

The full-compile observer retains its original 12 input roles and adds 12 priority-specific roles, reporting nine timing samples, phase/candidate counters, counted expression reparses and used arena bytes. Arena bytes exclude owned heap allocations. Timings include parsing, lowering, generation and JSON observation, and are reports rather than ceilings or production speedup claims. Browser CSR/SSR/hydration, actual Node ABI, merge, publication and fresh-consumer acceptance remain separate gates.
