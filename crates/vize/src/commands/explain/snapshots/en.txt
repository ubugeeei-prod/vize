=== a11y/aria-props
a11y/aria-props · lint rule
Disallow invalid ARIA attributes

tier: exact
domain: native elements with static attributes and roles in SFC templates; components and dynamic bindings are outside
severity: error
category: accessibility
autofix: no
docs: docs/content/rules/accessibility.md

help:
  Why: Invalid ARIA attributes prevent assistive technologies from conveying the intended meaning to users.
  Valid ARIA attributes are defined in the WAI-ARIA specification:
  https://www.w3.org/TR/wai-aria/#state_prop_def
  Common ARIA attributes:
    <!-- Labeling -->
    <input aria-label="Search" />
    <div aria-labelledby="title-id">

    <!-- State -->
    <button aria-expanded="false">
    <input aria-invalid="true">

    <!-- Relationships -->
    <input aria-describedby="hint-id">
    <div aria-controls="panel-id">
  Note: Custom aria-* attributes are not allowed. Only use attributes from the WAI-ARIA specification.

invalid:
  <div v-bind></div>

valid:
  <div :class="foo"></div>
  <div v-bind:class="foo"></div>
  <div v-bind="{ class: foo }"></div>

    <!-- Shorthand -->

    <img v-bind:src="imageUrl">

    <!-- Bind multiple attributes -->
    <div v-bind="{ id: itemId, class: itemClass }"></div>

category: essential
autofix: yes

invalid:
  <div v-else="foo"></div>
  <div v-else v-if="bar"></div>
  <div v-else></div> <!-- without preceding v-if -->

valid:
  <div v-if="foo"></div>
  <div v-else></div>

help:
  Correct usage:
    <div v-if="type === 'A'">A</div>
    <div v-else-if="type === 'B'">B</div>
    <div v-else>Other</div>
  Rules:
  - v-else takes no expression
  - Must immediately follow v-if or v-else-if
  - No other elements between them
=== vue/valid-v-for
vue/valid-v-for · lint rule
Enforce valid `v-for` directives

tier: exact
domain: elements and Vue directive syntax of SFC templates as parsed: names, arguments, modifiers, expressions and placement
severity: error
category: essential
autofix: no
docs: docs/content/rules/vue.md

invalid:
  <div v-for></div>
  <div v-for=""></div>
  <div v-for.stop="item in items"></div>

valid:
  <div v-for="item in items" :key="item.id"></div>
  <div v-for="(item, index) in items" :key="index"></div>

help:
  Valid v-for syntax:
    <!-- Array iteration -->
    <li v-for="item in items">{{ item }}</li>
    <li v-for="(item, index) in items">{{ index }}: {{ item }}</li>

    <!-- Object iteration -->
    <li v-for="(value, key) in object">{{ key }}: {{ value }}</li>
    <li v-for="(value, key, index) in object">{{ index }}</li>

    <!-- Range -->
    <span v-for="n in 10">{{ n }}</span>
