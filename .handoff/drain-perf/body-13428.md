## Changes

The linter traverses L2 operations, expression facts, diagnostics and the authored L1 tree. All three public lint entry points used to allocate an owned provenance record for each lowering decision. The internal lint input now requests the existing zero-sized provenance sink. Public markup inspection still returns the recorded artifact, including parser-inserted table owners.

**Scope change during the drain:** the Vitrine plugin-transform half of the original PR is reverted. With that half, the shipped release N-API library grew by 35,600 bytes even though the CLI shrank (see below). The transform keeps its recording lowering. The new test still pins the record a transform edit produces: plugin name, original and encoded spelling, node ID and authored span.

The template lint allocation budget runs inside the existing single-case `davinci_authored_markup_budget` harness, so its nextest protocol (`authored-allocation-nextest-protocol.test.ts`) stays unchanged.

Refs #11573.
