# Mapper campaign functional contracts

This library qualifies source and runtime custody for a future public mapper comparison. It does not register a performance job or a manual workflow trigger. Pull requests run source-pinned strict TypeScript and fourteen finite controls.

The contracts require complete emitted CLI diagnostic populations, preserve multiline messages and duplicates, validate raw protocol frames and every authored transform, compare directive authority, and close all physical SDK declarations and publish files. Conditional types exports, relative declaration imports and missing globals/slots fail even when unused by the checker. Provider payload, normal wrapper, NAPI image and helper closure must remain unchanged across an observation.

Repository orchestration and controls are typed TypeScript executed directly by Node stable type stripping. The protocol tee is a runtime asset copied into consumer node_modules; it is not a repository tooling entrypoint. External mapper commands receive no CI credentials or native-loader overrides.

The process helpers retain argv and original streams before spawning and clamp child timeouts to a shared deadline. GNU time maximum RSS and checker terminal memory are distinct metrics. A future performance controller must separate normal primary calls from diagnostic/profiler captures and define cold/warm, process-tree memory and complete diagnostic identity explicitly.

Run the finite qualification with the existing source-pinned dependencies:

```sh
node tools/benchmarks/scripts/template-alias-paired-11822-contracts.ts
```

The earlier campaign prototype depended on an unavailable private corpus. Its controller and manual job are excluded. Private source or lock data must not be published as fixtures or Actions artifacts. A public Misskey/n8n project or newly authored synthetic corpus needs its own source pins, scope, paired raw evidence, bounded budget and dispatch approval. Passing these controls is not performance acceptance.
