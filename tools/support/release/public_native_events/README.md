# Published native event casing

`Public native event casing` is a manual consumer qualification. It installs exact public npm packages outside the checkout; it neither builds native code nor publishes a release. The release coordinator supplies the version and exact release-tag commit. The workflow verifies the tag and requires an `after` release to contain source fix `3fa5cf66c8f5d12e7d2f286df5050933cb0daf47`.

The ten templates and twenty branch observations were captured before a release containing that fix. The original native `v-if`, keyed `v-for`, and component `v-if` reproductions are included alongside lowercase, unkeyed, explicit-key, and component controls. Both compilers use `prefixIdentifiers: true`. Complete VNode packets retain handler identities, props, keys, children, patch flags, dynamic prop lists, and shape flags. The receipt also keeps every complete native compile result, native binary digest/build token, and the installed package lock.

The `.json.txt` byte fixture preserves the original JSON serialization without reformatting. The independent reference is generated by `@vue/compiler-dom@3.5.44` and `vue@3.5.44`. Its immutable SHA-256 is `c8752cefa3ebd5ccfdbe9477804fe8fc4bc03060507efdef4bb7961f8df97437`; the input SHA-256 is `d614ba281249549cbc92c061defd21a9aeee0b724aa644b16e7df35b7a205cce`. Each run recomputes the official result and requires it to equal the original reference. The runner never rewrites the reference.

The `before` phase accepts only public `0.599.0` and requires exactly the five original affected cases to fail, with all five neighboring controls passing. It validates the harness and earns no fixed-release acceptance. The `after` phase requires all twenty observations to match the full frozen oracle. Receipts are written once, including comparison failures, and retained as Actions artifacts.

An earlier `prefixIdentifiers: false` exploration found Vize's pre-existing constant-loop stable-fragment optimization (flag 64) versus Vue's keyed/unkeyed flags (128/256). Those exploratory results remain separate from this prefixed contract; no fragment-flag expectations were changed to accept a fixed release.
